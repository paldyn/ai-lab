[앞 노트](/learn/certs/sqld/08-where-and-comparison-logical-operators)에서는 `WHERE`로 남길 행을 골랐습니다. 이번에는 남은 행의 값을 가공하는 함수입니다. 함수 문항은 대개 「이 식의 결과는?」 꼴이라, 이름과 뜻을 아는 것만으로는 모자라고 위치를 하나하나 세어 값을 직접 내 보는 연습이 필요합니다. 이 노트의 예는 전부 Oracle 기준으로 적고, SQL Server가 다른 자리는 마지막 절에서 한데 모읍니다.

## 단일행 함수

### 행마다 하나의 결과

SQL 함수는 결과를 몇 개 내느냐로 갈립니다. 행 하나를 받아 결과 하나를 돌려주는 것이 **단일행 함수**이고, 여러 행을 묶어 결과 하나를 내는 것이 다음다음 노트에서 볼 집계 함수입니다. 사원이 네 명인 테이블에 `UPPER(사원명)`을 걸면 결과도 네 행이고, `SUM(급여)`를 걸면 한 행입니다.

| 구분 | 단일행 함수 | 집계 함수 |
| --- | --- | --- |
| 입력 | 한 행의 값 | 여러 행의 값 |
| 결과 행 수 | 입력 행 수와 같다 | 그룹마다 하나 |
| 예 | `SUBSTR` `ROUND` `ADD_MONTHS` | `SUM` `AVG` `COUNT` |

### 쓸 수 있는 자리

단일행 함수는 `SELECT` 목록뿐 아니라 `WHERE`·`ORDER BY` 절에도 들어갑니다. 함수 안에 함수를 넣는 **중첩**도 되고, 이때는 가장 안쪽부터 계산합니다. `LENGTH(TRIM('  SQL  '))`는 먼저 양쪽 공백을 지워 `'SQL'`을 만들고 그 길이 3을 돌려줍니다. 그리고 `TO_CHAR`처럼 받은 값과 다른 데이터 타입을 돌려주는 함수도 있으므로, 「단일행 함수는 데이터 타입을 바꾸지 않는다」는 보기는 틀린 문장입니다.

## 문자 함수

### 자르기와 찾기

예제 문자열은 `'SQL Expert'`입니다. 공백도 한 글자로 세므로 위치는 S가 1, 공백이 4, E가 5이고 전체가 10글자입니다.

- `SUBSTR(문자열, 시작, 길이)` — 시작 위치부터 길이만큼 잘라 냅니다. `SUBSTR('SQL Expert', 5, 3)`은 `'Exp'`입니다. 길이를 빼면 끝까지 자르고, 시작에 음수를 주면 뒤에서부터 셉니다.
- `INSTR(문자열, 찾을 문자)` — 처음 나타나는 위치를 돌려주고 없으면 0입니다. 대소문자를 가리므로 `INSTR('SQL Expert', 'e')`는 대문자 E를 건너뛰고 8입니다.
- `LENGTH(문자열)` — 글자 수입니다. `LENGTH('SQL Expert')`는 10입니다.

### 바꾸기와 다듬기

`REPLACE(문자열, 찾을 것, 바꿀 것)`는 찾은 부분을 모두 바꿉니다. `REPLACE('SQL Expert', 'SQL', 'DB')`는 `'DB Expert'`이고, 셋째 인자를 빼면 찾은 부분을 지워 버립니다.

공백이나 지정한 문자를 걷어 내는 함수가 셋입니다. `LTRIM`은 왼쪽에서, `RTRIM`은 오른쪽에서 지정한 문자를 지우고, `TRIM`은 양쪽에서 지웁니다. 지울 문자를 안 적으면 공백을 지웁니다.

| 식 | 결과 |
| --- | --- |
| `LTRIM('xxSQLxx', 'x')` | `'SQLxx'` |
| `RTRIM('xxSQLxx', 'x')` | `'xxSQL'` |
| `TRIM('x' FROM 'xxSQLxx')` | `'SQL'` |

`TRIM`만 문법 모양이 다르다는 것이 헷갈리는 자리입니다. `LTRIM`·`RTRIM`은 지울 문자를 둘째 인자로 받지만 `TRIM`은 `FROM`을 써서 앞에 적고, `LEADING`·`TRAILING`·`BOTH`로 방향을 고를 수 있습니다.

### 채우기

`LPAD(문자열, 전체 길이, 채울 문자)`는 전체 길이가 될 때까지 왼쪽을 채우고, `RPAD`는 오른쪽을 채웁니다. `LPAD('7', 3, '0')`은 `'007'`, `RPAD('AB', 5, '*')`는 `'AB***'`입니다. 문자열이 이미 전체 길이보다 길면 채우는 대신 잘라 내서 `LPAD('ABCDE', 3)`은 `'ABC'`가 됩니다. 사번이나 코드를 일정한 자릿수로 맞출 때 쓰는 함수입니다.

## 숫자 함수

### ROUND와 TRUNC

`ROUND(숫자, 자리)`는 반올림이고 `TRUNC(숫자, 자리)`는 버림입니다. 둘째 인자는 소수점 아래 몇째 자리까지 남길지를 뜻하고, 빼면 0으로 보아 정수만 남깁니다. 음수를 주면 소수점 왼쪽 자리에서 처리합니다.

| 식 | 결과 | 읽는 법 |
| --- | --- | --- |
| `ROUND(123.456, 1)` | 123.5 | 소수 첫째 자리까지, 둘째 자리 5에서 올림 |
| `TRUNC(123.456, 1)` | 123.4 | 소수 첫째 자리까지, 나머지는 버림 |
| `ROUND(123.456, -1)` | 120 | 일의 자리 3에서 내림 |
| `ROUND(125, -1)` | 130 | 일의 자리 5에서 올림 |

### CEIL과 FLOOR

`CEIL`은 그 수보다 크거나 같은 가장 작은 정수이고 `FLOOR`는 작거나 같은 가장 큰 정수입니다. 양수에서는 「올림」과 「내림」으로 읽어도 맞지만 음수에서 방향이 갈립니다. `CEIL(-3.1)`은 -3이고 `FLOOR(-3.1)`은 -4입니다. 수직선에서 `CEIL`은 오른쪽, `FLOOR`는 왼쪽으로 간다고 기억하면 부호와 상관없이 맞습니다. `TRUNC(-3.7)`은 0 쪽으로 잘라 -3이라 `FLOOR(-3.7)`의 -4와 다릅니다.

### MOD

`MOD(m, n)`은 m을 n으로 나눈 나머지입니다. `MOD(17, 5)`는 2입니다. Oracle에서 나머지의 부호는 나뉘는 수 m을 따르므로 `MOD(-17, 5)`는 -2입니다. 짝수 행만 고르는 `WHERE MOD(사번, 2) = 0` 같은 조건에 씁니다.

## 날짜 함수

### SYSDATE와 날짜 산술

`SYSDATE`는 데이터베이스 서버의 현재 날짜와 시각입니다. Oracle의 날짜는 하루를 1로 보는 수처럼 더하고 뺄 수 있고, 결과의 타입이 연산마다 정해져 있습니다.

| 연산 | 결과 타입 | 예 |
| --- | --- | --- |
| 날짜 + 숫자 | 날짜 | `SYSDATE + 7`은 일주일 뒤 |
| 날짜 − 숫자 | 날짜 | `SYSDATE - 1`은 하루 전 |
| 날짜 − 날짜 | 숫자 | 두 날짜 사이의 일수 |
| 날짜 + 숫자/24 | 날짜 | `SYSDATE + 1/24`는 한 시간 뒤 |

날짜끼리 더하는 `날짜 + 날짜`는 뜻이 없어 오류입니다. 「날짜에서 날짜를 빼면 날짜가 된다」는 보기도 틀렸습니다 — 결과는 일수, 곧 숫자입니다.

### 월 단위 함수

일 단위가 아니라 월 단위로 셈하는 함수가 셋입니다.

- `MONTHS_BETWEEN(날짜1, 날짜2)` — 날짜1에서 날짜2를 뺀 개월 수입니다. 날짜1이 더 늦으면 양수입니다. `MONTHS_BETWEEN(DATE '2026-03-31', DATE '2026-01-31')`은 2입니다.
- `ADD_MONTHS(날짜, n)` — n개월 뒤의 날짜입니다. 결과 달에 그 일자가 없으면 그 달의 마지막 날이 됩니다. `ADD_MONTHS(DATE '2026-01-31', 1)`은 2026년 2월 28일입니다.
- `LAST_DAY(날짜)` — 그 날짜가 속한 달의 마지막 날입니다. `LAST_DAY(DATE '2026-02-10')`은 2026년 2월 28일이고, 윤년인 2028년이면 29일입니다.

### 날짜 자르기

`ROUND`와 `TRUNC`는 날짜에도 씁니다. `TRUNC(SYSDATE)`는 시각을 걷어 내 그날 0시로 만들고, `TRUNC(SYSDATE, 'MM')`은 그달 1일 0시입니다. `SYSDATE`에는 시각이 함께 들어 있어서 `WHERE 입사일 = SYSDATE`는 거의 맞는 행이 없고, 「오늘 입사한 사람」은 `TRUNC`로 시각을 맞춘 뒤 비교해야 찾습니다.

## Oracle과 SQL Server

### 이름이 다른 함수

시험은 두 제품의 표기를 섞어 보기로 낼 수 있습니다. 같은 일을 하는 함수의 이름이 다른 자리를 표로 모읍니다.

| 하는 일 | Oracle | SQL Server |
| --- | --- | --- |
| 부분 문자열 | `SUBSTR` | `SUBSTRING` |
| 문자 위치 | `INSTR` | `CHARINDEX` |
| 글자 수 | `LENGTH` | `LEN` |
| 올림 | `CEIL` | `CEILING` |
| 현재 시각 | `SYSDATE` | `GETDATE()` |
| 문자열 잇기 | `\|\|` 또는 `CONCAT` | `+` 또는 `CONCAT` |
| 월 더하기 | `ADD_MONTHS` | `DATEADD(MONTH, n, 날짜)` |

### 동작이 다른 자리

이름이 같아도 동작이 조금 다른 자리가 있습니다. SQL Server의 `LEN`은 끝에 붙은 공백을 세지 않지만 Oracle의 `LENGTH`는 셉니다. 또 SQL Server에는 `TRUNC`가 없어 버림을 `ROUND(숫자, 자리, 1)`처럼 셋째 인자로 냅니다. 시행처가 공개한 과목 구성은 SQLD를 2과목 50문항 객관식으로 두고 있어, 이런 표기 차이는 네 보기 중 하나를 다른 제품의 이름으로 바꿔 놓는 꼴로 물을 수 있습니다. 보기에 `SUBSTR`와 `SUBSTRING`이 함께 보이면 어느 제품 기준인지부터 확인합니다.

## 연습 문제

1. 단일행 함수에 대한 설명으로 옳지 않은 것은?\
   ① 각 행마다 결과를 하나씩 돌려준다\
   ② `WHERE` 절에서도 쓸 수 있다\
   ③ 함수 안에 다른 함수를 넣을 수 있다\
   ④ 입력과 다른 데이터 타입을 돌려줄 수 없다

   답. ④. `TO_CHAR`처럼 숫자나 날짜를 받아 문자를 돌려주는 함수가 있습니다.
2. `SUBSTR('DATABASE', 3, 4)`의 결과는?\
   ① `'ATAB'`\
   ② `'TABA'`\
   ③ `'DATA'`\
   ④ `'BASE'`

   답. ②. D1 A2 T3 A4 B5 이므로 3번째 T부터 네 글자인 `'TABA'`입니다.
3. Oracle에서 `INSTR('Data Model', 'a')`의 결과는?\
   ① 0\
   ② 1\
   ③ 2\
   ④ 4

   답. ③. 대소문자를 가리므로 첫 글자 D 다음의 a가 처음 나타나는 자리, 2입니다.
4. 다음 중 결과가 `'SQL'`이 아닌 것은?\
   ① `TRIM('*' FROM '**SQL**')`\
   ② `LTRIM(RTRIM('**SQL**', '*'), '*')`\
   ③ `REPLACE('**SQL**', '*')`\
   ④ `LTRIM('**SQL**', '*')`

   답. ④. 왼쪽 별표만 지워 `'SQL**'`이 남습니다. ③은 바꿀 것을 안 적어 별표가 모두 지워집니다.
5. 다음 중 결과가 가장 큰 것은?\
   ① `ROUND(45.67, 1)`\
   ② `TRUNC(45.67, 1)`\
   ③ `CEIL(45.67)`\
   ④ `ROUND(45.67, -1)`

   답. ④. 차례로 45.7, 45.6, 46, 50입니다. ④는 일의 자리 5에서 올려 50이 됩니다.
6. `CEIL(-2.5) + FLOOR(-2.5)`의 결과는?\
   ① -6\
   ② -5\
   ③ -4\
   ④ 0

   답. ②. `CEIL`은 오른쪽으로 가서 -2, `FLOOR`는 왼쪽으로 가서 -3이고 합은 -5입니다.
7. Oracle 날짜 연산에 대한 설명으로 옳은 것은?\
   ① 날짜에서 날짜를 빼면 날짜가 된다\
   ② 날짜에 날짜를 더하면 두 날짜의 합이 된다\
   ③ `SYSDATE + 1/24`는 한 시간 뒤의 시각이다\
   ④ 날짜에 숫자를 더하면 그 숫자만큼 개월이 늘어난다

   답. ③. 날짜의 1은 하루이므로 1/24는 한 시간입니다. 날짜끼리 빼면 일수(숫자)이고, 더하는 것은 오류이며, 개월을 더하는 것은 `ADD_MONTHS`입니다.
8. `ADD_MONTHS(DATE '2026-05-31', 1)`의 결과는?\
   ① 2026-06-30\
   ② 2026-07-01\
   ③ 2026-06-31\
   ④ 오류

   답. ①. 6월에는 31일이 없으므로 그 달의 마지막 날인 30일이 됩니다.
9. Oracle 함수와 SQL Server 함수의 짝이 바르지 않은 것은?\
   ① `SUBSTR` — `SUBSTRING`\
   ② `LENGTH` — `LEN`\
   ③ `SYSDATE` — `GETDATE()`\
   ④ `CEIL` — `FLOOR`

   답. ④. SQL Server에서 `CEIL`에 해당하는 것은 `CEILING`이고, `FLOOR`는 반대 방향의 다른 함수입니다.

다음 노트는 타입을 바꾸는 변환 함수와 NULL을 다루는 함수, 그리고 조건에 따라 값을 고르는 `CASE` 식입니다. 이 노트의 `TRUNC(SYSDATE)` 비교처럼 값의 모양이 어긋나 조건이 안 맞는 자리가 거기서 형변환의 문제로 다시 나옵니다.
