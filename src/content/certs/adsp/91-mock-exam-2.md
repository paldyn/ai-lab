ADsP 출제 범위에 맞춰 직접 만든 20문항입니다. 1과목 데이터의 이해 5문항, 2과목 데이터 분석 기획 5문항, 3과목 데이터 분석 10문항이고 1회와 겹치는 문제는 없습니다. 답은 문제를 눌러야 펼쳐지니 먼저 풀어 보세요.

## 1과목 데이터의 이해

1. 20년 경력의 정비 기사가 소리만 듣고 고장 부위를 짚어 내던 요령을 점검 절차서로 정리해 신입 교육에 썼습니다. 이 활동에 해당하는 지식 전환 방식은?\
   ① 공동화\
   ② 표출화\
   ③ 연결화\
   ④ 내면화

   답. ②. **암묵지**는 몸에 익어 말로 옮기기 어려운 지식이고 **형식지**는 문서나 매뉴얼처럼 밖으로 드러난 지식입니다. 암묵지를 형식지로 바꾸는 것이 **표출화**(externalization)라 절차서로 옮긴 이 사례가 여기에 해당합니다. ①은 함께 일하며 암묵지를 암묵지로 옮기는 것, ③은 흩어진 형식지를 모아 새 형식지를 만드는 것, ④는 형식지를 익혀 자기 암묵지로 삼는 것입니다.
2. 데이터베이스의 특성에 대한 설명으로 옳지 않은 것은?\
   ① 통합된 데이터 — 같은 내용의 데이터가 중복되지 않도록 모아 둔 것이다\
   ② 변화되는 데이터 — 한 번 저장한 값은 바뀌지 않고 처음 상태를 그대로 유지한다\
   ③ 저장된 데이터 — 컴퓨터가 접근할 수 있는 저장 매체에 들어 있다\
   ④ 공용 데이터 — 여러 사용자가 서로 다른 목적으로 함께 이용한다

   답. ②. '변화되는 데이터'는 값이 고정된다는 뜻이 아니라 그 반대입니다. 데이터베이스는 삽입·삭제·갱신을 거치며 내용이 계속 달라지지만 그때그때가 하나의 정확한 상태로 유지된다는 뜻입니다. ①·③·④는 각각 통합·저장·공용의 설명으로 그대로 맞습니다.
3. OLTP와 OLAP에 대한 설명으로 옳은 것은?\
   ① OLTP는 이미 쌓인 데이터를 여러 각도로 집계해 들여다보는 작업이다\
   ② OLAP는 거래 한 건을 실시간으로 기록하고 잔액을 갱신하는 작업이다\
   ③ OLTP는 거래 처리와 갱신 중심이고, OLAP는 조회와 다차원 집계 중심이다\
   ④ OLAP는 데이터를 한 건씩 입력하고 수정하는 데 최적화되어 있다

   답. ③. **OLTP**는 은행 입금처럼 거래 한 건을 즉시 기록하고 갱신하는 처리이고, **OLAP**는 쌓인 데이터를 기간·지역·상품처럼 여러 축으로 잘라 보는 분석입니다. ①과 ④는 둘의 설명을 서로 바꾸어 놓은 것이고, ②도 OLTP가 할 일을 OLAP에 붙인 것입니다.
4. 전사 데이터 웨어하우스에 모인 데이터 가운데 마케팅 부서가 쓰는 고객·캠페인 영역만 따로 떼어 구성한 저장소는?\
   ① 데이터 마트\
   ② 데이터 레이크\
   ③ ODS\
   ④ 데이터 웨어하우스

   답. ①. **데이터 마트**는 특정 부서나 주제에 필요한 부분만 잘라 놓은 작은 데이터 웨어하우스입니다. ②는 가공하지 않은 원본을 형식 구분 없이 모아 두는 곳, ③은 운영 시스템의 데이터를 통합해 잠시 두는 중간 저장소, ④는 주제 지향·통합·시계열·비휘발의 성격을 갖춘 전사 저장소라 범위가 다릅니다.
5. 빅데이터가 가져온 변화에 대한 설명으로 옳지 않은 것은?\
   ① 필요한 데이터만 미리 골라 두던 방식에서, 일단 모아 두고 쓰임새를 나중에 찾는 방식으로 옮겨 갔다\
   ② 일부를 뽑아 조사하던 방식에서 가능한 한 데이터 전체를 다루는 방식으로 옮겨 갔다\
   ③ 원인과 결과를 밝히기가 쉬워져 상관관계에 기댄 분석은 더 이상 쓰이지 않는다\
   ④ 데이터 하나하나의 정확성보다 양이 주는 힘을 활용하는 쪽으로 무게가 옮겨 갔다

   답. ③. 흔히 꼽는 변화는 사전 처리에서 사후 처리로, 표본조사에서 전수조사로, 질에서 양으로, 인과관계에서 상관관계로 넷입니다. 인과를 밝히는 일은 여전히 어렵고 비용이 크기 때문에, 무엇이 무엇과 함께 움직이는지를 보고 먼저 대응하는 상관관계 분석이 오히려 늘었습니다. ①·②·④는 나머지 세 변화를 그대로 옮긴 설명입니다.

## 2과목 데이터 분석 기획

6. 빅데이터 분석 방법론의 계층을 큰 단위부터 순서대로 나열한 것은?\
   ① 단계 → 태스크 → 스텝\
   ② 태스크 → 단계 → 스텝\
   ③ 스텝 → 태스크 → 단계\
   ④ 단계 → 스텝 → 태스크

   답. ①. **단계**(phase)는 끝날 때 기준선으로 관리할 산출물을 내놓는 가장 큰 묶음이고, **태스크**(task)는 그 단계를 이루는 일의 단위이며, **스텝**(step)은 입력·처리·출력이 하나로 묶인 가장 작은 단위입니다. 방법론 문제는 이 세 이름의 크기 순서와 각 단계 이름을 섞어 묻는 형태로 자주 나옵니다.
7. 빅데이터 분석 방법론의 다섯 단계를 순서대로 나열한 것은?\
   ① 분석 기획 → 데이터 분석 → 데이터 준비 → 시스템 구현 → 평가 및 전개\
   ② 데이터 준비 → 분석 기획 → 데이터 분석 → 시스템 구현 → 평가 및 전개\
   ③ 분석 기획 → 데이터 준비 → 데이터 분석 → 시스템 구현 → 평가 및 전개\
   ④ 분석 기획 → 데이터 준비 → 데이터 분석 → 평가 및 전개 → 시스템 구현

   답. ③. 무엇을 왜 할지 정하고(분석 기획), 쓸 데이터를 모아 손보고(데이터 준비), 모형을 만들어 확인한 뒤(데이터 분석), 운영에 올리고(시스템 구현), 성과를 재고 넓히는(평가 및 전개) 흐름입니다. ①은 준비와 분석이 뒤집혔고, ②는 기획보다 준비가 앞섰으며, ④는 구현 전에 평가를 끝낸 셈이라 순서가 어긋납니다.
8. 다음 중 분석 거버넌스 체계의 구성 요소로 보기 어려운 것은?\
   ① 분석 기획과 과제 관리를 맡는 조직\
   ② 과제 발굴에서 관리까지 이어지는 프로세스\
   ③ 개별 분석가가 개인적으로 선호하는 통계 패키지의 종류\
   ④ 분석 결과를 공유하는 IT 시스템과 관리 대상 데이터

   답. ③. **분석 거버넌스**는 분석을 조직 차원에서 지속하기 위한 관리 체계로, 조직·프로세스·시스템·데이터와 인력 교육 및 문화를 함께 다룹니다. 어떤 패키지를 쓰는지는 담당자의 선택일 뿐 전사 관리 대상이 아닙니다. ①·②·④는 각각 조직, 프로세스, 시스템과 데이터에 해당합니다.
9. 문제 정의가 뚜렷하지 않고 쓸 만한 데이터가 있는지도 확실하지 않아, 작게 만들어 보여 주고 반응을 보며 요구사항을 다듬기로 했습니다. 이 접근에 대한 설명으로 옳지 않은 것은?\
   ① 사용자가 원하는 바를 미리 말로 다 정의하기 어려울 때 쓴다\
   ② 데이터가 실제로 쓸 만한지 시행착오를 거쳐 확인할 수 있다\
   ③ 결과를 먼저 보여 주므로 요구사항을 구체화하는 데 도움이 된다\
   ④ 요구사항이 처음부터 명확하고 변경이 거의 없는 과제에 가장 알맞다

   답. ④. **프로토타이핑**은 일단 만들어 보여 주고 반응을 받아 고쳐 나가는 접근이라, 요구사항이 처음부터 확정되어 있고 바뀌지 않는 과제에서는 굳이 쓸 이유가 없습니다. 그런 과제는 앞 단계를 확정하고 순서대로 내려가는 폭포수 방식이 어울립니다. ①~③은 이 접근을 쓰는 대표적인 이유입니다.
10. 다음 중 분석 과제를 관리할 때 고려할 주요 영역으로 보기 어려운 것은?\
    ① 분석에 쓸 데이터의 양\
    ② 분석 담당자가 소속된 부서의 조직도상 위치\
    ③ 정형과 비정형이 섞여 있는 정도인 데이터 복잡도\
    ④ 결과를 만들어 내야 하는 속도

    답. ②. 분석 과제 관리에서 흔히 꼽는 영역은 데이터 양, 데이터 복잡도, 속도, 분석 복잡도, 정확도와 정밀도 다섯입니다. 담당자의 소속은 조직 설계의 문제이지 과제 자체의 관리 항목이 아닙니다. 다섯 중 마지막은 서로 부딪히기 쉬워서, 정확도를 끌어올리려 모형을 복잡하게 만들면 결과가 들쭉날쭉해져 정밀도가 떨어지는 자리가 시험에 자주 나옵니다.

## 3과목 데이터 분석

11. 어느 공정에서 만든 부품 무게는 평균 60g, 표준편차 12g입니다. 이 공정에서 36개를 무작위로 뽑았을 때 표본평균이 64g 이상일 확률은? (표준정규분포에서 $$P(Z \ge 1) = 0.1587$$, $$P(Z \ge 2) = 0.0228$$)\
    ① 0.0228\
    ② 0.1587\
    ③ 0.3707\
    ④ 0.4772

    답. ①. **중심극한정리**는 표본 크기가 충분히 크면 표본평균의 분포가 정규분포에 가까워진다는 성질이고, 이때 표본평균의 표준편차는 $$\frac{\sigma}{\sqrt{n}}$$ 입니다. 여기서는 $$\frac{12}{\sqrt{36}} = \frac{12}{6} = 2$$ 이므로 $$z = \frac{64 - 60}{2} = 2$$ 이고, 구하는 확률은 $$P(Z \ge 2) = 0.0228$$ 입니다. ②는 표준편차를 4로 잘못 보아 $$z = 1$$ 이 된 것, ③은 표본평균의 표준편차 대신 12를 그대로 넣어 $$z \approx 0.33$$ 으로 본 것, ④는 0과 2 사이의 넓이를 그대로 답으로 적은 것입니다.
12. 어느 공장에서 상자의 불량 여부를 검사합니다. 귀무가설은 '이 상자는 정상이다'입니다. 실제로 정상인 상자를 불량이라고 판정했을 때, 이 잘못에 대한 설명으로 옳은 것은?\
    ① 1종 오류이며, 이 오류를 저지를 확률의 상한을 미리 정해 둔 값이 유의수준이다\
    ② 1종 오류이며, 이 오류의 확률을 1에서 뺀 값을 검정력이라 한다\
    ③ 2종 오류이며, 이 오류를 저지를 확률의 상한을 미리 정해 둔 값이 유의수준이다\
    ④ 2종 오류이며, 표본 크기를 늘릴수록 이 오류의 확률은 반드시 커진다

    답. ①. 참인 귀무가설을 기각하는 잘못이 **1종 오류**이고 그 확률을 $$\alpha$$ 로 씁니다. 유의수준은 이 $$\alpha$$ 를 얼마까지 감수할지 미리 정해 둔 값입니다. 거짓인 귀무가설을 기각하지 못하는 잘못은 **2종 오류**로 확률이 $$\beta$$ 이고, **검정력**은 $$1 - \beta$$ 라 2종 오류 쪽에서 나옵니다. 그래서 ②는 1종과 2종을 섞은 설명이고, ③과 ④는 오류의 종류부터 틀렸습니다.
13. 두 변수 $$x$$ 와 $$y$$ 의 공분산이 24이고 $$x$$ 의 표준편차가 6, $$y$$ 의 표준편차가 8입니다. 옳은 것은?\
    ① 상관계수는 0.5이고 $$x$$ 가 $$y$$ 의 원인임을 뜻한다\
    ② 상관계수는 3이고 두 변수는 매우 강한 양의 관계다\
    ③ 상관계수는 0.5이고 $$x$$ 의 단위를 미터에서 센티미터로 바꾸면 값이 100배가 된다\
    ④ 상관계수는 0.5이고 단순선형회귀로 적합하면 결정계수는 0.25가 된다

    답. ④. **상관계수**는 공분산을 두 변수의 표준편차로 나눈 값이라 $$r = \frac{24}{6 \times 8} = \frac{24}{48} = 0.5$$ 입니다. 설명변수가 하나인 단순선형회귀에서는 결정계수가 상관계수의 제곱이므로 $$0.5^2 = 0.25$$ 입니다. ①은 상관을 인과로 읽은 것, ②는 나누지 않고 표준편차 하나만 나눈 값이며 상관계수는 $$-1$$ 과 1 사이를 벗어날 수 없습니다. ③은 상관계수가 단위에 영향을 받지 않는다는 점을 놓친 것입니다.
14. 시계열 분석에 대한 설명으로 옳지 않은 것은?\
    ① 정상 시계열은 시점에 관계없이 평균과 분산이 일정하고, 공분산은 시차에만 의존한다\
    ② 추세가 있는 시계열은 차분으로, 시간이 갈수록 분산이 커지는 시계열은 로그 변환으로 정상화한다\
    ③ ARIMA(1, 1, 0) 모형은 원 시계열을 한 번 차분한 뒤 AR(1) 모형을 적합한 것과 같다\
    ④ 계절성이 뚜렷한 시계열은 주기가 일정하므로 이미 정상 시계열이며 별도 변환이 필요 없다

    답. ④. **정상성**은 시간이 흘러도 통계적 성질이 그대로라는 뜻입니다. 계절성이 있으면 여름과 겨울의 평균이 다르므로 시점에 따라 평균이 달라져 정상이 아니고, 보통 계절 차분으로 걷어냅니다. ③의 **ARIMA**$$(p, d, q)$$ 에서 가운데 $$d$$ 가 차분 횟수라 $$d = 1$$ 이면 한 번 차분한 뒤 $$p = 1$$ 인 자기회귀 모형을 적합하는 것과 같습니다. ①과 ②도 옳은 설명입니다.
15. k-평균 군집에서 한 군집에 $$(1, 2)$$, $$(3, 4)$$, $$(5, 4)$$, $$(7, 6)$$ 네 점이 묶였습니다. 다음 중 옳지 않은 것은?\
    ① 이 군집의 새 중심 좌표는 $$(4, 4)$$ 이다\

16. 계층적 군집에서 군집 $$A = \{a_1, a_2\}$$ 와 $$B = \{b_1, b_2\}$$ 가 있고 점 사이 거리가 $$d(a_1, b_1) = 3$$, $$d(a_1, b_2) = 5$$, $$d(a_2, b_1) = 8$$, $$d(a_2, b_2) = 6$$ 입니다. 평균연결법으로 잰 두 군집 사이 거리는?\
    ① 3\
    ② 8\
    ③ 5.5\
    ④ 22

    답. ③. **평균연결법**은 두 군집에서 점을 하나씩 짝지어 잰 모든 거리의 평균을 군집 사이 거리로 봅니다. 짝이 네 개이므로 $$\frac{3 + 5 + 8 + 6}{4} = \frac{22}{4} = 5.5$$ 입니다. ①은 가장 가까운 짝을 쓰는 최단연결법의 값, ②는 가장 먼 짝을 쓰는 최장연결법의 값이고, ④는 평균을 내지 않고 합만 구한 것입니다. 군집 안 오차제곱합의 증가량이 가장 작은 쪽을 묶는 와드연결법까지 이름과 계산 방식을 함께 묻는 형태로 나옵니다.
17. 전체 거래 2,000건 가운데 빵이 든 거래가 600건, 잼이 든 거래가 300건, 둘 다 든 거래가 240건입니다. 규칙 '빵 → 잼'의 지지도는?\
    ① 0.4\
    ② 0.8\
    ③ 2.67\
    ④ 0.12

    답. ④. **지지도**는 전체 거래 가운데 두 품목이 함께 든 거래의 비율이라 $$\frac{240}{2000} = 0.12$$ 입니다. ①은 빵을 산 사람 중 잼도 산 비율인 신뢰도 $$\frac{240}{600} = 0.4$$, ②는 방향을 뒤집은 '잼 → 빵'의 신뢰도 $$\frac{240}{300} = 0.8$$, ③은 잼의 기대신뢰도 $$\frac{300}{2000} = 0.15$$ 로 신뢰도를 나눈 향상도 $$\frac{0.4}{0.15} \approx 2.67$$ 입니다. 세 지표는 분모가 각각 전체 거래, 앞 품목 거래, 기대신뢰도로 다르므로 무엇으로 나누는지를 먼저 확인해야 합니다.
18. 이진 분류 모형을 검증 데이터에 적용했더니 실제 양성 80건 가운데 60건을 양성으로 맞혔고, 모형이 양성이라고 예측한 건수는 모두 100건이었습니다. 이 모형의 F1 점수는?\
    ① 0.60\
    ② 0.67\
    ③ 0.68\
    ④ 0.75

    답. ②. 정밀도는 양성이라 예측한 100건 중 맞힌 비율이라 $$\frac{60}{100} = 0.6$$, 재현율은 실제 양성 80건 중 잡아낸 비율이라 $$\frac{60}{80} = 0.75$$ 입니다. **F1 점수**는 이 둘의 조화평균이므로 $$\frac{2 \times 0.6 \times 0.75}{0.6 + 0.75} = \frac{0.9}{1.35} \approx 0.67$$ 입니다. ③은 산술평균 $$\frac{0.6 + 0.75}{2} = 0.675$$ 를 반올림한 값으로, 조화평균은 낮은 쪽에 더 끌리기 때문에 산술평균보다 항상 작거나 같습니다. ①과 ④는 정밀도와 재현율 자체입니다.
19. 데이터 300개로 5-겹 교차검증을 수행합니다. 옳은 것은?\
    ① 한 번에 검증에 쓰는 데이터는 60개이고 모형은 한 번만 학습한다\
    ② 한 번에 검증에 쓰는 데이터는 240개이고 모형은 다섯 번 학습한다\
    ③ 한 번에 검증에 쓰는 데이터는 60개이고 모형은 모두 다섯 번 학습한다\
    ④ 데이터를 다섯 조각으로 나누되 같은 조각을 학습과 검증에 동시에 쓴다

    답. ③. **k-겹 교차검증**은 데이터를 $$k$$ 조각으로 나눈 뒤 한 조각을 검증에, 나머지를 학습에 쓰는 일을 조각을 바꿔 가며 $$k$$ 번 되풀이하고 그 성능을 평균 냅니다. 여기서는 한 조각이 $$\frac{300}{5} = 60$$ 개이므로 검증에 60개, 학습에 240개를 쓰고 학습은 다섯 번 일어납니다. ①은 되풀이를 빠뜨렸고, ②는 학습과 검증의 크기를 바꿔 놓았으며, ④는 같은 데이터를 학습과 검증에 함께 쓰면 성능이 부풀려지므로 교차검증의 전제를 깨는 설명입니다. $$k$$ 를 데이터 개수와 같게 잡으면 한 번에 하나씩만 검증에 쓰는 LOOCV가 됩니다.
20. 다음 R 코드의 실행 결과는?

    ```r
    m <- matrix(1:6, nrow = 2)
    apply(m, 1, sum)
    ```

    ① 3 7 11\
    ② 9 12\
    ③ 21\
    ④ 1 2

    답. ②. `matrix`는 값을 열 방향으로 채우므로 1행은 1, 3, 5이고 2행은 2, 4, 6입니다. `apply`의 두 번째 인자는 어느 방향으로 함수를 적용할지 정하는 값으로 1이면 행, 2면 열입니다. 여기서는 행별 합이라 $$1 + 3 + 5 = 9$$ 와 $$2 + 4 + 6 = 12$$ 가 나옵니다. ①은 `apply(m, 2, sum)`으로 열별 합을 구한 결과, ③은 전체 합인 `sum(m)`, ④는 1열의 값입니다. 리스트나 벡터의 원소마다 함수를 적용할 때는 결과를 리스트로 돌려주는 `lapply`와 가능하면 벡터로 줄여 주는 `sapply`를 씁니다.
