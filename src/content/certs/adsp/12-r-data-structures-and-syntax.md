여기서부터 3과목 「데이터분석」입니다. 출제범위표의 첫 주요항목이 「R기초와 데이터 마트」이고, 그 첫 세부항목이 R기초입니다. **R**은 통계 계산과 그래프를 위해 만든 언어이고, 이 과목의 통계분석과 데이터 마이닝도 R의 함수와 출력으로 익히게 됩니다. 이 노트는 코드를 쓰는 쪽 — 자료 구조를 만들고, 값을 꺼내고, 함수를 부르는 문법 — 을 다룹니다. 그 코드가 찍어 내는 출력을 읽는 쪽은 다음 노트의 몫입니다. 아래 코드는 모두 R 콘솔에 그대로 붙여 넣어 돌릴 수 있는 조각이고, `#`으로 시작하는 줄은 주석입니다.

## 다섯 자료 구조

### 벡터

R의 가장 작은 단위는 **벡터**입니다. 같은 자료형의 값을 한 줄로 늘어놓은 것이고, 숫자 하나도 길이가 1인 벡터입니다. `c()`로 값을 묶어 만들고, 대입은 `<-`로 합니다.

```r
x <- c(3, 8, 1, 6)
length(x)              # 4
seq(1, 9, by = 2)      # 1 3 5 7 9
rep(1:2, times = 3)    # 1 2 1 2 1 2
rep(1:2, each = 2)     # 1 1 2 2
c(1, 2, 3, 4) + c(10, 20)   # 11 22 13 24
```

`1:4`처럼 콜론은 1씩 늘어나는 정수 벡터를 만듭니다. 마지막 줄은 길이가 다른 두 벡터를 더한 것인데, 짧은 쪽이 되풀이되어 길이를 맞춥니다. 이것을 **재사용 규칙**(recycling)이라 부르고, 긴 쪽 길이가 짧은 쪽의 배수가 아니면 경고가 뜹니다.

### 행렬과 배열

벡터에 가로세로 차원을 준 것이 **행렬**(matrix)이고, 차원을 셋 이상 준 것이 **배열**(array)입니다. 둘 다 벡터처럼 한 가지 자료형만 담습니다. 행렬은 값을 기본으로 열부터 채운다는 점을 붙잡아 둡니다.

```r
m <- matrix(1:6, nrow = 2)
##      [,1] [,2] [,3]
## [1,]    1    3    5
## [2,]    2    4    6
matrix(1:6, nrow = 2, byrow = TRUE)   # 1 2 3 / 4 5 6 으로 행부터 채운다
dim(m)                                # 2 3
a <- array(1:24, dim = c(2, 3, 4))    # 2행 3열짜리 층이 넷
```

행 방향으로 채우려면 `byrow = TRUE`를 줍니다. 두 행렬을 옆으로 붙이는 `cbind()`와 아래로 붙이는 `rbind()`도 여기서 함께 씁니다.

### 리스트와 데이터프레임

**리스트**(list)는 자료형도 길이도 다른 것들을 한데 담는 상자입니다. 숫자 벡터, 문자, 다른 리스트까지 넣을 수 있습니다. **데이터프레임**(data.frame)은 길이가 같은 벡터들을 열로 세운 리스트로, 열마다 자료형이 달라도 되고 한 열 안에서는 같아야 합니다. 행렬과 달리 열마다 다른 자료형을 담을 수 있다는 점이 둘을 가릅니다.

```r
l <- list(a = 1:3, b = "x", c = list(d = TRUE))
df <- data.frame(name = c("A", "B", "C"), score = c(90, 75, 82))
nrow(df)   # 3
ncol(df)   # 2
```

| 구조 | 차원 | 자료형 |
| --- | --- | --- |
| 벡터 | 1 | 한 가지 |
| 행렬 | 2 | 한 가지 |
| 배열 | 3 이상 | 한 가지 |
| 리스트 | 1 | 원소마다 달라도 됨 |
| 데이터프레임 | 2 | 열마다 달라도 됨 |

## 자료형과 형 변환

### 기본 자료형

벡터에 담기는 값의 종류가 **자료형**입니다. 숫자형(numeric), 정수형(integer), 문자형(character), 논리형(logical), 복소수형(complex)이 기본이고, 결측값은 `NA`로 적습니다. `class()`는 객체가 어떤 종류인지, `typeof()`는 메모리에 어떻게 저장되는지를 알려 줍니다.

```r
class(1)        # "numeric"
typeof(1)       # "double"
class(1L)       # "integer"  — 숫자 뒤 L은 정수
class("1")      # "character"
class(TRUE)     # "logical"
is.numeric(1L)  # TRUE
```

`1`은 정수처럼 보여도 실수(double)로 저장되고, 정수를 쓰려면 `1L`처럼 L을 붙입니다.

### 자동 형 변환

벡터는 한 가지 자료형만 담으므로 다른 종류를 섞으면 R이 하나로 맞춥니다. 맞추는 방향은 논리형 → 정수형 → 숫자형 → 복소수형 → 문자형이고, 더 많은 것을 표현할 수 있는 쪽으로 올라갑니다.

```r
c(1, "a", TRUE)   # "1" "a" "TRUE"  — 전부 문자형
c(1, TRUE, FALSE) # 1 1 0           — 논리형이 숫자로
sum(c(TRUE, TRUE, FALSE))   # 2
```

논리값이 숫자로 바뀌면 `TRUE`가 1, `FALSE`가 0입니다. 그래서 논리 벡터에 `sum()`을 쓰면 조건을 만족하는 개수가 나옵니다.

### 명시적 형 변환

직접 바꿀 때는 `as.` 계열 함수를 씁니다. 바꿀 수 없는 값은 `NA`가 되고 경고가 뜹니다.

```r
as.numeric("3.5")   # 3.5
as.numeric("abc")   # NA (경고)
as.integer(3.9)     # 3   — 반올림이 아니라 버림
as.logical("T")     # TRUE
as.character(10)    # "10"
```

`as.integer(3.9)`가 4가 아니라 3이라는 점, 숫자로 못 읽는 문자가 오류로 멈추지 않고 `NA`가 된다는 점을 갈라 둡니다.

## 인덱싱 문법

### 벡터와 행렬

값을 꺼낼 때는 대괄호 `[ ]`를 씁니다. R의 위치는 0이 아니라 **1부터** 셉니다. 음수 위치는 「그것만 빼고」라는 뜻이고, 논리 벡터를 넣으면 `TRUE`인 자리만 남깁니다.

```r
x <- c(3, 8, 1, 6)
x[2]          # 8
x[-2]         # 3 1 6
x[c(1, 3)]    # 3 1
x[x > 2]      # 3 8 6
m <- matrix(1:6, nrow = 2)
m[2, 3]       # 6
m[1, ]        # 1 3 5  — 쉼표 뒤를 비우면 그 행 전체
m[, 2]        # 3 4
```

행렬은 `[행, 열]`로 두 자리를 적고, 한쪽을 비우면 그 방향 전체를 가져옵니다.

### 리스트

리스트에서는 대괄호 하나와 둘이 다른 것을 돌려줍니다. `[ ]`는 원소를 담은 **리스트**를 그대로 잘라 주고, **이중대괄호** `[[ ]]`는 상자를 열어 원소 자체를 꺼냅니다. 이름이 있는 원소는 `$`로도 꺼내는데, `l$a`는 `l[["a"]]`와 같습니다.

```r
l <- list(a = 1:3, b = "x")
class(l[1])     # "list"     — 상자째
class(l[[1]])   # "integer"  — 상자를 연 속
l[[1]][2]       # 2
l$b             # "x"
```

`l[1][2]`는 원소가 하나뿐인 리스트에서 두 번째를 찾으므로 원하는 값이 안 나옵니다. 속의 값을 꺼낸 뒤 다시 대괄호를 써야 합니다.

### 데이터프레임

데이터프레임은 리스트이자 2차원 표라서 두 가지 문법을 다 씁니다. 열 하나는 `$`나 `[[ ]]`로, 행과 열을 함께 고를 때는 `[행, 열]`로 꺼냅니다.

```r
df <- data.frame(name = c("A", "B", "C"), score = c(90, 75, 82))
df$score              # 90 75 82
df[["name"]]          # "A" "B" "C"
df[2, "score"]        # 75
df[df$score > 80, "name"]   # "A" "C"
df[1, ]               # 첫 행 전체(데이터프레임)
```

마지막에서 둘째 줄처럼 행 자리에 조건을 넣으면 조건에 맞는 행만 걸러 냅니다.

## 제어문과 함수

### 조건문과 반복문

조건에 따라 갈라 갈 때는 `if`와 `else`를, 되풀이할 때는 `for`와 `while`을 씁니다. 반복을 도중에 끝내는 것이 `break`, 이번 차례만 건너뛰는 것이 `next`입니다.

```r
s <- 0
for (i in 1:6) {
  if (i %% 2 == 1) next   # 홀수는 건너뛴다
  s <- s + i
}
s          # 12  (2 + 4 + 6)

k <- 1
while (k < 20) k <- k * 3
k          # 27
```

`%%`는 나머지 연산자이고 몫은 `%/%`입니다. 벡터 전체에 조건을 한꺼번에 걸 때는 반복문 대신 `ifelse(x > 2, "큼", "작음")`처럼 씁니다.

### 사용자 정의 함수

함수는 `function(인자) { 본문 }`으로 만들고 이름에 대입해 씁니다. 인자에 `=`로 기본값을 줄 수 있고, `return()`을 안 쓰면 마지막에 계산한 값이 돌아갑니다.

```r
add <- function(x, y = 2) {
  x + y
}
add(3)        # 5
add(3, 10)    # 13
add(y = 1, x = 4)   # 5 — 이름으로 넘기면 순서는 상관없다
```

## apply 계열과 파일 입출력

### apply 계열

반복문을 쓰지 않고 함수를 한꺼번에 적용하는 함수들이 **apply 계열**입니다. 호출 꼴과 돌려주는 모양이 함수마다 다릅니다.

```r
m <- matrix(1:6, nrow = 2)
apply(m, 1, sum)                     # 9 12      — 1은 행 방향
apply(m, 2, sum)                     # 3 7 11    — 2는 열 방향
lapply(1:3, function(k) k^2)         # 리스트 [[1]] 1 [[2]] 4 [[3]] 9
sapply(1:3, function(k) k^2)         # 1 4 9     — 벡터로 단순화
tapply(c(10, 20, 30, 40), c("a", "b", "a", "b"), mean)   # a 20  b 30
```

| 함수 | 호출 꼴 | 돌려주는 것 |
| --- | --- | --- |
| apply | `apply(행렬, MARGIN, 함수)` | MARGIN 1이면 행마다, 2면 열마다의 결과 |
| lapply | `lapply(리스트나 벡터, 함수)` | 리스트 |
| sapply | `sapply(리스트나 벡터, 함수)` | 되도록 벡터나 행렬로 단순화 |
| tapply | `tapply(값, 그룹, 함수)` | 그룹마다의 결과 |

`apply`의 두 번째 인자 1과 2를 뒤바꾼 선택지, `lapply`가 벡터를 돌려준다고 적은 선택지를 가려야 합니다.

### 파일 입출력과 패키지

CSV 파일은 `read.csv()`로 읽고 `write.csv()`로 씁니다. R 객체를 그대로 저장할 때는 `saveRDS()`와 `readRDS()`를 씁니다. 패키지는 한 번 `install.packages()`로 설치한 뒤, 쓸 때마다 `library()`로 불러옵니다.

```r
write.csv(df, "scores.csv", row.names = FALSE)
df2 <- read.csv("scores.csv", header = TRUE)
saveRDS(df, "scores.rds")
df3 <- readRDS("scores.rds")
install.packages("reshape2")   # 설치는 한 번
library(reshape2)              # 불러오기는 세션마다
```

`row.names = FALSE`를 빼면 행 번호가 첫 열로 함께 저장되어, 다시 읽을 때 쓸모없는 열이 하나 생깁니다. 설치와 불러오기를 혼동해 「`library()`로 패키지를 내려받는다」고 적은 선택지가 오답의 꼴입니다.

## 연습 문제

1. `x <- c(3, 8, 1, 6)`일 때 `x[-2]`의 결과는?\
   ① 8\
   ② 3 1 6\
   ③ 3 8\
   ④ 1 6

   답. ②. 음수 위치는 그 자리만 빼고 나머지를 돌려줍니다.
2. `m <- matrix(1:6, nrow = 3)`일 때 `m[3, 2]`의 값은?\
   ① 3\
   ② 4\
   ③ 5\
   ④ 6

   답. ④. 열부터 채우므로 첫 열이 1 2 3, 둘째 열이 4 5 6이고, 3행 2열은 6입니다.
3. `class(c(2, "b", FALSE))`의 결과는?\
   ① "numeric"\
   ② "logical"\
   ③ "character"\
   ④ "list"

   답. ③. 섞인 자료형 가운데 가장 위인 문자형으로 맞춰집니다.
4. `l <- list(p = 4:6, q = "z")`일 때 값 5를 꺼내는 코드는?\
   ① `l[1][2]`\
   ② `l[[1]][2]`\
   ③ `l[2]`\
   ④ `l$q[2]`

   답. ②. `l[[1]]`이 4 5 6을 꺼내고 그 두 번째가 5입니다. ①은 리스트를 자른 것이라 두 번째 원소가 없습니다.
5. `m <- matrix(1:6, nrow = 2)`일 때 `apply(m, 2, sum)`의 결과는?\
   ① 9 12\
   ② 3 7 11\
   ③ 21\
   ④ 6 15

   답. ②. 열은 (1, 2), (3, 4), (5, 6)이라 합이 3, 7, 11입니다. MARGIN이 1이었다면 행의 합 9, 12입니다.
6. 다음 함수에서 `f(7)`의 값은?\
   `f <- function(n) { s <- 0; for (i in 1:n) if (i %% 3 == 0) s <- s + i; s }`

   답. 9. 1부터 7까지에서 3으로 나누어떨어지는 3과 6을 더합니다.
7. `as.integer(4.7)`의 결과와 `as.numeric("x1")`의 결과를 짝지은 것은?\
   ① 5, 오류로 멈춤\
   ② 4, NA\
   ③ 5, NA\
   ④ 4, 1

   답. ②. 정수 변환은 버림이고, 숫자로 읽을 수 없는 문자는 경고와 함께 NA가 됩니다.
