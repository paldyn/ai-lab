앞 노트에서 과제를 찾아 하나씩 정의했다면, 이 노트는 그렇게 모인 과제 여럿을 조직 전체의 계획으로 묶고 그 계획이 한 번으로 끝나지 않게 받치는 틀을 다룹니다. 앞쪽 절반이 「무엇을 먼저 할까」이고 뒤쪽 절반이 「그것을 계속 할 수 있는 조직인가」입니다. 둘 다 축 두 개를 교차해 네 칸을 만드는 틀이라, 축이 무엇인지만 정확히 잡으면 칸의 이름은 따라옵니다.

## 마스터 플랜 수립

### 수립 절차

**분석 마스터 플랜**은 조직이 해야 할 분석 과제 전체를 언제, 어떤 순서로, 어디까지 할지 적은 중장기 계획입니다. 과제 하나를 다루는 과제 정의서와 달리 과제 여럿의 관계와 차례를 다룹니다. 절차는 네 걸음입니다.

1. 과제 도출 — 하향식·상향식으로 찾은 후보를 모은다
2. 우선순위 평가 — 무엇을 먼저 할지 점수를 매긴다
3. 적용 범위와 방식 결정 — 어디까지, 어떤 형태로 할지 정한다
4. 이행 로드맵 수립 — 정한 차례를 시간 위에 펼친다

### 우선순위 평가 기준

둘째 걸음에서 보는 것이 셋입니다. 조직의 전략 목표에 얼마나 맞닿는가를 보는 **전략적 중요도**, 들인 돈에 비해 얼마나 돌아오는가를 보는 비즈니스 성과와 ROI, 그리고 지금 가진 데이터·기술·인력으로 해낼 수 있는가를 보는 실행 용이성입니다. 셋째 걸음의 적용 범위와 방식은 다른 셋을 봅니다 — 업무 내재화 적용 수준, 분석 데이터 적용 수준, 기술 적용 수준.

| 걸음 | 묻는 것 | 보는 요소 |
| --- | --- | --- |
| 우선순위 평가 | 무엇을 먼저 할까 | 전략적 중요도, 비즈니스 성과와 ROI, 실행 용이성 |
| 적용 범위와 방식 | 어디까지 할까 | 업무 내재화, 분석 데이터, 기술 적용 수준 |

두 묶음이 셋씩이라 섞이기 쉽습니다. 「업무 내재화 적용 수준은 우선순위 평가 요소다」는 두 묶음을 섞은 틀린 문장입니다. 「먼저」를 묻는 것과 「어디까지」를 묻는 것으로 가르면 헷갈리지 않습니다.

## ROI와 포트폴리오

### 3V와 4V

우선순위를 한 번 더 좁히는 틀이 투자 대비 효과, 곧 ROI입니다. 빅데이터의 특성 **3V**(Volume·Variety·Velocity)는 데이터를 모으고 저장하고 처리하는 데 돈이 드는 이유라 투자비용 쪽에 서고, 여기에 네 번째 V인 Value를 더한 것이 **4V**입니다. Value는 그렇게 해서 얻는 것이므로 비즈니스 효과 쪽입니다.

이 갈림이 곧 평가의 두 축으로 이어집니다. 투자비용이 크면 해내기 어려우므로 3V는 **난이도**로, 효과가 크면 지금 해야 하므로 Value는 **시급성**으로 갑니다. 시급성은 전략적 중요도와 목표 가치(KPI)로, 난이도는 데이터 획득·가공·저장 비용과 조직의 분석 수준으로 판단합니다.

### 난이도-시급성 포트폴리오

두 축을 교차하면 과제를 올려놓는 네 칸이 나옵니다. 이것이 **포트폴리오 사분면**입니다.

| 시급성 | 난이도 | 차례 |
| --- | --- | --- |
| 현재 | 쉬움 | 어느 기준이든 가장 먼저 |
| 현재 | 어려움 | 시급성이 기준이면 둘째 |
| 미래 | 쉬움 | 난이도가 기준이면 둘째 |
| 미래 | 어려움 | 어느 기준이든 가장 나중 |

맨 앞과 맨 뒤는 고정이고 가운데 둘만 기준에 따라 바뀝니다. 교재 그림의 로마 숫자는 축을 어느 방향으로 그렸느냐에 따라 달라지므로 숫자보다 「현재·쉬움이 먼저, 미래·어려움이 나중」이라는 조합으로 잡아 둡니다. 지문이 로마 숫자로 묻는다면 함께 주어진 그림의 축 방향을 먼저 읽습니다.

칸은 고정되지 않습니다. 데이터를 새로 확보하거나 범위를 줄이면 난이도가 내려가 「현재·어려움」이 「현재·쉬움」으로 옮겨 가고, 그러면 곧바로 첫 차례가 됩니다. 어려운 과제를 버리지 않고 목록에 남겨 두는 이유가 이것입니다.

## 이행 계획 로드맵

### 세 단계

**이행 로드맵**은 정해진 차례를 시간 축에 얹은 것이고 세 단계를 밟습니다.

1. 데이터 분석 체계 도입 — 분석 기회를 발굴하고 과제를 정의해 계획을 세운다
2. 데이터 분석 유효성 검증 — 파일럿으로 돌려 효과를 확인한다
3. 데이터 분석 확산 및 고도화 — 검증된 것을 업무에 통합하고 넓힌다

가운데 검증 단계가 핵심입니다. 곧장 전사로 퍼뜨리지 않고 작은 범위에서 효과를 확인하는 관문을 두고, 여기서 효과가 안 나오면 과제를 접거나 다시 정의합니다.

### 세부 이행 계획

단계마다 추진 과제, 데이터, 시스템 세 갈래로 세부 계획을 적습니다. 그리고 분석 과제의 일정은 폭포수처럼 한 번에 끝까지 짜지 않습니다. 데이터 수집과 확보는 순차로 진행하되 분석과 모델링은 여러 번 반복하는 혼합형으로 짜는 것이 표준 답입니다 — 모델 성능이 목표에 닿을 때까지 몇 번 돌지 미리 알 수 없기 때문입니다.

## 분석 거버넌스

### 다섯 구성 요소

**분석 거버넌스**는 분석을 한 번 하고 끝내지 않고 조직 안에서 계속 돌게 하는 관리 체계입니다. 다섯 요소로 이뤄집니다.

| 요소 | 담는 것 |
| --- | --- |
| Organization | 분석 기획·관리와 추진을 맡는 조직 |
| Process | 과제 기획과 운영의 절차 |
| System | 분석 관련 IT 시스템과 프로그램 |
| Data | 데이터 거버넌스 |
| Human Resource | 분석 교육과 마인드 육성 |

사람 쪽 요소인 교육의 목표는 도구 사용법이 아니라 데이터로 무엇을 물어야 하는지 아는 역량입니다. 전담 인력만이 아니라 현업 임직원 모두에게 기본 소양을 붙이는 것까지 여기에 듭니다.

### 데이터 거버넌스와 변화 관리

다섯 가운데 Data 요소를 따로 떼어 부르는 이름이 **데이터 거버넌스**입니다. 전사 데이터의 표준을 정하고 그 표준이 지켜지게 관리하는 체계로, 데이터 표준화(표준 용어와 명명 규칙, 메타데이터와 데이터 사전), 데이터 관리 체계, 데이터 저장소 관리, 표준화 활동 네 가지를 합니다. 빅데이터 환경에서는 데이터의 양이 많아 전부를 같은 강도로 관리할 수 없으므로 산업·데이터 유형별로 적정한 보존 기간을 정하는 일이 더해집니다.

분석 문화가 자리 잡게 하는 일은 교육보다 **변화 관리**로 다룹니다. 분석 결과를 실제 의사결정에 쓰는 습관이 붙어야 문화가 되는데, 그것은 강의로 생기지 않고 업무 방식이 바뀌어야 생기기 때문입니다.

## 준비도와 성숙도

### 분석 준비도

거버넌스를 세우기 전에 조직이 지금 어디에 서 있는지 잽니다. **분석 준비도**는 분석을 할 준비가 됐는가를 재는 틀로, 여섯 영역을 봅니다 — 분석 업무 파악, 인력 및 조직, 분석 기법, 분석 데이터, 분석 문화, IT 인프라. 영역마다 세부 항목을 점수로 매기고, 정한 수준을 넘으면 도입할 준비가 됐다고 봅니다.

### 성숙도 네 단계

**분석 성숙도**는 이미 얼마나 깊이 쓰고 있는가를 재는 틀입니다. 준비도가 갖춘 것을 본다면 성숙도는 쓰는 정도를 봅니다. 비즈니스 부문, 조직·역량 부문, IT 부문 셋을 진단하고 네 단계로 매깁니다.

| 단계 | 모습 |
| --- | --- |
| 도입 | 분석을 시작해 환경과 시스템을 구축한다 |
| 활용 | 분석 결과를 실제 업무에 적용한다 |
| 확산 | 전사 차원에서 분석을 관리하고 공유한다 |
| 최적화 | 분석을 진화시켜 혁신과 성과 향상에 기여한다 |

### 사분면 분석

준비도와 성숙도를 교차하면 조직의 현재 위치가 네 유형으로 갈립니다. 이 **사분면 분석**이 거버넌스 체계를 어느 방향으로 세울지 정하는 출발점입니다.

| | 성숙도 낮음 | 성숙도 높음 |
| --- | --- | --- |
| 준비도 낮음 | 준비형 | 정착형 |
| 준비도 높음 | 도입형 | 확산형 |

헷갈리는 것은 도입형과 정착형입니다. 도입형은 갖춘 것은 충분한데 아직 안 쓰는 조직이라 바로 도입하면 되고, 정착형은 갖춘 것은 모자란데 이미 쓰고 있는 조직이라 부족한 준비를 채워 정착시키는 것이 과제입니다. 이름이 「다음에 할 일」을 가리킨다고 읽으면 풀립니다.

## 분석 조직 구조

### 세 유형

분석을 맡을 조직을 어디에 두느냐에 따라 세 유형이 있습니다.

| 유형 | 배치 | 강점 | 약점 |
| --- | --- | --- | --- |
| 집중형 | 전사 분석 전담 조직이 과제를 모두 맡는다 | 전략적 중요도로 우선순위를 정해 밀어붙일 수 있다 | 현업 부서의 분석 업무와 이원화·중복될 수 있다 |
| 기능형 | 별도 조직 없이 각 현업 부서가 직접 분석한다 | 업무를 잘 아는 사람이 분석한다 | 부서 최적화에 그쳐 전사 관점의 과제를 못 다룬다 |
| 분산형 | 전담 인력을 현업 부서에 나눠 배치한다 | 전사 차원의 우선순위와 현업 밀착을 함께 얻는다 | 인력을 어떻게 나누고 관리할지가 부담이다 |

### 고르는 기준

분산형은 흔히 가장 나은 구조로 소개되지만 조건이 붙습니다. 전사 조직이 과제 선정과 인력 관리를 쥐고 있어야 하고, 그러려면 분석 성숙도가 어느 정도 올라와 있어야 합니다. 준비형 조직이 곧바로 분산형을 택하면 흩어진 인력이 부서 일에 흡수되어 기능형과 다를 바가 없어집니다. 위 표의 배치·강점·약점을 유형마다 붙여 두면, 설명에서 이름을 찾든 약점에서 구조를 찾든 같은 표로 풀립니다.

## 연습 문제

1. 분석 마스터 플랜의 우선순위 평가 요소가 아닌 것은?\
   ① 전략적 중요도\
   ② 비즈니스 성과와 ROI\
   ③ 실행 용이성\
   ④ 업무 내재화 적용 수준

   답. ④. 업무 내재화 적용 수준은 분석 데이터·기술 적용 수준과 함께 적용 범위와 방식을 정할 때 보는 요소입니다. 우선순위는 「먼저」를, 적용 범위는 「어디까지」를 묻습니다.

2. ROI 관점에서 난이도와 시급성에 대응하는 것을 바르게 짝지은 것은?\
   ① 난이도 – Value, 시급성 – Volume·Variety·Velocity\
   ② 난이도 – Volume·Variety·Velocity, 시급성 – Value\
   ③ 난이도 – Volume·Value, 시급성 – Variety·Velocity\
   ④ 난이도와 시급성 모두 4V 전체

   답. ②. 3V는 데이터를 다루는 데 드는 투자비용이라 난이도로 가고, Value는 비즈니스 효과라 시급성으로 갑니다.

3. 한 조직이 우선순위 평가 요소에 가중치를 전략적 중요도 0.5, 비즈니스 성과와 ROI 0.3, 실행 용이성 0.2로 두고 5점 척도로 과제 셋을 매겼다. 과제 A는 (4, 3, 2), B는 (3, 4, 4), C는 (5, 1, 2)이다. 가중 점수가 높은 차례는?\
   ① A → B → C\
   ② B → A → C\
   ③ C → A → B\
   ④ B → C → A

   답. ②. A는 $$0.5 \times 4 + 0.3 \times 3 + 0.2 \times 2 = 2.0 + 0.9 + 0.4 = 3.3$$, B는 $$1.5 + 1.2 + 0.8 = 3.5$$, C는 $$2.5 + 0.3 + 0.4 = 3.2$$ 입니다. 전략적 중요도가 가장 높은 C가 ROI 점수가 낮아 마지막으로 밀린다는 점이 요점입니다.

4. 우선순위 기준을 난이도에 둘 때, 과제 차례로 옳은 것은?\
   ① 현재·쉬움 → 현재·어려움 → 미래·쉬움 → 미래·어려움\
   ② 현재·쉬움 → 미래·쉬움 → 현재·어려움 → 미래·어려움\
   ③ 현재·어려움 → 현재·쉬움 → 미래·쉬움 → 미래·어려움\
   ④ 미래·쉬움 → 현재·쉬움 → 현재·어려움 → 미래·어려움

   답. ②. 맨 앞(현재·쉬움)과 맨 뒤(미래·어려움)는 기준과 무관하게 고정입니다. 난이도를 앞세우면 쉬운 미래 과제가 어려운 현재 과제보다 앞섭니다. ①은 시급성을 기준으로 할 때의 차례입니다.

5. 한 조직이 준비도 여섯 영역을 5점 척도로 3.5, 4.0, 3.0, 4.5, 3.5, 3.5로, 성숙도 세 부문을 2.0, 2.5, 2.0으로 받았다. 두 값 모두 평균 3.0 이상을 「높음」으로 본다면 이 조직의 유형은?\
   ① 준비형\
   ② 도입형\
   ③ 정착형\
   ④ 확산형

   답. ②. 준비도 평균은 $$22 \div 6 \approx 3.67$$ 로 높음이고, 성숙도 평균은 $$6.5 \div 3 \approx 2.17$$ 로 낮음입니다. 준비는 됐는데 아직 쓰지 않는 조직이 도입형입니다. 성숙도만 높은 정착형과 뒤바꾸는 것이 가장 흔한 실수입니다.

6. 「전사 분석 조직이 모든 과제를 맡아 우선순위를 정하고 추진하지만, 현업 부서에도 자체 분석 인력이 있어 같은 분석이 두 번 이뤄지는 일이 잦다.」 이 조직 구조는?\
   ① 집중형\
   ② 기능형\
   ③ 분산형\
   ④ 확산형

   답. ①. 전담 조직이 과제를 모두 쥐는 것이 집중형이고, 현업과의 이원화·중복이 그 약점입니다. ④는 조직 구조가 아니라 준비도·성숙도 사분면의 유형입니다.

7. 서술형 연습입니다. 준비도는 낮지만 일부 부서가 이미 분석 결과를 업무에 쓰고 있는 제조사가 전사 분석을 넓히려 합니다. 이 조직의 사분면 유형을 짚고, 거버넌스 다섯 요소 가운데 먼저 손댈 것 둘과 알맞은 조직 구조를 5줄 이내로 쓰시오.

   답. 채점 기준은 셋입니다. (1) 유형을 짚었는가 — 준비도 낮음, 성숙도 높음이므로 정착형입니다. 이미 쓰고 있으니 과제는 모자란 준비를 채워 정착시키는 것입니다. (2) 요소를 근거와 함께 골랐는가 — 부서마다 따로 쓰는 데이터를 맞추는 Data(데이터 표준화와 메타데이터 관리)와, 흩어진 활용을 전사 절차로 묶는 Process가 표준 답이고, 전 임직원의 기본 소양을 붙이는 Human Resource를 드는 답도 근거가 있으면 인정합니다. (3) 조직 구조를 조건과 함께 적었는가 — 준비가 모자란 상태에서 분산형으로 가면 인력이 부서에 흡수되므로, 먼저 집중형으로 과제 선정과 표준을 쥔 뒤 성숙도가 받쳐 주면 분산형으로 옮기는 단계적 답이 가장 좋습니다. 유형만 짚고 요소와 구조를 적지 않으면 배점의 3분의 1만 붙습니다.
