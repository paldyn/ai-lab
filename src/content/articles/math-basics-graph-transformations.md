> **평행이동**은 곡선을 모양 그대로 옮기는 것입니다. $$y = f(x-a) + k$$ 는 오른쪽으로 $$a$$, 위로 $$k$$ 만큼 옮긴 곡선입니다.
>
> **역함수**는 입력과 출력을 맞바꾼 함수입니다. 그래프가 $$y = x$$ 에 대해 대칭이고, 일대일일 때만 생깁니다.
>
> **점근선**은 곡선이 한없이 가까워지지만 닿지는 않는 직선입니다.

[지난 글](/articles/math-basics-functions-and-graphs)에서 곡선 다섯을 표로 채워 그렸습니다. 이 글은 그 다섯 말고 새 곡선을 그리지 않습니다.

대신 이미 그린 곡선 하나를 **옮기고 늘이고 뒤집어** 새 곡선을 얻습니다. 규칙은 몇 개 안 되고, 그것만 익히면 표를 다시 채울 일이 없습니다.

## 위아래로 옮기기 — y = f(x) + k

가장 쉬운 것부터 봅니다. 출력이 나온 뒤에 $$k$$ 를 더하니 점이 통째로 $$k$$ 만큼 올라갑니다.

$$y = f(x) + k \;\to\; \text{위로 } k$$

$$k$$ 가 음수면 내려갑니다. $$y = x^2 - 3$$ 은 $$y=x^2$$ 을 아래로 3만큼 내린 것이고, 꼭짓점이 $$(0,0)$$ 에서 $$(0,-3)$$ 으로 갑니다.

**여기까지는 예상대로입니다.** 문제는 좌우입니다.

## 좌우로 옮기기 — y = f(x − a)

$$y = (x-2)^2$$ 을 봅니다. $$-2$$ 가 있으니 왼쪽으로 갈 것 같은데, 실제로는 **오른쪽**으로 갑니다.

![y=x² 과 y=(x−2)² 을 겹쳐 그리고 같은 값이 나오는 자리를 표시한 그림](/assets/posts/math-basics-graph-transformations-shift.svg)

**대입으로 읽으면 헷갈리지 않습니다.** 원래 곡선 $$y=x^2$$ 은 $$x=1$$ 에서 값이 1이었습니다. 새 곡선이 같은 1을 내놓으려면 괄호 안이 1이 되어야 하므로 $$x-2=1$$, 즉 $$x=3$$ 입니다.

**같은 값을 얻는 자리가 2만큼 뒤로 밀렸습니다.** 그것이 곧 그래프가 오른쪽으로 2 간다는 말입니다.

$$y = f(x-a) \;\to\; \text{오른쪽으로 } a$$

$$y = f(x+1)$$ 은 $$a=-1$$ 이므로 왼쪽으로 1입니다.

**괄호 안에 든 것은 늘 예상과 반대로 움직입니다.** 여기가 가장 많이 틀리는 자리이므로, 헷갈릴 때마다 "괄호 안이 0이 되는 $$x$$ 는 얼마인가"를 물어보세요. $$y=(x-2)^2$$ 은 $$x=2$$ 에서 괄호가 0이 되고, 거기가 새 꼭짓점입니다.

## 세로로 늘이기 — y = cf(x)

출력에 $$c$$ 를 곱하니 모든 점의 높이가 $$c$$ 배가 됩니다.

$$y = 3f(x) \;\to\; \text{세로로 3배}$$

$$c$$ 가 0과 1 사이면 납작해집니다. $$y = \frac{1}{2}x^2$$ 은 $$y=x^2$$ 보다 완만합니다.

**높이만 바뀌고 가로 위치는 그대로입니다.** $$y=0$$ 인 자리, 즉 $$x$$ 축과 만나는 점은 몇 배를 해도 0이라 움직이지 않습니다.

## 가로로 늘이기 — y = f(cx)

이번에는 입력 쪽입니다. 좌우 이동과 같은 이유로 예상과 반대가 됩니다.

$$y = f(2x)$$

원래 곡선이 $$x=6$$ 에서 내놓던 값을 새 곡선이 내놓으려면 $$2x=6$$, 즉 $$x=3$$ 이어야 합니다. **자리가 절반으로 당겨졌습니다.**

$$y = f(cx) \;\to\; \text{가로로 } \frac{1}{c} \text{ 배}$$

$$c=2$$ 면 폭이 절반으로 좁아지고, $$c=\frac{1}{2}$$ 이면 두 배로 넓어집니다. **세로는 곱한 만큼, 가로는 곱한 것의 역수만큼**입니다.

## 뒤집기 — y = −f(x) 와 y = f(−x)

부호를 어디에 붙이느냐로 갈립니다.

$$y = -f(x)$$ 는 출력의 부호를 바꿉니다. 위에 있던 것이 아래로 가므로 **$$x$$ 축을 거울로 뒤집은 모습**입니다.

$$y = f(-x)$$ 는 입력의 부호를 바꿉니다. 오른쪽에서 쓰던 값을 왼쪽에서 쓰게 되므로 **$$y$$ 축을 거울로 뒤집은 모습**입니다.

$$y=\sqrt{x}$$ 로 보면 분명합니다. $$y=-\sqrt{x}$$ 는 오른쪽 아래로 뻗고, $$y=\sqrt{-x}$$ 는 왼쪽 위로 뻗습니다. 정의역 자체가 $$x \le 0$$ 으로 옮겨 갑니다.

## 겹칠 때는 순서가 결과를 바꾼다

변형을 두 번 하면 순서를 따져야 합니다. $$y=x^2$$ 에 "위로 1"과 "세로 2배"를 해 봅니다.

먼저 올리고 늘이면 $$y = 2(x^2+1) = 2x^2 + 2$$ 입니다.

먼저 늘이고 올리면 $$y = 2x^2 + 1$$ 입니다.

**다릅니다.** 나중에 한 확대가 앞서 더한 1까지 함께 늘렸기 때문입니다.

그래서 식을 볼 때는 **괄호가 정한 순서**를 그대로 따릅니다. $$y = -\dfrac{1}{2}(x+2)^2 + 3$$ 이면 안쪽부터 이렇게 읽습니다.

| 순서 | 무엇이 붙었나 | 하는 일 |
| --- | --- | --- |
| 1 | $$(x+2)$$ | 왼쪽으로 2 |
| 2 | $$\dfrac{1}{2} \times$$ | 세로로 절반 |
| 3 | 앞의 $$-$$ | $$x$$ 축 대칭으로 뒤집기 |
| 4 | $$+3$$ | 위로 3 |

꼭짓점은 $$(0,0)$$ 에서 $$(-2, 3)$$ 으로 가고, 뒤집혔으므로 위로 볼록한 모양이 됩니다.

## 대칭 세 가지

변형을 정리하면 대칭이 셋 남습니다.

| 대칭 | 식에서 바뀌는 것 | 점 $$(a,b)$$ 가 가는 곳 |
| --- | --- | --- |
| $$y$$ 축 대칭 | $$x \to -x$$ | $$(-a, b)$$ |
| 원점 대칭 | $$x \to -x$$, $$y \to -y$$ | $$(-a, -b)$$ |
| $$y=x$$ 대칭 | $$x$$ 와 $$y$$ 를 맞바꾼다 | $$(b, a)$$ |

$$y$$ 축 대칭인 함수, 즉 $$f(-x)=f(x)$$ 인 함수를 **우함수** 라 하고, 원점 대칭인 $$f(-x)=-f(x)$$ 를 **기함수** 라 합니다. $$y=x^2$$ 과 $$y=|x|$$ 가 우함수, $$y=x$$ 와 $$y=1/x$$ 가 기함수입니다. 이름만 붙여 두고 지나갑니다.

## y = x 대칭 자리가 역함수의 자리다

셋째 대칭은 다른 둘과 격이 다릅니다. **함수를 거꾸로 돌리는 일**이기 때문입니다.

$$f(x) = \frac{x}{2} + 1$$ 은 2로 나누고 1을 더합니다. 거꾸로 하면 1을 빼고 2를 곱합니다. 그 거꾸로 하는 함수를 **역함수** 라 하고 $$f^{-1}$$ 로 적습니다.

![y=x/2+1 과 그 역함수가 y=x 에 대해 대칭인 그림](/assets/posts/math-basics-graph-transformations-inverse.svg)

구하는 절차는 두 줄입니다.

$$y = \frac{x}{2} + 1$$

**하나 — $$x$$ 에 대해 풉니다.** [16번 글](/articles/math-basics-linear-equations)의 등식의 성질 그대로입니다.

$$y - 1 = \frac{x}{2} \;\to\; x = 2y - 2$$

**둘 — 문자를 맞바꿉니다.** 입력을 늘 $$x$$ 라 부르기로 했으므로 이름만 바꿔 답니다.

$$y = 2x - 2$$

그래프에서는 **$$y=x$$ 에 비친 모습**입니다. 점 $$(4,3)$$ 이 $$(3,4)$$ 로 갑니다. 좌표를 맞바꾸는 것이 곧 $$y=x$$ 에 대한 대칭이기 때문입니다.

### 아무 함수나 역함수를 갖지는 않는다

$$f(x)=x^2$$ 을 거꾸로 돌려 봅니다. 4에서 출발하면 2로 가야 할지 $$-2$$ 로 가야 할지 정해지지 않습니다. **출력 하나에 입력이 둘**이라 거꾸로 돌리면 함수가 아니게 됩니다.

지난 글의 세로선 판정법을 $$y=x$$ 에 비춰 보면 이번에는 **가로선**입니다. 가로선 하나가 그래프를 두 번 이상 만나면 역함수가 없습니다.

**서로 다른 입력이 서로 다른 출력으로 가는 함수**를 일대일이라 하고, 역함수는 그때만 생깁니다. $$y=x^2$$ 도 정의역을 $$x \ge 0$$ 으로 줄이면 일대일이 되고, 그 역함수가 $$y=\sqrt{x}$$ 입니다.

## 점근선 — 그림에서만

$$y = \frac{1}{x}$$ 을 오른쪽으로 2, 위로 3 옮기면 이렇게 됩니다.

$$y = \frac{1}{x-2} + 3$$

원래 곡선은 $$x=0$$ 과 $$y=0$$ 이라는 두 직선에 한없이 가까워지면서 닿지는 않았습니다. 옮겼으니 그 두 직선도 함께 옮겨 갑니다. $$x=2$$ 와 $$y=3$$ 입니다.

이렇게 **가까이 가지만 닿지 않는 직선**을 점근선이라 합니다. 여기서는 그림에서 눈으로 확인하는 데까지만 씁니다. "한없이 가까워진다"를 식으로 정확히 적는 것은 28번 · 극한의 몫입니다.

**점근선을 먼저 찾으면 그래프의 자리가 정해집니다.** 분수 꼴을 만나면 분모가 0이 되는 $$x$$ 와 뒤에 더해진 수를 먼저 보세요.

## 연습 문제

2번 묶음은 **단계마다 한 번씩 그려 보세요.** 마지막 그림만 그리면 순서를 익히지 못합니다.

### 연습 1 — 어느 곡선을 어떻게 한 것인가 여덟 문제

괄호 안에 적은 곡선에서 출발했습니다. 무엇을 한 것입니까?

1. $$y = x^2 + 3$$ &nbsp;($$y=x^2$$ 에서)

   답. 위로 3만큼 옮긴 것. 꼭짓점이 $$(0,3)$$ 입니다.
2. $$y = \sqrt{x-4}$$ &nbsp;($$y=\sqrt{x}$$ 에서)

   답. 오른쪽으로 4만큼. 근호 안이 0이 되는 자리가 4로 옮겨 갑니다.
3. $$y = |x+1|$$ &nbsp;($$y=|x|$$ 에서)

   답. 왼쪽으로 1만큼. 꺾이는 점이 $$(-1, 0)$$ 입니다.
4. $$y = 3x^2$$ &nbsp;($$y=x^2$$ 에서)

   답. 세로로 3배 늘인 것. 원점을 지나는 것은 그대로입니다.
5. $$y = \sqrt{2x}$$ &nbsp;($$y=\sqrt{x}$$ 에서)

   답. 가로로 $$\dfrac{1}{2}$$ 배. $$y=2$$ 가 나오던 자리가 4에서 2로 당겨집니다.
6. $$y = -\dfrac{1}{x}$$ &nbsp;($$y=\dfrac{1}{x}$$ 에서)

   답. 출력의 부호를 바꿨으므로 $$x$$ 축 대칭입니다.
7. $$y = \dfrac{1}{-x}$$ &nbsp;($$y=\dfrac{1}{x}$$ 에서)

   답. 입력의 부호를 바꿨으므로 $$y$$ 축 대칭입니다. 정리하면 $$-\dfrac{1}{x}$$ 이라 6번과 그래프가 같습니다. $$y=1/x$$ 가 기함수여서 두 뒤집기의 결과가 겹칩니다.
8. $$y = -\sqrt{-x}$$ &nbsp;($$y=\sqrt{x}$$ 에서)

   답. 두 뒤집기를 함께 했으므로 원점을 중심으로 돌린 모습입니다. 왼쪽 아래로 뻗고 정의역은 $$x \le 0$$ 입니다.

### 연습 2 — 단계마다 옮겨 그리기 두 문제

1. $$y = x^2$$ 에서 출발해 $$y = -2(x-3)^2 + 1$$ 까지 단계마다 그리고, 꼭짓점과 볼록한 방향을 적으세요.

   답. 오른쪽 3 → 세로 2배 → $$x$$ 축 대칭 → 위로 1. 꼭짓점은 $$(3, 1)$$ 이고 앞에 $$-$$ 가 붙었으므로 위로 볼록합니다.
2. $$y = \dfrac{1}{x}$$ 에서 출발해 $$y = \dfrac{1}{x+1} - 2$$ 까지 그리고, 점근선 두 개를 적으세요.

   답. 왼쪽 1 → 아래로 2. 점근선은 $$x = -1$$ 과 $$y = -2$$ 입니다.

### 연습 3 — 설명을 보고 식 되쓰기 네 문제

지난 글의 다섯 곡선 중 하나를 옮겨 놓은 것입니다. 식을 쓰세요.

1. $$y=x^2$$ 과 같은 모양이고 꼭짓점이 $$(1, 2)$$ 입니다.

   답. $$y = (x-1)^2 + 2$$.
2. $$y=|x|$$ 와 같은 모양이고 꺾이는 점이 $$(-2, 0)$$ 입니다.

   답. $$y = |x+2|$$. 왼쪽으로 2 옮겼으므로 괄호 안이 $$x+2$$ 입니다.
3. $$y=\dfrac{1}{x}$$ 를 옮긴 것이고 점근선이 $$x=3$$ 과 $$y=-1$$ 입니다.

   답. $$y = \dfrac{1}{x-3} - 1$$.
4. $$y=\sqrt{x}$$ 를 옮긴 것이고 곡선이 $$(4, 1)$$ 에서 시작합니다.

   답. $$y = \sqrt{x-4} + 1$$. 근호 안이 0이 되는 자리가 4입니다.

### 연습 4 — 역함수 세 문제

1. $$f(x) = 2x - 3$$ 의 역함수를 구하고, 두 그래프가 $$y=x$$ 에 대칭인지 점 하나로 확인하세요.

   답. $$y = 2x-3$$ 을 $$x$$ 에 대해 풀면 $$x = \dfrac{y+3}{2}$$ 이고, 문자를 맞바꾸면 $$f^{-1}(x) = \dfrac{x+3}{2}$$ 입니다. $$f(3) = 3$$ 은 $$y=x$$ 위의 점이라 확인에 못 쓰므로 다른 점을 씁니다. $$f(4) = 5$$ 이므로 원래 그래프에 $$(4,5)$$ 가 있고, 역함수에 $$f^{-1}(5) = 4$$ 이므로 $$(5,4)$$ 가 있습니다. 좌표가 맞바뀌었으므로 $$y=x$$ 에 대칭입니다.
2. $$f(x) = \dfrac{x}{3} + 2$$ 의 역함수를 구하세요.

   답. $$x = 3(y-2) = 3y - 6$$ 이므로 $$f^{-1}(x) = 3x - 6$$.
3. 모든 실수에서 정의된 $$f(x) = |x|$$ 에 역함수가 있습니까? 없다면 어떻게 고치면 생깁니까?

   답. 없습니다. $$f(3) = f(-3) = 3$$ 이라 가로선 $$y=3$$ 이 그래프를 두 번 만납니다. 정의역을 $$x \ge 0$$ 으로 줄이면 식이 $$f(x)=x$$ 가 되어 일대일이 되고, 역함수는 $$y=x$$ 입니다.

## 정리

- $$y = f(x)+k$$ 는 위아래, $$y = f(x-a)$$ 는 좌우입니다. **괄호 안에 든 것은 예상과 반대로 움직입니다.**
- 헷갈리면 **괄호 안이 0이 되는 $$x$$** 를 물어보세요. 거기가 새 기준점입니다.
- $$y=cf(x)$$ 는 세로로 $$c$$ 배, $$y=f(cx)$$ 는 가로로 $$\dfrac{1}{c}$$ 배입니다.
- $$y=-f(x)$$ 는 $$x$$ 축 대칭, $$y=f(-x)$$ 는 $$y$$ 축 대칭입니다.
- 변형을 겹칠 때는 **괄호가 정한 순서**를 따릅니다. 순서를 바꾸면 결과가 달라집니다.
- **역함수는 $$y=x$$ 대칭**이고, $$x$$ 에 대해 푼 뒤 문자를 맞바꾸면 나옵니다. 일대일일 때만 생깁니다.
- 점근선은 옮긴 만큼 함께 옮겨 갑니다. 분모가 0이 되는 $$x$$ 와 뒤에 더한 수를 보면 됩니다.
