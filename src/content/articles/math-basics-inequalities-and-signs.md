[지난 글](/articles/math-basics-linear-equations)에서 $$2x + 3 = 11$$ 을 풀어 $$x=4$$ 하나를 얻었습니다. 이번에는 그 자리에 부등호를 놓습니다.

$$2x + 3 < 11$$

$$x=4$$ 는 이제 답이 아닙니다. $$x=3$$ 도, $$x=0$$ 도, $$x=-100$$ 도 참입니다. **답이 하나가 아니라 덩어리로 나오는 것**이 부등식의 첫 번째 차이입니다.

## 부등호 넷 — 읽기만 확인하고 넘어갑니다

[9번 글](/articles/math-basics-symbol-glossary)에서 소리를 이미 줬습니다.

| 기호 | 읽는 법 | 뜻 |
| --- | --- | --- |
| $$a < b$$ | a는 b보다 작다 | 같은 것은 안 된다 |
| $$a > b$$ | a는 b보다 크다 | 같은 것은 안 된다 |
| $$a \le b$$ | a는 b보다 작거나 같다 | 같아도 된다 |
| $$a \ge b$$ | a는 b보다 크거나 같다 | 같아도 된다 |

밑줄이 붙으면 **경계를 포함합니다.** 이 차이가 답을 적을 때 계속 따라다닙니다.

## 해는 값이 아니라 구간이다

$$2x + 3 < 11$$ 의 해는 $$x < 4$$ 입니다. 이것을 수직선에 칠하면 눈에 들어옵니다.

![부등식의 해를 수직선에 칠하고 구간 기호로 적은 그림](/assets/posts/math-basics-inequalities-and-signs-intervals.svg)

경계에 찍는 점이 두 가지입니다. **속이 찬 점은 그 값을 포함**하고, **빈 점은 포함하지 않습니다.** $$\le$$ 와 $$\ge$$ 는 찬 점, $$<$$ 와 $$>$$ 는 빈 점입니다.

같은 것을 기호로 짧게 적는 방법도 있습니다.

| 부등식 | 구간 기호 |
| --- | --- |
| $$a \le x \le b$$ | $$[a, b]$$ |
| $$a < x < b$$ | $$(a, b)$$ |
| $$x \le b$$ | $$(-\infty, b]$$ |
| $$x > a$$ | $$(a, \infty)$$ |

대괄호가 찬 점, 둥근 괄호가 빈 점입니다. **$$\infty$$ 쪽은 늘 둥근 괄호입니다.** 무한대는 값이 아니라 방향이라 포함할 것 자체가 없습니다.

## 부등식의 성질 — 한 자리만 다르다

등식의 성질 넷을 그대로 가져옵니다. 셋은 아무 일도 없습니다.

$$a < b \;\Longrightarrow\; a + c < b + c$$

$$a < b \;\Longrightarrow\; a - c < b - c$$

$$a < b, \; c > 0 \;\Longrightarrow\; ac < bc$$

더하기와 빼기는 두 수를 나란히 같은 만큼 옮기는 일이라 순서가 안 바뀝니다. 양수를 곱하는 것도 둘을 같은 배율로 늘리는 일이라 그렇습니다.

문제는 음수입니다.

![2 < 5 의 양변에 −1을 곱하면 두 수가 자리를 맞바꾼다](/assets/posts/math-basics-inequalities-and-signs-flip.svg)

$$2 < 5$$ 의 양변에 $$-1$$ 을 곱해 봅니다. $$-2$$ 와 $$-5$$ 가 되는데, 수직선에서 $$-5$$ 는 $$-2$$ 보다 **왼쪽**입니다. [10번 글](/articles/math-basics-numbers-and-number-line)의 "왼쪽에 있는 수가 작다"를 그대로 읽으면 $$-2 > -5$$ 입니다.

$$a < b, \; c < 0 \;\Longrightarrow\; ac > bc$$

**음수를 곱하는 것은 수직선을 0을 기준으로 통째로 뒤집는 일**입니다. 뒤집으면 왼쪽에 있던 것이 오른쪽으로 갑니다. 나누는 것도 같습니다 — 음수로 나누는 것은 음수인 역수를 곱하는 것이니까요.

$$-2x > 6$$

양변을 $$-2$$ 로 나눕니다. 음수로 나눴으니 방향을 돌립니다.

$$x < -3$$

확인해 봅니다. $$x=-4$$ 를 넣으면 $$-2 \times (-4) = 8$$ 이고 8은 6보다 큽니다. 맞습니다. 방향을 안 돌려 $$x > -3$$ 이라 적었다면 $$x=0$$ 이 답에 들어가는데, $$0 > 6$$ 은 거짓입니다.

## 일차부등식 풀기

절차는 지난 글의 다섯 걸음 그대로입니다. **마지막에 음수로 나누는지만 살피면 됩니다.**

$$\frac{2x - 1}{3} \ge x - 2$$

양변에 3을 곱합니다. 3은 양수이므로 방향은 그대로입니다.

$$2x - 1 \ge 3x - 6$$

$$x$$ 를 왼쪽으로, 수를 오른쪽으로 이항합니다.

$$-x \ge -5$$

양변을 $$-1$$ 로 나눕니다. **여기서 돌립니다.**

$$x \le 5$$

## 연립부등식 — 나란히 칠하고 겹치는 데를 읽는다

부등식 둘을 동시에 만족하는 $$x$$ 를 찾는 것입니다.

$$3x - 1 > 5 \quad \text{그리고} \quad x + 2 \le 7$$

각각 따로 풉니다. 앞은 $$3x > 6$$ 이므로 $$x > 2$$, 뒤는 $$x \le 5$$ 입니다.

이제 수직선 하나에 둘을 나란히 칠하고 **둘 다 칠해진 구간**을 읽습니다.

$$2 < x \le 5 \quad \to \quad (2, 5]$$

왼쪽 경계는 빈 점, 오른쪽은 찬 점입니다. **두 부등식의 부등호를 각각 그대로 가져옵니다.**

![연립부등식을 수직선에 나란히 칠하기](/assets/posts/math-basics-inequalities-and-signs-system.svg)

겹치는 데가 없으면 해가 없습니다. $$x > 5$$ 와 $$x < 1$$ 을 함께 만족하는 수는 없습니다.

## 절댓값 부등식 — 거리로 읽는다

[10번 글](/articles/math-basics-numbers-and-number-line)에서 $$|a - b|$$ 가 두 수 사이의 거리라고 했습니다. 그 문장 하나로 절댓값 부등식이 풀립니다.

$$|x - 3| < 2$$

**"$$x$$ 가 3에서 거리 2보다 가깝다"** 로 읽습니다. 수직선에서 3을 중심으로 양쪽 2칸씩이므로 1과 5 사이입니다.

$$1 < x < 5$$

일반형으로 적으면 이렇습니다.

$$|x - c| < r \;\Longleftrightarrow\; c - r < x < c + r$$

부등호가 반대면 바깥쪽이 됩니다.

$$|x - c| > r \;\Longleftrightarrow\; x < c - r \;\text{또는}\; x > c + r$$

**"가깝다"는 한 덩어리, "멀다"는 두 덩어리**입니다. 그림을 한 번 그려 두면 부호를 헷갈릴 일이 없습니다.

![절댓값 부등식을 거리로 읽기](/assets/posts/math-basics-inequalities-and-signs-absolute.svg)

## 양변을 제곱해도 되는 때

근호가 든 부등식을 만나면 제곱해 없애고 싶어집니다. 그런데 제곱은 아무 때나 되는 조작이 아닙니다.

$$-5 < 2$$

참입니다. 양변을 제곱하면 $$25 < 4$$ 로 거짓이 됩니다. **음수가 끼면 제곱이 순서를 지키지 않습니다.**

$$a \ge 0, \; b \ge 0$$ 일 때만 $$a < b \Longleftrightarrow a^2 < b^2$$ 입니다. **양변이 모두 음이 아닌 것을 확인한 뒤에 제곱합니다.**

확인 없이 제곱하면 원래 식이 참이 아닌 값이 답에 섞여 들어옵니다. 이런 것을 **가짜 해**라고 부릅니다. 막는 방법은 하나입니다 — 구한 값을 **원래 식**에 도로 넣어 봅니다. 지난 글의 검산 습관이 여기서 한 번 더 값을 합니다.

## 부등식을 세우는 두 상투 수단

부등식을 푸는 것 말고 **없는 부등식을 만들어 내는** 일도 자주 합니다. 밑천은 사실상 하나입니다.

$$(\text{실수})^2 \ge 0$$

제곱은 음수가 될 수 없습니다. 등호는 안이 0일 때만 성립합니다. 여기서 출발해 원하는 모양으로 옮겨 갑니다.

$$a > 0, b > 0$$ 일 때 $$(\sqrt{a} - \sqrt{b})^2 \ge 0$$ 에서 시작합니다. 전개합니다.

$$a - 2\sqrt{ab} + b \ge 0$$

$$2\sqrt{ab}$$ 를 이항합니다.

$$a + b \ge 2\sqrt{ab}$$

**산술-기하 평균 부등식**입니다. 등호는 $$\sqrt{a} = \sqrt{b}$$ 일 때, 즉 $$a = b$$ 일 때만 성립합니다.

**등호가 언제 성립하는지를 늘 함께 적으세요.** 부등식은 "얼마나 큰가"만이 아니라 "언제 딱 맞는가"를 함께 말할 때 쓸모가 생깁니다.

이름만 적어 두고 지나가는 것이 둘 있습니다. 하나는 **삼각부등식** $$|a + b| \le |a| + |b|$$ 로, 부호로 경우를 나눠 확인하는 것은 46번 · 증명 읽는 법의 예제 자리입니다. 다른 하나는 곱과 몫의 **부호표** 인데, 초급에서 이차부등식을 푸는 자리는 23번 · 이차함수와 포물선 하나이고 그 글은 부호표가 아니라 그래프로 읽습니다.

## 연습 문제

답은 구간으로 적고, 경계가 찬 점인지 빈 점인지까지 함께 정하세요.

### 연습 1 — 일차·연립부등식 스무 문제

1. $$x + 3 > 7$$

   답. $$x > 4$$.
2. $$x - 5 \le 2$$

   답. $$x \le 7$$.
3. $$3x < 12$$

   답. 양변을 3으로 나눕니다. $$x < 4$$.
4. $$-5x > 20$$

   답. 음수로 나누므로 방향을 돌립니다. $$x < -4$$.
5. $$-x \ge 4$$

   답. $$x \le -4$$.
6. $$2x + 1 \le 9$$

   답. $$2x \le 8$$, $$x \le 4$$.
7. $$5 - 3x > 14$$

   답. $$-3x > 9$$ 이고 음수로 나누므로 $$x < -3$$.
8. $$4x - 3 \ge x + 6$$

   답. $$3x \ge 9$$, $$x \ge 3$$.
9. $$2(x - 1) < x + 5$$

   답. $$2x - 2 < x + 5$$, $$x < 7$$.
10. $$3(x + 2) \ge 5x - 4$$

    답. $$3x + 6 \ge 5x - 4$$, $$-2x \ge -10$$, 방향을 돌려 $$x \le 5$$.
11. $$\dfrac{x}{2} + 1 > 4$$

    답. $$\dfrac{x}{2} > 3$$, $$x > 6$$.
12. $$\dfrac{x - 1}{3} \le 2$$

    답. 양변에 3을 곱하면 $$x - 1 \le 6$$, $$x \le 7$$.
13. $$\dfrac{x}{2} - \dfrac{x}{3} < 1$$

    답. 양변에 6을 곱하면 $$3x - 2x < 6$$, $$x < 6$$.
14. $$-\dfrac{x + 2}{4} \ge 1$$

    답. 양변에 $$-4$$ 를 곱하면 방향이 돌아 $$x + 2 \le -4$$, $$x \le -6$$.
15. $$x > 1$$ 이고 $$x < 5$$

    답. 겹치는 구간은 $$1 < x < 5$$, 즉 $$(1, 5)$$.
16. $$x \ge -2$$ 이고 $$x \le 3$$

    답. $$-2 \le x \le 3$$, 즉 $$[-2, 3]$$.
17. $$2x + 1 > 5$$ 이고 $$x - 3 < 1$$

    답. 각각 $$x > 2$$ 와 $$x < 4$$ 이므로 $$2 < x < 4$$.
18. $$3x \le 9$$ 이고 $$-x < 1$$

    답. 각각 $$x \le 3$$ 과 $$x > -1$$ 이므로 $$-1 < x \le 3$$.
19. $$x + 4 > 2$$ 이고 $$2x \ge 10$$

    답. 각각 $$x > -2$$ 와 $$x \ge 5$$ 입니다. 뒤쪽이 앞쪽에 통째로 들어가므로 $$x \ge 5$$.
20. $$x < -2$$ 이고 $$x > 4$$

    답. 수직선에서 겹치는 데가 없습니다. 해가 없습니다.

### 연습 2 — 절댓값 부등식 다섯 문제

1. $$|x| < 3$$

   답. 0에서 거리가 3보다 가까운 수이므로 $$-3 < x < 3$$.
2. $$|x| \ge 2$$

   답. 0에서 거리가 2 이상이므로 $$x \le -2$$ 또는 $$x \ge 2$$.
3. $$|x - 1| < 4$$

   답. 1에서 거리가 4보다 가까우므로 $$-3 < x < 5$$.
4. $$|x + 2| \le 5$$

   답. $$|x - (-2)| \le 5$$ 이므로 $$-2$$ 에서 거리가 5 이하, $$-7 \le x \le 3$$.
5. $$|2x - 6| < 4$$

   답. 안을 2로 묶으면 $$2|x - 3| < 4$$, 즉 $$|x - 3| < 2$$ 이므로 $$1 < x < 5$$.

### 연습 3 — 제곱이 만드는 가짜 해 셋

각 문제에서 두 식의 해를 **따로** 구한 뒤 나란히 놓고 비교하세요.

1. $$\sqrt{x + 2} = x$$ 를 양변 제곱해 풀고, 나온 값을 원래 식에 넣어 확인하세요.

   답. 제곱하면 $$x + 2 = x^2$$, 즉 $$x^2 - x - 2 = 0$$ 이므로 $$(x-2)(x+1)=0$$ 에서 $$x=2$$ 와 $$x=-1$$ 이 나옵니다. 넣어 보면 $$x=2$$ 는 $$\sqrt{4}=2$$ 로 참이지만 $$x=-1$$ 은 $$\sqrt{1}=1$$ 이고 오른쪽은 $$-1$$ 이라 거짓입니다. $$x=-1$$ 이 가짜 해입니다.
2. $$-x > 3$$ 과 $$x^2 > 9$$

   답. 앞은 $$x < -3$$, 뒤는 $$x < -3$$ 또는 $$x > 3$$ 입니다. $$x=4$$ 는 뒤만 만족합니다. 제곱하면서 답이 늘었습니다.
3. $$x - 3 < 1$$ 과 $$(x - 3)^2 < 1$$

   답. 앞은 $$x < 4$$, 뒤는 $$|x-3|<1$$ 이므로 $$2 < x < 4$$ 입니다. $$x=0$$ 은 앞만 만족합니다. 이번에는 제곱하면서 답이 줄었습니다.

세 문제가 같은 것을 말합니다. **양변이 모두 음이 아닌지 확인하지 않고 제곱하면, 답이 늘 수도 줄 수도 있습니다.**

### 연습 4 — 부등식 하나 세워 보기

1. $$a > 0$$ 일 때 $$a + \dfrac{1}{a} \ge 2$$ 임을 $$\left(\sqrt{a} - \dfrac{1}{\sqrt{a}}\right)^2 \ge 0$$ 에서 출발해 보이고, 등호가 성립하는 $$a$$ 를 구하세요.

   답. 왼쪽을 전개하면 $$a - 2 \cdot \sqrt{a} \cdot \dfrac{1}{\sqrt{a}} + \dfrac{1}{a} = a - 2 + \dfrac{1}{a}$$ 입니다. 이것이 0 이상이므로 $$-2$$ 를 이항해 $$a + \dfrac{1}{a} \ge 2$$ 를 얻습니다. 등호는 괄호 안이 0일 때, 즉 $$\sqrt{a} = \dfrac{1}{\sqrt{a}}$$ 에서 $$a = 1$$ 일 때입니다.

## 정리

- 부등식의 **해는 값 하나가 아니라 구간**입니다. 수직선에 칠하고 $$[a,b]$$ 나 $$(a,b)$$ 로 적습니다.
- 성질은 등식과 같은데 **음수를 곱하거나 나눌 때만 방향이 뒤집힙니다.** 수직선이 통째로 뒤집히기 때문입니다.
- 연립부등식은 각각 풀어 **나란히 칠하고 둘 다 칠해진 구간**을 읽습니다.
- 절댓값 부등식은 **거리로 읽습니다** — 가까우면 한 덩어리, 멀면 두 덩어리입니다.
- **양변이 모두 음이 아닐 때만** 제곱해도 해가 그대로입니다. 아니면 원래 식에 넣어 가짜 해를 걸러 냅니다.
- 부등식을 만들 때의 밑천은 $$(\text{실수})^2 \ge 0$$ 하나이고, **등호 성립 조건을 늘 함께 적습니다.**

다음 글에서는 여기까지 익힌 조작을 한데 묶습니다. 유도가 막히는 자리는 개념이 아니라 이 줄에서 저 줄로 어떻게 갔는가이고, 그 빈 줄을 채우는 훈련을 합니다.
