[지난 글](/articles/math-basics-complex-numbers-and-euler)까지 다룬 수는 하나씩 떨어져 있었습니다. 이 글부터는 수를 줄지어 세웁니다.

줄이 길어지면 적는 일이 문제가 됩니다. 1부터 100까지 더하라는 말을 점 세 개로 얼버무리지 않고 정확히 적으려면 기호가 하나 필요합니다. 그 기호가 $$\Sigma$$ 이고, **이 글의 절반은 그것을 펼쳤다 다시 접는 연습입니다.**

## 순서가 정해진 수의 나열

$$3,\ 7,\ 11,\ 15,\ 19,\ \ldots$$ 처럼 **순서가 정해진 수의 나열** 을 수열이라고 합니다. 하나하나를 항이라 하고, 몇 번째인지를 아래에 작게 붙여 $$a_1, a_2, a_3, \ldots$$ 으로 적습니다. 이 작은 숫자를 **첨자**라고 하고 $$a_3$$ 은 "에이 삼"이라고 읽습니다.

위 수열이면 $$a_1=3$$, $$a_2=7$$, $$a_5=19$$ 입니다. **$$a_n$$ 은 곱셈이 아닙니다** — $$n$$ 번째 항을 가리키는 이름 하나입니다.

수열을 남에게 넘겨주는 방법은 둘입니다.

- **일반항** — $$n$$ 을 넣으면 곧바로 $$n$$ 번째 항이 나오는 식입니다. 위 수열은 $$a_n = 4n-1$$ 입니다.
- **점화식** — 앞 항으로 다음 항을 만드는 식입니다. 위 수열은 $$a_1=3$$, $$a_{n+1}=a_n+4$$ 입니다.

일반항은 $$a_{100}$$ 을 바로 주지만 점화식은 100번을 굴려야 합니다. 대신 점화식은 규칙 자체를 그대로 적은 것이라 세우기가 쉽습니다.

## 두 가지 흔한 수열

![등차수열과 등비수열의 항을 칸으로 펼쳐 규칙을 비교한 그림](/assets/posts/math-basics-sequences-and-sigma-two-sequences.svg)

**등차수열**은 이웃한 두 항의 차가 늘 같은 수열입니다. 그 차를 공차라 하고 $$d$$ 로 적습니다. $$3, 7, 11, 15$$ 는 $$d=4$$ 입니다. 손으로 펼쳐 봅니다.

$$a_1 = 3,\quad a_2 = 3+4,\quad a_3 = 3+4+4,\quad a_4 = 3+4+4+4$$

$$a_4$$ 에서 4가 세 번 더해졌습니다. **$$n$$ 번째 항에서는 $$n-1$$ 번입니다.**

$$a_n = a_1 + (n-1)d$$

$$a_5 = 3 + 4\times 4 = 19$$ 이고, 위에서 세어 본 값과 같습니다.

**등비수열**은 이웃한 두 항의 비가 늘 같은 수열입니다. 그 비를 공비라 하고 $$r$$ 로 적습니다. $$2, 6, 18, 54$$ 는 $$r=3$$ 입니다.

$$a_1 = 2,\quad a_2 = 2\times 3,\quad a_3 = 2\times 3\times 3,\quad a_4 = 2\times 3^3$$

여기서도 곱해진 횟수가 $$n-1$$ 입니다. [13번 글](/articles/math-basics-powers-and-roots)의 거듭제곱으로 접으면

$$a_n = a_1 r^{n-1}$$

확인하면 $$a_4 = 2\times 3^3 = 54$$ 입니다.

## 점화식은 굴려 보면 안다

점화식이 낯설면 손으로 몇 번 굴리는 것이 가장 빠릅니다. $$a_1=1$$, $$a_{n+1}=2a_n+1$$ 을 다섯 항까지 굴려 봅니다.

![점화식 a(n+1) = 2a(n) + 1 을 다섯 항까지 굴리는 과정](/assets/posts/math-basics-sequences-and-sigma-recurrence.svg)

$$a_2 = 2\times 1+1 = 3$$

$$a_3 = 2\times 3+1 = 7$$

$$a_4 = 2\times 7+1 = 15$$

$$a_5 = 2\times 15+1 = 31$$

$$1, 3, 7, 15, 31$$ 이 나왔습니다. 눈에 띄는 것이 있습니다 — 전부 2의 거듭제곱보다 1 작습니다. 실제로 $$a_n = 2^n - 1$$ 입니다. **점화식에서 일반항을 찾아내는 일반적인 방법은 여기서 다루지 않습니다.** 굴려서 값을 얻는 것까지가 이 글의 몫입니다.

## Σ 는 "여기부터 저기까지 더하라"는 지시문이다

이제 본론입니다. $$a_1$$ 부터 $$a_n$$ 까지 더한 값을 이렇게 적습니다.

$$\sum_{k=1}^{n} a_k$$

[9번 글](/articles/math-basics-symbol-glossary)이 이 기호의 이름과 발음을 표로 주었습니다. 여기서 세울 것은 **이것이 무슨 계산인가** 하나입니다.

![시그마 표기의 네 부분에 각각 이름을 붙인 해부도](/assets/posts/math-basics-sequences-and-sigma-anatomy.svg)

소리 내어 읽으면 이렇습니다.

> **$$k$$ 가 1부터 $$n$$ 까지 갈 동안, $$a_k$$ 를 전부 더하라.**

아래에 적힌 $$k=1$$ 이 출발, 위에 적힌 $$n$$ 이 도착, 오른쪽에 적힌 $$a_k$$ 가 더할 것입니다. $$k$$ 를 1부터 하나씩 올리며 $$a_k$$ 를 적어 나열하고 사이에 +를 끼우면 끝입니다. **새로운 계산이 아니라 긴 덧셈을 짧게 적은 표기입니다.**

펼치는 연습을 합니다.

$$\sum_{k=1}^{4} k^2 = 1^2+2^2+3^2+4^2 = 1+4+9+16 = 30$$

$$\sum_{k=1}^{5} (2k+1) = 3+5+7+9+11 = 35$$

$$\sum_{k=2}^{4} \frac{1}{k} = \frac12+\frac13+\frac14 = \frac{13}{12}$$

거꾸로 접는 연습도 합니다. $$1+3+5+7+9$$ 를 보면 홀수 다섯 개이고 $$k$$ 번째 홀수가 $$2k-1$$ 이므로

$$1+3+5+7+9 = \sum_{k=1}^{5}(2k-1)$$

접을 때 확인할 것은 둘입니다 — **$$k$$ 에 출발값을 넣으면 첫 항이 나오는가, 도착값을 넣으면 마지막 항이 나오는가.** $$k=1$$ 에서 $$1$$, $$k=5$$ 에서 $$9$$ 이니 맞습니다.

## 접힌 채로 다룰 수 있는 네 가지

펼치지 않고도 손댈 수 있는 규칙이 넷 있습니다. 전부 덧셈에서 이미 알던 것을 접힌 표기로 옮긴 것뿐입니다.

**첫째, 첨자의 이름은 아무래도 좋습니다.**

$$\sum_{k=1}^{n} a_k = \sum_{i=1}^{n} a_i$$

$$k$$ 는 1부터 $$n$$ 까지 훑고 사라지는 임시 이름이라 **더미 첨자**라고 합니다. 바깥에는 그 값이 남지 않으므로 이름을 바꿔도 결과가 같습니다.

**둘째, 모든 항에 공통으로 곱해진 수는 밖으로 나옵니다.**

$$\sum_{k=1}^{n} c\,a_k = c\sum_{k=1}^{n} a_k$$

[14번 글](/articles/math-basics-variables-and-expressions)에서 $$ca_1+ca_2+ca_3 = c(a_1+a_2+a_3)$$ 으로 묶던 것입니다.

**셋째, 더하는 것이 둘이면 따로 더해도 됩니다.**

$$\sum_{k=1}^{n} (a_k+b_k) = \sum_{k=1}^{n} a_k + \sum_{k=1}^{n} b_k$$

**넷째, 첨자를 옮겨 적을 수 있습니다.** $$\sum_{k=1}^{n} a_{k+1}$$ 은 $$a_2$$ 부터 $$a_{n+1}$$ 까지를 더한 것이므로

$$\sum_{k=1}^{n} a_{k+1} = \sum_{j=2}^{n+1} a_j$$

**여기 없는 것 하나를 못 박아 둡니다.** 곱셈은 이렇게 쪼개지지 않습니다.

$$\sum_{k=1}^{n} a_k b_k \ \ne\ \left(\sum_{k=1}^{n} a_k\right)\left(\sum_{k=1}^{n} b_k\right)$$

$$n=2$$ 로 세어 보면 왼쪽은 $$a_1b_1+a_2b_2$$, 오른쪽은 거기에 $$a_1b_2+a_2b_1$$ 이 더 붙습니다. **틀린 곳을 찾는 가장 빠른 방법은 작은 $$n$$ 으로 펼쳐 보는 것입니다.**

## 자주 쓰는 세 공식과 그 하나의 유도

$$\sum_{k=1}^{n} 1 = n, \qquad \sum_{k=1}^{n} k = \frac{n(n+1)}{2}, \qquad \sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}$$

첫 번째는 1을 $$n$$ 번 더한 것이니 그대로 $$n$$ 입니다. 두 번째를 직접 유도합니다.

$$1+2+3+\cdots+100$$ 을 앞뒤로 짝지어 봅니다.

![1부터 100까지를 앞뒤로 짝지어 101이 50쌍 나오는 그림](/assets/posts/math-basics-sequences-and-sigma-pairing.svg)

$$1+100 = 101,\quad 2+99=101,\quad 3+98=101,\quad \ldots,\quad 50+51=101$$

**모든 짝의 합이 같습니다.** 앞에서 하나 올라간 만큼 뒤에서 하나 내려오기 때문입니다. 짝은 $$100 \div 2 = 50$$ 개이므로

$$1+2+\cdots+100 = 50 \times 101 = 5050$$

$$n$$ 개로 똑같이 하면 짝의 합이 $$n+1$$, 짝의 수가 $$\dfrac{n}{2}$$ 이므로 $$\dfrac{n(n+1)}{2}$$ 입니다. 등차수열이면 짝의 합이 $$a_1+a_n$$ 이므로 같은 방식으로

$$S_n = \frac{n(a_1+a_n)}{2}$$

**세 번째 공식($$\sum k^2$$)은 결과만 씁니다.** 이런 식의 증명은 수학적 귀납법을 쓰는데, 그것은 46번 · 증명 읽는 법의 몫입니다.

이제 앞의 네 규칙과 세 공식을 함께 써 봅니다.

$$\sum_{k=1}^{10} (k^2-3k) = \sum_{k=1}^{10} k^2 - 3\sum_{k=1}^{10} k$$

$$= \frac{10\times 11\times 21}{6} - 3\times\frac{10\times 11}{2} = 385 - 165 = 220$$

열 항을 하나씩 더하지 않고 끝났습니다. **접힌 채로 다루는 것의 값이 여기 있습니다.**

## 더하기 대신 곱하는 Σ

같은 자리에 곱셈을 넣은 기호도 있습니다. $$\prod$$ 라고 적고 **곱기호**라고 읽습니다.

$$\prod_{k=1}^{4} k = 1\times 2\times 3\times 4 = 24$$

읽는 법도 성질도 $$\Sigma$$ 와 나란합니다 — 첨자를 훑으며 이번에는 곱합니다. 이 글에서는 이름을 붙이는 데까지만 갑니다.

## 여기서 멈추는 것

지금까지 더한 항은 언제나 유한했습니다. 도착값 $$n$$ 자리에 $$\infty$$ 를 적으면 어떻게 되는지 — 무한히 더해도 값이 있는지 — 는 29번 · 등비급수의 몫이고, 그 전에 "한없이 진행하면 어디에 붙는가"를 다루는 것이 다음 글입니다.

## 연습 문제

### 연습 1 — 수열 네 문제

1. $$5, 9, 13, 17, \ldots$$ 의 일반항과 20번째 항

   답. 이웃한 차가 4로 일정하므로 $$a_n = 5+(n-1)\times 4 = 4n+1$$ 입니다. $$a_{20} = 81$$.
2. $$3, 6, 12, 24, \ldots$$ 의 일반항과 7번째 항

   답. 이웃한 비가 2로 일정하므로 $$a_n = 3\times 2^{\,n-1}$$ 입니다. $$a_7 = 3\times 64 = 192$$.
3. $$a_1=2$$, $$a_{n+1}=3a_n-1$$ 을 다섯 항까지

   답. $$2,\ 5,\ 14,\ 41,\ 122$$ 입니다. $$3\times 2-1=5$$, $$3\times 5-1=14$$, $$3\times 14-1=41$$, $$3\times 41-1=122$$.
4. $$a_n = n^2+1$$ 의 처음 네 항

   답. $$2,\ 5,\ 10,\ 17$$ 입니다.

### 연습 2 — 펼치고 접기 네 문제

1. $$\sum_{k=1}^{4}(3k-2)$$ 를 펼쳐 값 구하기

   답. $$1+4+7+10 = 22$$ 입니다.
2. $$2+4+6+8+10+12$$ 를 $$\Sigma$$ 로 접기

   답. $$k$$ 번째 항이 $$2k$$ 이고 여섯 항이므로 $$\sum_{k=1}^{6} 2k$$ 입니다.
3. $$\sum_{k=1}^{n} 5$$

   답. 5를 $$n$$ 번 더한 것이므로 $$5n$$ 입니다. 더하는 것에 $$k$$ 가 없어도 $$k$$ 는 $$n$$ 번 돕니다.
4. $$\sum_{i=1}^{3} i^2$$ 과 $$\sum_{j=1}^{3} j^2$$ 의 관계

   답. 값이 같습니다. 첨자는 훑고 사라지는 더미 첨자라 이름이 결과에 남지 않습니다.

### 연습 3 — 공식 쓰기 네 문제

1. $$\sum_{k=1}^{20} k$$

   답. $$\dfrac{20\times 21}{2} = 210$$ 입니다.
2. $$\sum_{k=1}^{8} k^2$$

   답. $$\dfrac{8\times 9\times 17}{6} = 204$$ 입니다.
3. $$\sum_{k=1}^{6} (2k+3)$$

   답. $$2\sum k + \sum 3 = 2\times\dfrac{6\times 7}{2} + 3\times 6 = 42+18 = 60$$ 입니다. 펼쳐서 $$5+7+9+11+13+15$$ 를 더해도 같습니다.
4. $$1+2+\cdots+200$$

   답. $$\dfrac{200\times 201}{2} = 20100$$ 입니다.

## 정리

- 수열은 순서가 정해진 수의 나열이고, $$a_n$$ 은 곱셈이 아니라 $$n$$ 번째 항의 이름입니다.
- 넘겨주는 방법이 둘입니다 — **일반항** 은 $$n$$ 을 넣으면 바로 나오고, **점화식** 은 앞 항으로 다음을 만듭니다.
- 등차수열은 $$a_n = a_1+(n-1)d$$, 등비수열은 $$a_n = a_1r^{\,n-1}$$ 입니다. 둘 다 더하거나 곱한 횟수가 $$n-1$$ 입니다.
- $$\sum_{k=1}^{n} a_k$$ 는 "$$k$$ 가 1부터 $$n$$ 까지 갈 동안 $$a_k$$ 를 더하라"는 지시문입니다.
- 접힌 채로 쓸 수 있는 규칙 넷 — **더미 첨자 바꾸기, 상수 빼내기, 항별로 쪼개기, 첨자 옮겨 적기** 입니다. 곱셈은 쪼개지지 않습니다.
- $$\sum 1 = n$$, $$\sum k = \dfrac{n(n+1)}{2}$$, $$\sum k^2 = \dfrac{n(n+1)(2n+1)}{6}$$ 입니다. 가운데 것은 앞뒤로 짝지으면 바로 나옵니다.
- $$\prod$$ 는 같은 자리에 곱셈을 넣은 기호입니다.
