디코딩 코드 두 줄을 봅니다.

```python
probs = softmax(logits / temperature)      # (1)
idx = np.searchsorted(cdf, rng.random())   # (2)
```

(1)에서 `temperature`로 나누는 것은 곱셈 하나인데, 결과로 나오는 분포의 모양이 통째로 바뀝니다. 온도가 낮으면 한 토큰에 확률이 몰리고 높으면 평평해집니다. **나누기 하나가 그래프에 무엇을 한 것인지**를 말할 수 있으면 온도를 감으로 고르지 않아도 됩니다.

(2)는 더 이상합니다. 누적확률 배열에서 난수 하나의 자리를 찾는 것뿐인데, 그 결과가 원하는 분포에서 뽑은 표본이 됩니다. 이것이 성립하는 이유는 **누적분포함수가 역함수를 갖기 때문**이고, 역함수를 갖는 조건은 "증가하기만 한다"입니다.

둘 다 함수 이야기입니다. 이 글은 함수를 다시 정의하는 자리가 아니라, **함수에 대해 이미 아는 것을 AI 코드와 맞춰 놓는** 자리입니다.

## 이 글이 필요한지 30초 확인

**문제 1.** $$f(x) = x^2$$은 역함수를 갖나요? 갖게 하려면 무엇을 바꿔야 하나요?

**문제 2.** $$y = f(2x)$$와 $$y = f(x/2)$$ 중 원래 그래프보다 **가로로 눌린** 쪽은 어느 것인가요?

<br>

1번에 "정의역을 $$x \ge 0$$으로 제한하면 갖는다"고 답했고 2번에 "$$f(2x)$$"라고 답했다면 **이 글은 건너뛰어도 됩니다.** 본선 18번 · 지수와 로그로 가세요.

2번에서 헷갈렸다면 — 대부분 헷갈립니다. 「가로 방향」 절에 그 이유가 있습니다.

## 함수 — 입력 하나에 출력 하나

$$f: X \to Y$$는 $$X$$의 원소 하나마다 $$Y$$의 원소를 **정확히 하나** 대응시키는 규칙입니다. 조건은 "하나만"이지 "빠짐없이 다르게"가 아닙니다.

| 이름 | 뜻 | 예: $$f(x) = x^2$$, $$f: \mathbb{R} \to \mathbb{R}$$ |
| --- | --- | --- |
| 정의역 | 입력이 될 수 있는 것 전부 | $$\mathbb{R}$$ |
| 공역 | 출력이 놓일 곳 | $$\mathbb{R}$$ |
| 치역 | 실제로 나오는 출력 전부 | $$[0, \infty)$$ |

**공역과 치역의 구분이 실제로 쓰이는 자리**가 있습니다. `nn.Linear(768, 10)`의 출력은 공역이 $$\mathbb{R}^{10}$$이지만, 그 뒤에 softmax를 붙이면 치역이 "성분이 모두 양수이고 합이 1인 벡터들"로 줄어듭니다. 확률로 쓸 수 있는 이유가 정확히 그것이고, 로짓을 그대로 확률처럼 다루면 안 되는 이유도 같습니다.

$$f: \mathbb{R}^n \to \mathbb{R}^m$$처럼 입력과 출력이 벡터인 경우를 어떻게 서술하고 읽는지는 본선 2번 · 논문 수식 표기 규약이 맡습니다. 이 글은 $$y = f(x)$$ 한 변수만 다룹니다.

## 합성 — 순서와 정의역

$$(g \circ f)(x) = g(f(x))$$입니다. **오른쪽 것을 먼저 적용합니다.**

```python
x = torch.randn(4, 768)
h = layer2(torch.relu(layer1(x)))     # (layer2 ∘ relu ∘ layer1)(x)
```

코드는 왼쪽부터 읽히는데 수식은 오른쪽부터 적용되니 옮겨 적을 때 한 번 뒤집어야 합니다.

**합성에는 조건이 하나 붙습니다. $$f$$의 치역이 $$g$$의 정의역 안에 들어가야 합니다.** 안 그러면 정의되지 않는 입력이 $$g$$에 들어갑니다.

$$f(x) = x - 1, \qquad g(x) = \log x$$

$$g \circ f$$는 $$\log(x-1)$$이고 $$x > 1$$에서만 정의됩니다. 이 조건이 깨지면 코드에서는 `nan`으로 나타납니다. 그래서 확률의 로그를 취하기 전에 `clamp(min=1e-9)`를 걸거나 `log_softmax`를 쓰는 것이고, 그것은 수치 문제이기 이전에 **정의역 문제**입니다.

## 단사·전사, 그리고 역함수

| 이름 | 조건 | 그래프로 판정 |
| --- | --- | --- |
| 단사 (일대일) | $$f(a) = f(b) \Rightarrow a = b$$ | 가로선이 두 번 이상 만나지 않는다 |
| 전사 (위로의) | 공역의 모든 값이 나온다 | 치역 = 공역 |
| 전단사 | 둘 다 | 역함수가 존재한다 |

$$f(x) = x^2$$는 $$f(-2) = f(2) = 4$$라서 단사가 아닙니다. 그래서 역함수가 없습니다 — 4를 되돌리려는데 $$-2$$인지 $$2$$인지 알 수 없기 때문입니다.

**정의역을 $$x \ge 0$$으로 줄이면 단사가 되고, 그때 역함수가 $$\sqrt{x}$$입니다.** 이것이 30초 확인 1번의 답입니다. 역함수는 함수의 성질이 아니라 **함수와 정의역을 함께 정한 것의 성질**입니다.

역함수의 그래프는 원래 그래프를 직선 $$y = x$$에 대해 뒤집은 것입니다. $$(a, b)$$가 원래 그래프 위에 있으면 $$(b, a)$$가 역함수 그래프 위에 있기 때문입니다.

### 단조증가면 역함수가 있다

증가하기만 하는 함수는 자동으로 단사입니다. $$a < b$$이면 $$f(a) < f(b)$$라 값이 같아질 수가 없습니다. **그래서 "증가한다"만 확인하면 역함수를 쓸 수 있습니다.**

이것이 처음 코드 (2)가 성립하는 근거입니다. 누적분포함수 $$F(x) = \Pr(X \le x)$$는 정의상 감소하지 않고, 치역이 $$[0, 1]$$입니다. 그러니 $$[0,1]$$에서 균등하게 뽑은 $$u$$에 대해 $$F^{-1}(u)$$를 계산하면 원하는 분포의 표본이 됩니다.

```python
probs = np.array([0.1, 0.5, 0.3, 0.1])
cdf = np.cumsum(probs)          # [0.1, 0.6, 0.9, 1.0]

u = 0.72                        # 균등분포에서 뽑은 값
idx = np.searchsorted(cdf, u)   # 2
```

`searchsorted`가 하는 일이 **이산분포에서의 $$F^{-1}$$** 입니다. $$u = 0.72$$는 $$0.6$$과 $$0.9$$ 사이이므로 세 번째 항목(인덱스 2)이 나오고, 그 구간의 길이가 $$0.3$$이라 그 항목이 뽑힐 확률이 정확히 $$0.3$$이 됩니다. **구간의 길이가 곧 확률**이라는 것이 전부입니다.

이 방법이 왜 옳은지의 증명과, top-k·top-p·Gumbel-max 같은 변형은 본선 25번 · 범주분포에서 뽑기가 맡습니다. 여기서 확인한 것은 **그 방법이 역함수 위에 서 있다**는 것 하나입니다.

## 대칭과 조각별 정의

**우함수**는 $$f(-x) = f(x)$$입니다. $$y$$축에 대해 좌우대칭이고, $$x^2$$과 $$\cos x$$, 그리고 가우시안 종형이 여기 속합니다.

**기함수**는 $$f(-x) = -f(x)$$입니다. 원점에 대해 점대칭이고 $$x^3$$, $$\sin x$$, $$\tanh x$$가 그렇습니다. 기함수는 반드시 $$f(0) = 0$$입니다($$f(0) = -f(0)$$이므로).

`tanh`가 원점 대칭이고 `sigmoid`가 아니라는 것이 실제로 차이를 만드는 자리가 있는데, 그 비교와 활성함수 선택 기준은 [활성함수 글](/articles/nn-activation-functions)이 이미 다룹니다. 여기서는 대칭이라는 성질만 봅니다.

**조각별 정의 함수**는 구간마다 다른 식을 쓰는 것입니다.

$$\mathrm{ReLU}(x) = \begin{cases} x & x > 0 \\ 0 & x \le 0 \end{cases}$$

경계에서 이어지는지(연속인지)와 꺾이는지가 따로 물어야 할 질문입니다. ReLU는 0에서 이어지지만 꺾입니다.

**지시함수**는 조건이 참이면 1, 거짓이면 0인 함수입니다.

$$\mathbf{1}[x > 0] = \begin{cases} 1 & x > 0 \\ 0 & \text{그 외} \end{cases}$$

논문에서 아주 자주 나오는데, 대부분 **합 안에서 "이 항만 세라"는 뜻**입니다. 정확도를 적은 식

$$\text{acc} = \frac{1}{N}\sum_{i=1}^{N} \mathbf{1}[\hat{y}_i = y_i]$$

은 `(pred == label).mean()` 한 줄과 같은 것이고, 어텐션 마스크도 $$\mathbf{1}[j \le i]$$ 꼴입니다.

## 파라미터 하나가 그래프에 하는 일

이제 변환입니다. 다섯 가지가 전부입니다.

| 식 | 하는 일 | 방향 |
| --- | --- | --- |
| $$y = f(x - a)$$ | 오른쪽으로 $$a$$만큼 이동 | 가로 |
| $$y = f(x) + b$$ | 위로 $$b$$만큼 이동 | 세로 |
| $$y = c\,f(x)$$ | 세로로 $$c$$배 확대 | 세로 |
| $$y = f(cx)$$ | 가로로 $$1/c$$배 축소 | 가로 |
| $$y = -f(x)$$ | 위아래 뒤집기 | 세로 |
| $$y = f(-x)$$ | 좌우 뒤집기 | 가로 |

![파라미터 하나가 그래프에 하는 일](/assets/posts/math-basics-functions-and-graphs-transforms.svg)

### 가로 방향은 왜 반대로 느껴지는가

세로 변환은 직관대로입니다. $$y = 3f(x)$$는 출력에 3을 곱하니 세로로 3배 늘어납니다.

가로는 반대입니다. **$$y = f(2x)$$가 가로로 절반으로 줄어듭니다.** 이유는 한 줄로 확인됩니다. 원래 그래프가 $$x = 6$$에서 갖던 값을, 새 그래프는 $$2x = 6$$, 즉 $$x = 3$$에서 갖습니다. 6에 있던 것이 3으로 당겨졌으니 절반입니다.

$$y = f(x - a)$$의 이동 방향도 같은 이유입니다. 원래 $$x = 0$$에서 갖던 값을 새 그래프는 $$x - a = 0$$, 즉 $$x = a$$에서 갖습니다. **빼는데 오른쪽으로 갑니다.**

가로 변환은 "그 값을 갖게 되는 $$x$$가 어디로 옮겨지는가"를 한 번 풀어 보면 항상 맞습니다. 외우는 것보다 이 한 줄을 매번 푸는 편이 빠릅니다.

이제 처음 코드 (1)로 돌아갈 수 있습니다.

```python
probs = softmax(logits / temperature)
```

$$\tau$$로 나누는 것은 $$c = 1/\tau$$인 **가로 변환**입니다. $$\tau < 1$$이면 $$c > 1$$이라 가로로 눌리고, 점수 차이가 벌어지는 효과가 나서 분포가 뾰족해집니다. $$\tau > 1$$이면 가로로 늘어나 차이가 줄고 분포가 평평해집니다. $$\tau \to 0$$이면 가장 큰 로짓 하나만 남아 argmax와 같아지고, $$\tau \to \infty$$면 균등분포에 가까워집니다.

**곱셈 하나가 분포를 다시 만드는 것이 아니라 가로 눈금을 바꾼 것뿐**입니다. softmax가 정확히 왜 그 모양이고 온도가 그 식 어디에 들어가는지는 본선 24번 · softmax 유도가 맡습니다.

## 좌표 몇 점으로 복원해야 하는 다섯 곡선

마지막으로 개형입니다. 아래 다섯은 AI 글에서 반복해서 나오고, **점근선과 휘는 방향만 기억하면 좌표 몇 점으로 다시 그릴 수 있습니다.**

![좌표 몇 점만으로 다시 그릴 수 있어야 하는 다섯 곡선](/assets/posts/math-basics-functions-and-graphs-five-curves.svg)

| 곡선 | 점근선 | 단조 | 볼록 | 어디서 만나는가 |
| --- | --- | --- | --- | --- |
| $$y = e^x$$ | $$y = 0$$ | 항상 증가 | 아래로 볼록 | softmax 분자, 확률의 지수 꼴 |
| $$y = \ln x$$ | $$x = 0$$ | 항상 증가 | 위로 볼록 | 로그가능도, 손실 |
| $$y = e^{-x^2/2}$$ | $$y = 0$$ | 0에서 최대 | 변곡점 $$x = \pm1$$ | 정규분포 밀도 |
| $$y = x^{-b}$$ | $$x = 0$$, $$y = 0$$ | 감소 | 아래로 볼록 | 스케일링 곡선 |
| $$y = \dfrac{1}{1+e^{-x}}$$ | $$y = 0$$, $$y = 1$$ | 항상 증가 | 변곡점 $$x = 0$$ | 게이트, 확률 출력 |

몇 가지만 짚습니다.

**지수와 로그는 서로 역함수입니다.** 그래서 두 그래프는 $$y = x$$에 대해 뒤집은 관계이고, 한쪽의 점근선 $$y = 0$$이 다른 쪽에서 $$x = 0$$이 됩니다. 지수·로그 법칙과 그것이 왜 AI 코드 도처에 있는지는 본선 18번 · 지수와 로그가 맡습니다.

**멱함수 $$y = x^{-b}$$는 로그-로그 축에서 직선이 됩니다.** 스케일링 곡선을 로그-로그로 그리는 이유가 그것인데, 로그 축을 읽는 법 자체는 기초 자릿수와 오차 글이 맡습니다. 곡선의 해석은 [스케일링 법칙 글](/articles/llm-scaling-laws)이 다룹니다.

**포화 곡선의 핵심은 양 끝이 평평하다는 것**입니다. $$x$$가 커져도 출력이 1을 넘지 못하고, 그 구간에서는 입력이 크게 변해도 출력이 거의 안 변합니다. 이 평평함이 나중에 학습을 멈추게 만드는데(기울기가 0에 가까워져서), 그 계산은 본선 38번 · 활성함수의 미분의 몫입니다.

**변곡점은 휘는 방향이 바뀌는 자리**입니다. 종형은 $$x = \pm1$$에서, 포화 곡선은 $$x = 0$$에서 바뀝니다. 이 지점들이 "가장 가파른 곳"과 겹치는 것도 우연이 아니지만, 그것을 계산으로 확인하는 것은 미분의 일입니다.

**이차식은 이 다섯에 넣지 않습니다.** 포물선의 개형과 꼭짓점은 [앞 글](/articles/math-basics-quadratic-and-parabola)이 통째로 맡았습니다.

## 다시 그 두 줄로

```python
probs = softmax(logits / temperature)      # 가로 확대 — 분포의 뾰족함을 정한다
idx = np.searchsorted(cdf, rng.random())   # 역함수 — 균등난수를 원하는 분포로 옮긴다
```

첫 줄은 함수의 **가로 눈금**을 바꾸는 일이었고, 둘째 줄은 **단조증가라서 역함수가 있다**는 사실을 그대로 쓴 것이었습니다. 둘 다 새 개념이 아니라 학교에서 배운 함수의 성질을 코드가 그대로 쓰고 있는 자리입니다.

여기까지가 한 변수 $$y = f(x)$$의 전부입니다. 그런데 학습 이야기로 넘어가면 곧 **입력이 둘 이상인 함수**가 나옵니다. 손실은 파라미터 수백만 개의 함수이고, "손실 지형"이라는 말은 그 함수의 그래프를 가리킵니다. 변수가 둘일 때 그래프가 어떻게 생겼고 그것을 종이 위에서 어떻게 보는지 — 곡면, 등고선, 단면 — 는 다음 글이 맡습니다.
