[지난 글](/articles/math-basics-expanding-and-factoring)의 끝에서 두 식을 나란히 놓고 봤습니다. $$(a+b)^2 = a^2+2ab+b^2$$ 은 무엇을 넣어도 참이고, $$2x + 1 = 7$$ 은 $$x=4$$ 일 때만 참이었습니다.

뒤쪽 같은 등식에서 그 값을 찾아내는 것이 이 글입니다.

## 해 — 등식을 참으로 만드는 값

$$2x + 1 = 7$$

$$x$$ 에 아무 수나 넣어 봅니다. $$x=1$$ 이면 왼쪽이 3이라 거짓, $$x=2$$ 면 5라 거짓, $$x=4$$ 면 9가 아니라 7이라 참입니다.

이렇게 **등식을 참으로 만드는 값**을 그 방정식의 **해**라고 하고, 해를 모두 찾는 일을 **푼다**고 합니다.

여기서 오해가 하나 생깁니다. 푼다는 것이 값을 하나씩 넣어 보는 일 같지만 그렇지 않습니다. 넣어 보기로는 $$x = \frac{17}{6}$$ 같은 해를 영영 못 찾습니다.

**푼다는 것은 등식을 $$x = \square$$ 꼴로 옷을 갈아입히는 일입니다.** 옷을 갈아입히는 동안 해가 바뀌지 않게만 하면, 마지막 줄에 답이 그냥 적혀 있습니다.

## 등식의 성질 넷

옷을 갈아입혀도 해가 안 바뀌게 하는 방법이 딱 넷입니다.

![양팔 저울로 본 등식의 성질 넷](/assets/posts/math-basics-linear-equations-balance.svg)

등호는 양팔 저울입니다. 양쪽에 똑같이 해 주는 동안에는 기울지 않습니다.

| 하는 일 | 적으면 |
| --- | --- |
| 양변에 같은 수를 더한다 | $$a=b$$ 이면 $$a+c=b+c$$ |
| 양변에서 같은 수를 뺀다 | $$a=b$$ 이면 $$a-c=b-c$$ |
| 양변에 같은 수를 곱한다 | $$a=b$$ 이면 $$ac=bc$$ |
| 양변을 0이 아닌 수로 나눈다 | $$a=b$$ 이면 $$\dfrac{a}{c}=\dfrac{b}{c}$$ |

마지막 줄의 단서가 중요합니다. **0으로는 나눌 수 없습니다.** [11번 글](/articles/math-basics-fractions)에서 본 이유 그대로입니다.

이 넷이 전부입니다. 앞으로 나올 어떤 풀이도 이 넷을 번갈아 쓴 것입니다.

## 이항 — 새 규칙이 아니다

$$2x + 3 = 11$$ 을 풉니다. 왼쪽에 $$x$$ 만 남기고 싶으니 $$+3$$ 을 없애야 합니다. 양변에서 3을 뺍니다.

$$2x + 3 - 3 = 11 - 3$$

$$2x = 8$$

양변을 2로 나눕니다.

$$x = 4$$

이제 가운데 줄을 빼고 첫 줄과 셋째 줄만 놓고 봅니다.

![이항은 양변에서 같은 것을 뺀 두 줄을 줄여 적은 것](/assets/posts/math-basics-linear-equations-transpose.svg)

$$2x + 3 = 11 \;\to\; 2x = 11 - 3$$

왼쪽의 $$+3$$ 이 오른쪽에서 $$-3$$ 으로 나타났습니다. 이것을 **이항**이라고 합니다.

**"넘기면 부호가 바뀐다"는 규칙은 외울 것이 아닙니다.** 지금 한 일은 양변에서 3을 뺀 것뿐이고, 부호가 바뀐 것처럼 보이는 이유도 뺐기 때문입니다. 성질 넷 중 앞의 둘을 줄여 적은 이름일 뿐입니다.

[3번 글](/articles/math-basics-working-by-hand)의 "한 줄에 한 조작"이 여기서 처음 값을 합니다. 이항을 두 개씩 한꺼번에 하면 부호를 놓치고, 놓친 자리를 나중에 찾을 수 없습니다.

## 푸는 절차 — 다섯 걸음

순서를 고정해 두면 생각할 것이 없어집니다.

| 걸음 | 하는 일 |
| --- | --- |
| 1 | 괄호를 푼다 |
| 2 | 분모의 최소공배수를 양변에 곱해 분수를 없앤다 |
| 3 | 양쪽에서 각각 동류항을 정리한다 |
| 4 | 미지수를 한쪽으로, 수를 반대쪽으로 이항한다 |
| 5 | 미지수의 계수로 양변을 나눈다 |

분수가 섞인 것으로 다섯 걸음을 끝까지 밟아 봅니다.

$$\frac{x-1}{2} + \frac{x}{3} = 3$$

분모가 2와 3이므로 최소공배수는 6입니다. 양변에 6을 곱합니다. 이때 **오른쪽의 3에도 반드시 곱해야 합니다.** 가장 자주 새는 자리입니다.

$$6 \times \frac{x-1}{2} + 6 \times \frac{x}{3} = 6 \times 3$$

$$3(x-1) + 2x = 18$$

괄호를 풉니다.

$$3x - 3 + 2x = 18$$

왼쪽의 동류항을 정리합니다.

$$5x - 3 = 18$$

$$-3$$ 을 이항합니다.

$$5x = 21$$

계수 5로 나눕니다.

$$x = \frac{21}{5}$$

## 검산 — 한 줄이면 끝난다

구한 값을 **원래 식**에 도로 넣습니다. 정리한 식이 아니라 처음 식입니다. 중간에 틀렸으면 정리한 식에서는 안 잡힙니다.

$$\frac{\frac{21}{5}-1}{2} + \frac{\frac{21}{5}}{3} = \frac{\frac{16}{5}}{2} + \frac{7}{5} = \frac{8}{5} + \frac{7}{5} = \frac{15}{5} = 3$$

오른쪽이 3이었으니 맞습니다. **답이 지저분할수록 검산이 값을 합니다.**

## 해가 없을 때, 해가 무수히 많을 때

일차방정식이라고 늘 답이 하나인 것은 아닙니다.

$$2x + 3 = 2x + 7$$

$$2x$$ 를 이항하면 왼쪽에서 미지수가 통째로 사라집니다.

$$0 \cdot x = 4$$

어떤 수를 0에 곱해도 4가 되지 않으므로 **해가 없습니다.**

$$3(x + 1) = 3x + 3$$

괄호를 풀면 $$3x+3 = 3x+3$$ 이고, 이항하면 이렇게 됩니다.

$$0 \cdot x = 0$$

이번에는 어떤 수를 넣어도 참입니다. **해가 무수히 많습니다.** [1번 글](/articles/math-basics-what-equals-means)에서 나눈 갈래로 보면 이 등식은 사실 항등식이었습니다.

미지수가 사라졌다고 당황하지 마세요. **남은 것이 거짓이면 해가 없고, 참이면 모든 수가 해입니다.**

## 특정 문자에 대해 풀기

문자가 여럿인 등식도 같은 도구로 다룹니다. 어느 문자를 남길지만 정하면 됩니다.

$$S = \frac{1}{2}ah$$

여기서 $$h$$ 를 남기고 싶습니다. 양변에 2를 곱하고, 양변을 $$a$$ 로 나눕니다.

$$2S = ah$$

$$h = \frac{2S}{a}$$

$$a$$ 로 나눌 수 있는 것은 $$a \neq 0$$ 일 때입니다. 삼각형의 밑변이므로 문제없습니다.

**푸는 절차는 미지수가 수든 문자든 똑같습니다.** 남길 문자를 미지수로 보고 나머지를 전부 수처럼 다루면 됩니다.

## 미지수가 둘일 때 — 연립방정식

$$x + y = 7$$ 하나만으로는 해가 정해지지 않습니다. $$(1,6)$$ 도 $$(2,5)$$ 도 참입니다. 식이 하나 더 있어야 합니다.

$$\begin{aligned} x + y &= 7 \\ 2x - y &= 2 \end{aligned}$$

**두 식을 동시에 참으로 만드는 짝**을 찾는 것이 연립방정식입니다. 요령은 하나입니다 — **미지수를 하나 없애 버리면 앞에서 푼 것과 같아집니다.** 없애는 방법이 둘입니다.

### 대입법 — 한쪽을 다른 쪽에 밀어 넣는다

첫 식을 $$y$$ 에 대해 풉니다.

$$y = 7 - x$$

이것을 둘째 식의 $$y$$ 자리에 통째로 넣습니다.

$$2x - (7 - x) = 2$$

$$2x - 7 + x = 2$$

$$3x = 9$$

$$x = 3$$

$$y = 7 - 3 = 4$$

괄호를 빼먹고 $$2x - 7 - x$$ 라고 적는 것이 가장 흔한 실수입니다. **대입한 것이 두 항이면 괄호로 묶어 넣습니다.**

### 가감법 — 두 식을 그대로 더하거나 뺀다

두 식을 세로로 더합니다. 왼쪽끼리, 오른쪽끼리 더합니다.

$$(x + y) + (2x - y) = 7 + 2$$

$$3x = 9$$

$$y$$ 와 $$-y$$ 가 상쇄돼 사라졌습니다. 이렇게 부호가 반대이면 그냥 더하면 됩니다.

계수가 안 맞으면 한쪽 식에 수를 곱해 맞춥니다. 등식의 성질 셋째입니다.

$$\begin{aligned} 2x + 3y &= 13 \\ 4x - y &= 5 \end{aligned}$$

$$y$$ 를 없애려면 아래 식을 3배 합니다. $$12x - 3y = 15$$ 가 되고, 위 식과 더하면 $$14x = 28$$ 이므로 $$x=2$$, 이어서 $$y=3$$ 입니다.

**둘 중 어느 것을 써도 답은 같습니다.** 한쪽 식이 이미 $$y = \cdots$$ 꼴이면 대입법이, 계수가 나란히 놓여 있으면 가감법이 손이 덜 갑니다.

미지수가 셋 이상일 때 이 소거를 표로 체계화하는 것은 43번 · 가우스 소거의 몫이고, 두 식을 두 직선으로 보고 만나는 점을 읽는 그림은 24번 · 좌표평면과 직선이 맡습니다.

## 비례식은 이미 푼 것이다

[12번 글](/articles/math-basics-decimals-percent-ratio)에서 값으로 읽었던 비가 여기서 식이 됩니다.

$$a : b = c : d \;\Longleftrightarrow\; ad = bc$$

"내항의 곱과 외항의 곱이 같다"는 규칙도 외울 것이 아닙니다. $$\frac{a}{b} = \frac{c}{d}$$ 의 양변에 $$bd$$ 를 곱한 것뿐이고, 방금 세운 등식의 성질 셋째입니다.

## 연습 문제

세 묶음 모두 **구한 값을 원래 식에 도로 넣어 확인**하세요.

### 연습 1 — 일차방정식 스무 문제

1. $$x + 7 = 12$$

   답. 양변에서 7을 뺍니다. $$x = 5$$.
2. $$3x = 21$$

   답. 양변을 3으로 나눕니다. $$x = 7$$.
3. $$2x - 5 = 9$$

   답. $$2x = 14$$, $$x = 7$$.
4. $$5 - x = 8$$

   답. $$-x = 3$$ 이고 양변을 $$-1$$ 로 나누면 $$x = -3$$.
5. $$4x + 3 = x + 18$$

   답. $$3x = 15$$, $$x = 5$$.
6. $$7x - 2 = 3x + 10$$

   답. $$4x = 12$$, $$x = 3$$.
7. $$2(x + 3) = 14$$

   답. 괄호를 풀면 $$2x + 6 = 14$$, $$x = 4$$.
8. $$3(x - 1) = 2(x + 4)$$

   답. $$3x - 3 = 2x + 8$$, $$x = 11$$.
9. $$5(x + 2) - 3 = 2x + 16$$

   답. $$5x + 7 = 2x + 16$$, $$3x = 9$$, $$x = 3$$.
10. $$\dfrac{x}{2} = 6$$

    답. 양변에 2를 곱합니다. $$x = 12$$.
11. $$\dfrac{x}{3} + 1 = 4$$

    답. $$\dfrac{x}{3} = 3$$, $$x = 9$$.
12. $$\dfrac{2x}{5} = 4$$

    답. 양변에 5를 곱하면 $$2x = 20$$, $$x = 10$$.
13. $$\dfrac{3}{4}x = 9$$

    답. 양변에 $$\dfrac{4}{3}$$ 을 곱합니다. $$x = 12$$.
14. $$\dfrac{x}{2} + \dfrac{x}{3} = 5$$

    답. 양변에 6을 곱하면 $$3x + 2x = 30$$, $$x = 6$$.
15. $$\dfrac{x}{4} - \dfrac{x}{6} = 1$$

    답. 양변에 12를 곱하면 $$3x - 2x = 12$$, $$x = 12$$.
16. $$\dfrac{2x - 1}{3} = 5$$

    답. 양변에 3을 곱하면 $$2x - 1 = 15$$, $$x = 8$$.
17. $$\dfrac{x+1}{2} = \dfrac{x-1}{3}$$

    답. 양변에 6을 곱하면 $$3(x+1) = 2(x-1)$$, $$3x + 3 = 2x - 2$$, $$x = -5$$.
18. $$\dfrac{x}{2} + \dfrac{x+2}{5} = 6$$

    답. 양변에 10을 곱하면 $$5x + 2(x+2) = 60$$, $$7x = 56$$, $$x = 8$$.
19. $$4(x - 1) = 4x - 4$$

    답. 괄호를 풀면 양쪽이 같아져 $$0 \cdot x = 0$$. 모든 수가 해입니다.
20. $$2(x + 1) = 2x + 5$$

    답. $$2x + 2 = 2x + 5$$ 에서 $$0 \cdot x = 3$$. 해가 없습니다.

### 연습 2 — 연립방정식 열 문제

1. $$x + y = 7$$, $$x - y = 1$$

   답. 더하면 $$2x = 8$$ 이므로 $$x = 4$$, $$y = 3$$.
2. $$x + y = 10$$, $$2x + y = 16$$

   답. 아래에서 위를 빼면 $$x = 6$$, $$y = 4$$.
3. $$y = 2x$$, $$x + y = 9$$

   답. 대입하면 $$3x = 9$$ 이므로 $$x = 3$$, $$y = 6$$.
4. $$y = x + 1$$, $$2x + y = 10$$

   답. 대입하면 $$3x + 1 = 10$$ 이므로 $$x = 3$$, $$y = 4$$.
5. $$y = x - 1$$, $$3x + y = 11$$

   답. 대입하면 $$4x - 1 = 11$$ 이므로 $$x = 3$$, $$y = 2$$.
6. $$2x + y = 7$$, $$3x - y = 8$$

   답. 더하면 $$5x = 15$$ 이므로 $$x = 3$$, $$y = 1$$.
7. $$3x + 2y = 16$$, $$x - 2y = 0$$

   답. 더하면 $$4x = 16$$ 이므로 $$x = 4$$, $$y = 2$$.
8. $$2x + 3y = 13$$, $$4x - y = 5$$

   답. 아래를 3배 해 더하면 $$14x = 28$$ 이므로 $$x = 2$$, $$y = 3$$.
9. $$5x - 2y = 4$$, $$3x + 4y = 18$$

   답. 위를 2배 해 더하면 $$13x = 26$$ 이므로 $$x = 2$$, $$y = 3$$.
10. $$\dfrac{x}{2} + \dfrac{y}{3} = 4$$, $$x - y = 3$$

    답. 위에 6을 곱해 $$3x + 2y = 24$$. 아래에서 $$x = y + 3$$ 을 대입하면 $$5y = 15$$ 이므로 $$y = 3$$, $$x = 6$$.

### 연습 3 — 문장제 다섯 문제

식을 세우는 것까지가 문제입니다. 구하려는 것을 $$x$$ 로 놓고 시작하세요.

1. 어떤 수에 3을 곱하고 4를 더했더니 25가 되었습니다.

   답. $$3x + 4 = 25$$, $$3x = 21$$, $$x = 7$$.
2. 연속한 두 자연수의 합이 47입니다.

   답. 작은 쪽을 $$x$$ 로 놓으면 $$x + (x+1) = 47$$, $$2x = 46$$, $$x = 23$$. 두 수는 23과 24입니다.
3. 한 개에 800원인 사과와 1200원인 배를 합쳐 10개 사고 9,600원을 냈습니다. 사과는 몇 개입니까?

   답. 사과를 $$x$$ 개라 하면 배는 $$10-x$$ 개이므로 $$800x + 1200(10-x) = 9600$$. 풀면 $$-400x = -2400$$, $$x = 6$$. 사과 6개, 배 4개입니다.
4. 가로가 세로보다 5cm 긴 직사각형의 둘레가 46cm입니다. 세로의 길이는 얼마입니까?

   답. 세로를 $$x$$ 라 하면 $$2(x + x + 5) = 46$$, $$4x + 10 = 46$$, $$x = 9$$. 세로 9cm, 가로 14cm입니다.
5. 지금 형은 12살, 동생은 4살입니다. 형의 나이가 동생 나이의 2배가 되는 것은 몇 년 뒤입니까?

   답. $$t$$ 년 뒤라 하면 $$12 + t = 2(4 + t)$$, $$12 + t = 8 + 2t$$, $$t = 4$$. 4년 뒤에 16살과 8살이 됩니다.

문장제에서 막히는 자리는 계산이 아니라 **무엇을 $$x$$ 로 놓을지** 정하는 데 있습니다. 3번처럼 구하는 것을 $$x$$ 로 놓으면 나머지가 $$10-x$$ 로 저절로 따라옵니다.

## 정리

- **방정식의 해는 등식을 참으로 만드는 값**이고, 푼다는 것은 등식을 $$x=\square$$ 꼴로 갈아입히는 일입니다.
- 갈아입힐 때 쓰는 도구는 **등식의 성질 넷**뿐입니다 — 양변에 같은 수를 더하고, 빼고, 곱하고, 0이 아닌 수로 나눕니다.
- **이항은 새 규칙이 아니라** 앞의 둘을 줄여 적은 이름입니다. 부호가 바뀌어 보이는 이유가 뺐기 때문입니다.
- 절차를 다섯 걸음으로 고정합니다 — 괄호, 분모 없애기, 동류항, 이항, 계수로 나누기.
- 미지수가 사라지면 **남은 것이 거짓이면 해가 없고 참이면 모든 수가 해**입니다.
- 연립은 **미지수를 하나 없애면** 앞에서 푼 것과 같아집니다. 대입법과 가감법 둘 다 그 목적입니다.
- 검산은 정리한 식이 아니라 **원래 식**에 넣습니다.

다음 글에서는 등호 자리에 부등호가 놓입니다. 도구는 거의 그대로인데 딱 한 자리에서 갈라집니다 — 음수를 곱하면 방향이 뒤집힙니다.
