[지난 글](/articles/math-basics-variables-and-expressions)의 연습에서 $$(a+b)^2$$ 과 $$a^2 + b^2$$ 이 다른 값이 나왔습니다. $$a = 3$$, $$b = -2$$ 에서 하나는 1이고 하나는 13이었습니다.

왜 다른지, 그리고 정확히 얼마나 다른지를 이 글에서 답합니다. 그러려면 **괄호를 푸는 조작**이 필요합니다.

## 전개 — 괄호를 푼다

[10번 글](/articles/math-basics-numbers-and-number-line)에서 수에 대해 세운 것이 있습니다.

$$a \times (b + c) = a \times b + a \times c$$

**분배법칙**입니다. 가로 $$a$$, 세로 $$b+c$$ 인 직사각형을 세로로 자르면 넓이가 두 조각으로 나뉜다 — 그 그림이 이 식이었습니다.

문자가 들어와도 그대로 성립합니다. 괄호를 이렇게 푸는 것을 **전개**라고 합니다.

$$2(x + 3) = 2x + 6$$

괄호가 둘일 때도 같습니다. **앞 괄호의 각 항을 뒤 괄호의 각 항에 하나씩 곱합니다.**

$$(x + 2)(x + 5) = x^2 + 5x + 2x + 10 = x^2 + 7x + 10$$

$$x$$ 짜리 두 항이 [지난 글](/articles/math-basics-variables-and-expressions)의 동류항이므로 합쳐서 $$7x$$ 가 됐습니다.

전개는 **절차**입니다. 빠뜨리지만 않으면 늘 됩니다.

## 곱셈 공식 셋 — 외우지 않고 그리기

자주 나오는 세 모양에는 이름이 붙어 있습니다. 다만 외워야 할 것은 아닙니다.

### (a+b)²

[6번 글](/articles/math-basics-area-and-volume)에서 도형의 넓이를 잘라 붙여 구했습니다. 여기서도 같은 그림을 씁니다.

![한 변이 a+b인 정사각형을 네 조각으로 나눈 그림](/assets/posts/math-basics-expanding-and-factoring-square.svg)

한 변이 $$a + b$$ 인 정사각형을 $$a$$ 와 $$b$$ 로 끊어 자르면 네 조각이 나옵니다. $$a^2$$, $$ab$$, $$ab$$, $$b^2$$ 입니다.

$$(a+b)^2 = a^2 + 2ab + b^2$$

**$$a^2 + b^2$$ 이 아닌 이유가 그림에 그대로 있습니다.** 가운데 두 조각 $$2ab$$ 를 통째로 버린 것이 $$a^2 + b^2$$ 입니다.

지난 글의 값으로 확인해 봅니다. $$a = 3$$, $$b = -2$$ 이면 $$2ab = -12$$ 이고, $$13 + (-12) = 1$$ 입니다. 정확히 맞습니다.

### (a−b)²

같은 그림에서 나옵니다. 한 변 $$a$$ 인 정사각형에서 폭 $$b$$ 인 띠를 가로세로로 하나씩 떼어 내면, 겹치는 모서리의 $$b^2$$ 을 두 번 뺀 셈이 됩니다. 한 번 되돌려 줍니다.

$$(a-b)^2 = a^2 - 2ab + b^2$$

가운데 항의 부호만 바뀝니다.

### (a+b)(a−b)

이것은 잘라 붙이는 그림이 더 깔끔합니다.

![a²에서 b²을 도려낸 ㄱ자를 잘라 붙여 직사각형을 만드는 그림](/assets/posts/math-basics-expanding-and-factoring-difference.svg)

한 변 $$a$$ 인 정사각형에서 한 변 $$b$$ 인 정사각형을 도려냅니다. 남은 ㄱ자를 한 번 잘라 옮겨 붙이면 가로 $$a+b$$, 세로 $$a-b$$ 인 직사각형이 됩니다.

$$(a+b)(a-b) = a^2 - b^2$$

13번 글에서 유리화할 때 켤레를 곱하면 분모의 근호가 사라졌던 것이 이 공식입니다. $$(\sqrt{5}-\sqrt{3})(\sqrt{5}+\sqrt{3}) = 5 - 3$$ 이었습니다.

## 인수분해 — 다시 묶는다

전개의 반대 방향입니다. 더하기로 늘어놓은 식을 **곱의 모양으로** 되돌립니다.

$$x^2 + 7x + 10 \;\to\; (x+2)(x+5)$$

전개는 절차라 금방 익습니다. **인수분해는 찾기라서 훈련이 필요합니다.** 뒤에서 실제로 막히는 쪽은 늘 이쪽입니다. 세 가지로 나눠 익힙니다.

### 하나 — 공통인수 빼기

모든 항에 들어 있는 것을 밖으로 꺼냅니다. 분배법칙을 거꾸로 쓰는 것입니다.

$$6x^2 + 4x = 2x(3x + 2)$$

$$6$$ 과 $$4$$ 의 공약수 2, 그리고 두 항에 다 있는 $$x$$ 를 꺼냈습니다. **가장 먼저 확인할 것이 이것입니다.** 공통인수를 빼 두면 남은 식이 작아져 뒤가 쉬워집니다.

### 둘 — 곱셈 공식 되돌리기

위에서 만든 셋을 오른쪽에서 왼쪽으로 읽습니다.

| 이 모양이 보이면 | 이렇게 묶는다 |
| --- | --- |
| $$a^2 + 2ab + b^2$$ | $$(a+b)^2$$ |
| $$a^2 - 2ab + b^2$$ | $$(a-b)^2$$ |
| $$a^2 - b^2$$ | $$(a+b)(a-b)$$ |

$$x^2 + 10x + 25$$ 를 봅니다. 첫 항이 $$x^2$$, 끝 항이 $$5^2$$, 가운데가 $$2 \times x \times 5$$ 입니다. 모양이 맞으므로 $$(x+5)^2$$ 입니다.

$$x^2 - 16$$ 은 $$x^2 - 4^2$$ 이므로 $$(x+4)(x-4)$$ 입니다. **제곱에서 제곱을 뺀 모양은 눈에 익혀 두면 가장 빨리 알아보게 됩니다.**

### 셋 — 곱이 ab, 합이 a+b 인 두 수 찾기

$$x^2 + 7x + 12$$ 처럼 완전제곱도 아니고 차도 아닌 것이 남습니다.

$$(x+a)(x+b) = x^2 + (a+b)x + ab$$

이 모양을 되돌리려면 **곱하면 12, 더하면 7이 되는 두 수**를 찾으면 됩니다. 12를 만드는 짝을 늘어놓고 합을 봅니다.

| 두 수 | 곱 | 합 |
| --- | --- | --- |
| 1, 12 | 12 | 13 |
| 2, 6 | 12 | 8 |
| **3, 4** | **12** | **7** |

$$x^2 + 7x + 12 = (x+3)(x+4)$$

부호가 섞이면 이렇게 봅니다. **끝 항이 음수이면 두 수의 부호가 다르고**, 양수이면 같습니다. 같을 때는 가운데 항의 부호가 곧 두 수의 부호입니다.

$$x^2 - 2x - 8$$ 은 끝이 음수이므로 부호가 다른 짝을 찾습니다. 곱이 $$-8$$, 합이 $$-2$$ 인 두 수는 $$-4$$ 와 $$2$$ 이므로 $$(x-4)(x+2)$$ 입니다.

삼차 이상은 이 과정에서 쓰지 않으므로 다루지 않습니다.

## 등호가 무엇을 뜻하는지 한 번 확인

[1번 글](/articles/math-basics-what-equals-means)에서 등호를 셋으로 갈랐습니다. 지금 손에 든 두 식으로 확인만 하고 넘어갑니다.

$$(a+b)^2 = a^2 + 2ab + b^2$$

$$a$$ 와 $$b$$ 에 무엇을 넣어도 참입니다. 항등식입니다.

$$2x + 1 = 7$$

$$x = 4$$ 일 때만 참입니다. 방정식입니다.

**곱셈 공식은 전부 항등식**이고, 그래서 아무 값이나 넣어 검산할 수 있습니다. 방정식을 실제로 푸는 절차는 16번 · 일차방정식과 이항의 몫입니다.

## 연습 문제

두 연습 모두 **$$x = 2$$ 를 넣어 검산**하세요. 전개나 인수분해는 같은 식을 다른 모양으로 적은 것이므로, 어떤 값을 넣어도 양쪽 값이 같아야 합니다. 다르면 어딘가 틀린 것입니다.

### 연습 1 — 전개 열 문제

1. $$3(x + 4)$$

   답. $$3x + 12$$. $$x=2$$ 에서 양쪽 다 $$18$$.
2. $$-2(x - 5)$$

   답. $$-2x + 10$$. 부호에 주의합니다. $$x=2$$ 에서 양쪽 다 $$6$$.
3. $$x(x + 7)$$

   답. $$x^2 + 7x$$. $$x=2$$ 에서 양쪽 다 $$18$$.
4. $$(x + 3)(x + 5)$$

   답. $$x^2 + 8x + 15$$. $$x=2$$ 에서 $$5 \times 7 = 35$$ 이고 $$4+16+15 = 35$$.
5. $$(x - 2)(x + 6)$$

   답. $$x^2 + 4x - 12$$. $$x=2$$ 에서 양쪽 다 $$0$$.
6. $$(x + 4)^2$$

   답. $$x^2 + 8x + 16$$. $$x=2$$ 에서 양쪽 다 $$36$$.
7. $$(x - 5)^2$$

   답. $$x^2 - 10x + 25$$. $$x=2$$ 에서 양쪽 다 $$9$$.
8. $$(x + 7)(x - 7)$$

   답. $$x^2 - 49$$. $$x=2$$ 에서 $$9 \times (-5) = -45$$ 이고 $$4 - 49 = -45$$.
9. $$(2x + 1)(x - 3)$$

   답. $$2x^2 - 5x - 3$$. $$x=2$$ 에서 $$5 \times (-1) = -5$$ 이고 $$8 - 10 - 3 = -5$$.
10. $$(3x - 2)^2$$

    답. $$9x^2 - 12x + 4$$. $$x=2$$ 에서 $$4^2 = 16$$ 이고 $$36 - 24 + 4 = 16$$.

### 연습 2 — 인수분해 열 문제

1. $$6x + 9$$

   답. $$3(2x + 3)$$. $$x=2$$ 에서 양쪽 다 $$21$$.
2. $$x^2 - 5x$$

   답. $$x(x - 5)$$. $$x=2$$ 에서 양쪽 다 $$-6$$.
3. $$4x^2 + 6x$$

   답. $$2x(2x + 3)$$. $$x=2$$ 에서 양쪽 다 $$28$$.
4. $$x^2 + 9x + 20$$

   답. 곱이 20, 합이 9인 두 수는 4와 5이므로 $$(x+4)(x+5)$$. $$x=2$$ 에서 양쪽 다 $$42$$.
5. $$x^2 - 7x + 12$$

   답. 끝이 양수이고 가운데가 음수이니 둘 다 음수입니다. $$(x-3)(x-4)$$. $$x=2$$ 에서 양쪽 다 $$2$$.
6. $$x^2 + 2x - 15$$

   답. 끝이 음수이니 부호가 다릅니다. $$(x+5)(x-3)$$. $$x=2$$ 에서 양쪽 다 $$-7$$.
7. $$x^2 - 3x - 10$$

   답. $$(x-5)(x+2)$$. $$x=2$$ 에서 양쪽 다 $$-12$$.
8. $$x^2 + 12x + 36$$

   답. $$36 = 6^2$$ 이고 가운데가 $$2 \times 6$$ 이므로 $$(x+6)^2$$. $$x=2$$ 에서 양쪽 다 $$64$$.
9. $$x^2 - 81$$

   답. $$(x+9)(x-9)$$. $$x=2$$ 에서 양쪽 다 $$-77$$.
10. $$4x^2 - 25$$

    답. $$(2x)^2 - 5^2$$ 이므로 $$(2x+5)(2x-5)$$. $$x=2$$ 에서 양쪽 다 $$-9$$.

연습 2의 3번을 $$x(4x + 6)$$ 이라고 적었다면 틀린 것은 아니지만 다 푼 것도 아닙니다. **괄호 안에 아직 공통인수 2가 남아 있습니다.** 인수분해는 더 이상 안 쪼개질 때까지 갑니다.

## 정리

- **전개는 분배법칙을 문자로 확장한 것**입니다. 앞 괄호의 각 항을 뒤 괄호의 각 항에 하나씩 곱합니다.
- 곱셈 공식 셋은 **정사각형 넓이 그림에서 매번 복원할 수 있습니다.** $$(a+b)^2$$ 이 $$a^2+b^2$$ 이 아닌 이유가 그림의 가운데 두 조각입니다.
- **인수분해는 셋으로 나눠 익힙니다** — 공통인수 빼기, 곱셈 공식 되돌리기, 곱이 끝 항이고 합이 가운데 항인 두 수 찾기.
- 공통인수는 **가장 먼저** 확인하고, 더 이상 안 쪼개질 때까지 갑니다.
- 전개와 인수분해는 같은 식을 다르게 적은 것이므로 **아무 값이나 넣어 검산할 수 있습니다.**

다음 글에서는 방정식을 실제로 풉니다. $$2x + 1 = 7$$ 에서 $$x$$ 를 찾아내는 절차, 그리고 양변에 같은 것을 해도 등호가 유지된다는 원칙을 손에 익힙니다.
