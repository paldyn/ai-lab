[지난 글](/articles/math-basics-integral-as-area)에서 $$\int_0^1 x^2\,dx=\dfrac13$$ 하나를 구하는 데 시그마 공식과 극한이 필요했습니다. $$\sqrt{x}$$ 는 그 공식조차 없어 표를 채우다 말았습니다.

이 글은 그 계산을 한 줄에 끝내는 도구를 만듭니다. 도구는 이미 손에 있습니다 — 미분입니다.

## 누적 넓이 함수

넓이를 구간마다 따로 보지 말고, **왼쪽 끝을 고정하고 오른쪽 끝만 움직여** 봅니다.

$$A(x) = \int_a^x f(t)\,dt$$

$$a$$ 부터 $$x$$ 까지의 넓이입니다. $$x$$ 를 오른쪽으로 밀면 넓이가 늘어나므로 **$$A$$ 는 $$x$$ 의 함수** 입니다. 이것을 **누적 넓이 함수** 라고 합니다.

안쪽 글자가 $$x$$ 가 아니라 $$t$$ 인 것은 자리가 겹치지 않게 하려는 것뿐입니다. 위끝의 $$x$$ 는 어디까지 더할지를 정하는 값이고, 안쪽 글자는 더해 나가는 동안 움직이는 값이라 둘을 갈라 적습니다.

## 이 함수를 미분해 본다

$$A$$ 도 함수이므로 미분할 수 있습니다. 정의식을 씁니다.

$$\frac{A(x+h)-A(x)}{h}$$

분자는 **$$x$$ 까지의 넓이와 $$x+h$$ 까지의 넓이의 차이** 이므로, 그 사이의 얇은 띠 하나의 넓이입니다.

![누적 넓이가 폭 h짜리 띠 하나만큼 늘어나는 그림](/assets/posts/math-basics-fundamental-theorem-of-calculus-accumulation.svg)

$$h$$ 가 작으면 그 띠는 거의 직사각형입니다. 폭이 $$h$$ 이고 높이가 $$f(x)$$ 이므로

$$A(x+h)-A(x) \approx f(x)\cdot h$$

양변을 $$h$$ 로 나눕니다.

$$\frac{A(x+h)-A(x)}{h} \approx f(x)$$

$$h$$ 를 0으로 보내면 왼쪽은 $$A'(x)$$ 의 정의 그 자체이고, 오른쪽의 근사는 정확해집니다. 위쪽에 남던 얇은 조각이 먼저 사라지기 때문입니다.

$$A'(x) = f(x)$$

**넓이를 쌓아 온 함수를 미분하면 원래 함수가 나옵니다.** 이것이 **미적분의 기본정리** 입니다.

## 넓이를 구하는 데 어떻게 쓰는가

$$A'=f$$ 라는 말은 거꾸로 읽으면 **미분해서 $$f$$ 가 되는 함수를 찾으면 그것이 넓이를 재 준다** 는 뜻입니다.

미분해서 $$f$$ 가 되는 함수를 $$F$$ 라고 부릅니다. 그러면

$$\int_a^b f(x)\,dx = F(b)-F(a)$$

$$F(b)$$ 는 $$a$$ 부터 $$b$$ 까지의 넓이이고 $$F(a)$$ 는 $$a$$ 부터 $$a$$ 까지라 0이므로 빼 준 것인데, 실제로는 $$F$$ 를 어떻게 잡아도 이 뺄셈에서 차이가 지워집니다. 아래에서 다시 봅니다.

$$F(b)-F(a)$$ 는 자주 쓰는 모양이라 표기가 따로 있습니다.

$$\Bigl[F(x)\Bigr]_a^b = F(b)-F(a)$$

### 지난 글의 답을 한 줄에 다시 얻는다

$$\int_0^1 x^2\,dx$$ 를 이걸로 풉니다. **미분해서 $$x^2$$ 이 되는 함수** 를 찾습니다. [32번 글](/articles/math-basics-derivative-rules)의 $$x^n\to nx^{n-1}$$ 을 거꾸로 읽으면 지수를 하나 올리고 그 수로 나누면 됩니다.

$$F(x)=\frac{x^3}{3} \quad\Longrightarrow\quad F'(x)=\frac{3x^2}{3}=x^2$$

이제 끝점을 넣고 뺍니다.

$$\int_0^1 x^2\,dx = \left[\frac{x^3}{3}\right]_0^1 = \frac13-0 = \frac13$$

**지난 글이 시그마 공식과 극한으로 얻은 답을 한 줄에 얻었습니다.** 두 방법이 같은 답을 줍니다.

## 부정적분과 +C

미분해서 $$x^2$$ 이 되는 함수가 $$\dfrac{x^3}{3}$$ 하나뿐일까요. $$\dfrac{x^3}{3}+5$$ 도 미분하면 $$x^2$$ 입니다. **상수는 미분하면 0이 되어 사라지기 때문입니다.**

![미분과 적분이 서로를 되돌리되 적분 쪽에만 C가 붙는 그림](/assets/posts/math-basics-fundamental-theorem-of-calculus-inverse-pair.svg)

그래서 미분해서 $$f$$ 가 되는 함수는 하나가 아니라 **상수만큼 어긋난 무리 전체** 입니다. 이 무리를 **부정적분** 이라고 하고 끝을 적지 않은 $$\int$$ 로 씁니다.

$$\int x^2\,dx = \frac{x^3}{3}+C$$

$$C$$ 를 **적분상수** 라고 합니다. "얼마인지 모르는 상수 하나"라는 뜻입니다.

**정적분에서는 이 $$C$$ 가 걱정되지 않습니다.** $$F(b)-F(a)$$ 에서 $$(F(b)+C)-(F(a)+C)$$ 가 되어 서로 지워지기 때문입니다. 그래서 정적분을 계산할 때는 $$C$$ 를 아예 적지 않습니다.

## 기본 적분 표

32번 글의 도함수 표를 오른쪽에서 왼쪽으로 읽으면 그대로 적분 표가 됩니다.

| $$f(x)$$ | $$\displaystyle\int f(x)\,dx$$ |
| --- | --- |
| $$x^n$$ ($$n\ne-1$$) | $$\dfrac{x^{n+1}}{n+1}+C$$ |
| $$\dfrac1x$$ | $$\ln\lvert x\rvert+C$$ |
| $$e^x$$ | $$e^x+C$$ |
| $$\sin x$$ | $$-\cos x+C$$ |
| $$\cos x$$ | $$\sin x+C$$ |

읽을 때 걸리는 자리가 셋 있습니다.

- **$$n=-1$$ 만 빠져 있습니다.** 지수를 하나 올리면 0이 되어 0으로 나누게 되기 때문입니다. 그 자리를 $$\ln$$ 이 대신 맡습니다.
- **$$\ln$$ 에 절댓값이 붙습니다.** $$\ln$$ 은 음수를 못 받는데 $$\dfrac1x$$ 은 $$x$$ 가 음수여도 값이 있기 때문입니다.
- **$$\sin$$ 쪽에 마이너스가 나옵니다.** $$\cos$$ 을 미분하면 $$-\sin$$ 이었으니 거꾸로 오면서 부호가 따라옵니다.

$$\int_0^{\pi} \sin x\,dx$$ 로 써 봅니다.

$$\Bigl[-\cos x\Bigr]_0^{\pi} = -\cos\pi - (-\cos 0) = -(-1)+1 = 2$$

## 치환적분

표에 없는 모양은 규칙을 거꾸로 돌려 만듭니다. 먼저 연쇄법칙입니다.

$$\int 2x\,e^{x^2}\,dx$$

표에 없습니다. 그런데 이 식을 미분 쪽에서 보면 낯익습니다 — $$e^{x^2}$$ 을 미분하면 겉이 $$e^{x^2}$$, 속 $$x^2$$ 의 도함수가 $$2x$$ 라서 정확히 이 모양이 나옵니다.

![연쇄법칙을 거꾸로 돌려 u로 묶어 적분하는 세 단계 그림](/assets/posts/math-basics-fundamental-theorem-of-calculus-substitution.svg)

**속을 $$u$$ 로 두고 통째로 바꿔 쓰는 방법을 치환적분이라고 합니다.**

1. $$u=x^2$$ 으로 둡니다. 그러면 $$\dfrac{du}{dx}=2x$$ 이므로 $$du = 2x\,dx$$ 입니다.
2. 식에서 $$2x\,dx$$ 자리에 $$du$$ 를, $$x^2$$ 자리에 $$u$$ 를 넣습니다.

$$\int 2x\,e^{x^2}\,dx = \int e^u\,du = e^u + C$$

3. $$u$$ 를 도로 $$x^2$$ 으로 돌립니다.

$$= e^{x^2}+C$$

맞는지 미분해 봅니다. $$e^{x^2}$$ 을 미분하면 $$e^{x^2}\cdot2x$$ 입니다. **적분은 미분해서 확인할 수 있습니다** — 이 점검을 매번 하는 것이 좋습니다.

**무엇을 $$u$$ 로 잡을지의 기준은 하나입니다 — 식 안에 그것의 도함수가 곱해져 있는 것.** 위에서는 $$2x$$ 가 $$x^2$$ 의 도함수라서 $$x^2$$ 이 $$u$$ 였습니다.

## 부분적분

이번에는 곱의 규칙을 거꾸로 돌립니다.

$$(fg)' = f'g + fg'$$

양변을 적분합니다. 왼쪽은 미분한 것을 도로 적분하는 것이라 $$fg$$ 로 돌아옵니다.

$$fg = \int f'g\,dx + \int fg'\,dx$$

$$\int fg'\,dx$$ 에 대해 풀면

$$\int f\,g'\,dx = fg - \int f'g\,dx$$

**이것을 부분적분이라고 합니다.** 흔히 $$f$$ 를 $$u$$, $$g'\,dx$$ 를 $$dv$$ 로 적어 이렇게 씁니다.

$$\int u\,dv = uv - \int v\,du$$

**하는 일은 적분을 없애는 것이 아니라 더 쉬운 적분으로 바꿔 넘기는 것입니다.** 오른쪽에 여전히 적분이 남아 있고, 그것이 원래보다 쉬워야 이득입니다.

### 무엇을 u로 잡을까

![u는 미분해서 간단해지는 쪽으로 고른다는 절차 그림](/assets/posts/math-basics-fundamental-theorem-of-calculus-by-parts-choice.svg)

$$u$$ 는 **미분하면 간단해지는 쪽** 으로 잡습니다. $$u$$ 쪽은 나중에 $$du$$ 로 미분되어 오른쪽 적분에 들어가기 때문입니다.

- $$\ln x$$ 는 미분하면 $$\dfrac1x$$ 로 로그가 사라집니다. **있으면 무조건 이것이 $$u$$ 입니다.**
- 다항식은 미분하면 차수가 하나 줄어듭니다. $$\ln$$ 이 없으면 이것이 $$u$$ 입니다.
- $$e^x$$ 과 $$\sin x$$ 는 미분해도 그대로라 줄어들지 않습니다. 이쪽이 $$dv$$ 입니다.

### 셋을 손으로 푼다

**$$\int x\,e^x\,dx$$.** $$\ln$$ 이 없으니 다항식 $$x$$ 가 $$u$$ 이고 $$e^x\,dx$$ 가 $$dv$$ 입니다. 그러면 $$du=dx$$ 이고 $$v=e^x$$ 입니다.

$$\int x\,e^x\,dx = x\,e^x - \int e^x\,dx = x\,e^x - e^x + C = (x-1)e^x+C$$

미분해 확인합니다 — $$e^x + (x-1)e^x = x\,e^x$$ 로 맞습니다.

**$$\int x\sin x\,dx$$.** $$u=x$$, $$dv=\sin x\,dx$$ 이므로 $$du=dx$$, $$v=-\cos x$$ 입니다.

$$\int x\sin x\,dx = -x\cos x - \int(-\cos x)\,dx = -x\cos x + \sin x + C$$

미분해 확인합니다 — $$-\cos x + x\sin x + \cos x = x\sin x$$ 로 맞습니다.

**$$\int \ln x\,dx$$.** 곱이 아닌데도 부분적분이 통하는 자리입니다. $$\ln x$$ 가 있으니 $$u=\ln x$$ 이고, 남는 $$dx$$ 가 통째로 $$dv$$ 입니다. 그러면 $$du=\dfrac1x\,dx$$ 이고 $$v=x$$ 입니다.

$$\int \ln x\,dx = x\ln x - \int x\cdot\frac1x\,dx = x\ln x - \int 1\,dx = x\ln x - x + C$$

미분해 확인합니다 — $$\ln x + x\cdot\dfrac1x - 1 = \ln x$$ 로 맞습니다.

**$$u$$ 를 반대로 잡았다면** 오른쪽에 남는 적분이 원래보다 어려워집니다. $$\int x\,e^x\,dx$$ 에서 $$u=e^x$$ 으로 잡으면 오른쪽에 $$\int \dfrac{x^2}{2}e^x\,dx$$ 가 남아 차수가 오히려 올라갑니다. **그렇게 되면 두 자리를 맞바꿔 다시 합니다.**

## 연습 문제

### 연습 1 — 정적분 여덟 문제

미분해서 그 함수가 되는 것을 찾고 끝점을 넣어 뺍니다.

1. $$\int_0^2 x^3\,dx$$

   답. $$\left[\dfrac{x^4}{4}\right]_0^2 = \dfrac{16}{4}-0 = 4$$ 입니다.
2. $$\int_1^3 (2x+1)\,dx$$

   답. $$\bigl[x^2+x\bigr]_1^3 = (9+3)-(1+1) = 10$$ 입니다.
3. $$\int_0^1 e^x\,dx$$

   답. $$\bigl[e^x\bigr]_0^1 = e-1 \approx 1.71828$$ 입니다.
4. $$\int_1^e \dfrac1x\,dx$$

   답. $$\bigl[\ln x\bigr]_1^e = 1-0 = 1$$ 입니다. $$\ln e=1$$ 이고 $$\ln 1=0$$ 입니다.
5. $$\int_0^{\pi/2}\cos x\,dx$$

   답. $$\bigl[\sin x\bigr]_0^{\pi/2} = 1-0 = 1$$ 입니다.
6. $$\int_1^4 \sqrt{x}\,dx$$

   답. $$x^{1/2}$$ 이므로 지수를 올려 $$\dfrac{x^{3/2}}{3/2}=\dfrac23x^{3/2}$$ 입니다. $$\left[\dfrac23x^{3/2}\right]_1^4 = \dfrac{16}{3}-\dfrac23 = \dfrac{14}{3}$$ 입니다.
7. $$\int_{-1}^{1} x^3\,dx$$

   답. $$\left[\dfrac{x^4}{4}\right]_{-1}^{1} = \dfrac14-\dfrac14 = 0$$ 입니다. 축 위와 아래의 넓이가 같고 부호가 반대라 지워집니다.
8. $$\int_0^1 (3x^2-2x)\,dx$$

   답. $$\bigl[x^3-x^2\bigr]_0^1 = (1-1)-0 = 0$$ 입니다.

### 연습 2 — 치환적분 세 문제

식 안에 도함수가 곱해져 있는 덩어리를 찾습니다.

1. $$\int 2x(x^2+1)^3\,dx$$

   답. $$u=x^2+1$$ 이면 $$du=2x\,dx$$ 이므로 $$\int u^3\,du = \dfrac{u^4}{4}+C = \dfrac{(x^2+1)^4}{4}+C$$ 입니다.
2. $$\int \cos(3x)\,dx$$

   답. $$u=3x$$ 이면 $$du=3\,dx$$ 이므로 $$dx=\dfrac{du}{3}$$ 입니다. $$\dfrac13\int\cos u\,du = \dfrac13\sin(3x)+C$$ 입니다.
3. $$\int \dfrac{x}{x^2+1}\,dx$$

   답. $$u=x^2+1$$ 이면 $$du=2x\,dx$$ 이므로 $$x\,dx=\dfrac{du}{2}$$ 입니다. $$\dfrac12\int\dfrac{du}{u} = \dfrac12\ln(x^2+1)+C$$ 입니다. 분모가 늘 양수라 절댓값을 벗겼습니다.

### 연습 3 — 부분적분 세 문제

미분해서 간단해지는 쪽을 $$u$$ 로 잡습니다.

1. $$\int x\cos x\,dx$$

   답. $$u=x$$, $$dv=\cos x\,dx$$ 이므로 $$v=\sin x$$ 입니다. $$x\sin x-\int\sin x\,dx = x\sin x+\cos x+C$$ 입니다.
2. $$\int x\,e^{2x}\,dx$$

   답. $$u=x$$, $$dv=e^{2x}dx$$ 이므로 $$v=\dfrac12e^{2x}$$ 입니다. $$\dfrac{x}{2}e^{2x}-\dfrac12\int e^{2x}dx = \dfrac{x}{2}e^{2x}-\dfrac14e^{2x}+C$$ 입니다.
3. $$\int x^2\ln x\,dx$$

   답. $$\ln$$ 이 있으므로 $$u=\ln x$$, $$dv=x^2dx$$ 이고 $$v=\dfrac{x^3}{3}$$ 입니다. $$\dfrac{x^3}{3}\ln x-\int\dfrac{x^3}{3}\cdot\dfrac1x\,dx = \dfrac{x^3}{3}\ln x-\dfrac{x^3}{9}+C$$ 입니다.

## 정리

- 누적 넓이 함수 $$A(x)=\int_a^x f$$ 를 미분하면 $$A'(x)=f(x)$$ 입니다. 이것이 **미적분의 기본정리** 입니다.
- 그래서 미분해서 $$f$$ 가 되는 $$F$$ 를 찾으면 $$\int_a^b f = F(b)-F(a)$$ 로 넓이가 나옵니다. 리만합이 필요 없습니다.
- 그런 $$F$$ 는 상수만큼 어긋난 무리 전체이고 이것을 **부정적분** 이라고 씁니다. 정적분에서는 $$C$$ 가 뺄셈에서 지워집니다.
- 기본 적분 표는 도함수 표를 거꾸로 읽은 것입니다. $$n=-1$$ 만 빠지고 그 자리를 $$\ln\lvert x\rvert$$ 가 맡습니다.
- **치환적분** 은 연쇄법칙을 거꾸로 돌린 것이고, 도함수가 곱해져 있는 덩어리를 $$u$$ 로 잡습니다.
- **부분적분** 은 곱의 규칙을 거꾸로 돌린 것이고, 미분해서 간단해지는 쪽을 $$u$$ 로 잡습니다. 결과는 늘 미분해서 확인할 수 있습니다.

미분과 적분이 여기서 한 쌍으로 묶였습니다. 다음 글은 미분을 다시 꺼내 씁니다 — 접선 하나로 곡선을 흉내 내다가, 항을 더 붙이면 얼마나 잘 흉내 낼 수 있는지를 봅니다.
