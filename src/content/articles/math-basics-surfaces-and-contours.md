지금까지 다룬 함수는 전부 입력 하나에 출력 하나였습니다. $$y = f(x)$$ 처럼요.

이번에는 입력을 둘로 늘립니다. $$z = f(x, y)$$ 는 **평면 위 각 점 $$(x, y)$$ 에 하나의 높이 $$z$$ 를 얹은 것**입니다. 예를 들어

$$z = x^2 + y^2$$

는 원점에서 0이고 원점에서 멀어질수록 커지는 함수입니다. **$$(1, 0)$$ 에서는 1, $$(0, 2)$$ 에서는 4, $$(3, 4)$$ 에서는 25.**

## 같은 함수를 보는 세 가지 방법

두 변수 함수를 눈에 익히는 방법이 셋 있습니다. **세 방법이 모두 같은 함수를 다른 언어로 그린 것**입니다.

**첫째, 3차원 곡면입니다.** $$x$$·$$y$$ 평면 위에 각 점의 높이 $$z$$ 를 얹으면 종이 위로 튀어 오르는 곡면이 그려집니다. $$z = x^2 + y^2$$ 는 그릇처럼 생긴 면이 됩니다. 종이에 그리기가 번거로운 것이 흠입니다.

**둘째, 등고선입니다.** 같은 높이가 되는 점들을 잇는 선을 그립니다. 지도의 등고선과 같은 얼개입니다. $$z = 1$$ 이 되는 점은 $$x^2 + y^2 = 1$$ 을 만족하는 점들이니 반지름 1인 원이고, $$z = 4$$ 는 반지름 2인 원입니다. **등고선이 촘촘한 곳이 가파르고, 멀리 떨어진 곳이 완만한 곳**입니다.

**셋째, 단면입니다.** 한 변수를 상수로 고정하면 나머지 하나로만 움직이는 1변수 함수가 남습니다. $$z = x^2 + y^2$$ 에서 $$y = 0$$ 을 고정하면 $$z = x^2$$ 이라는 [23번 · 이차함수와 포물선](/articles/math-basics-quadratic-and-parabola)의 포물선이 나오고, $$x = 0$$ 을 고정해도 $$z = y^2$$ 로 같은 포물선입니다.

## 네 가지 함수를 등고선으로 견주기

이 세 언어 중 **등고선이 가장 실용적**입니다. 종이 위에 그릴 수 있고, 여러 함수를 나란히 놓고 견주기 쉽습니다.

![그릇·안장·골짜기·봉우리 네 함수의 등고선](/assets/posts/math-basics-surfaces-and-contours-four-contours.svg)

**첫째, 그릇 $$z = x^2 + y^2$$.** 등고선이 원점을 가운데 둔 동심원입니다. $$z = 1$$ 이 반지름 1인 원, $$z = 2$$ 가 반지름 $$\sqrt{2}$$, $$z = 4$$ 가 반지름 2 — **높이가 두 배가 될 때마다 반지름은 $$\sqrt{2}$$ 배씩** 늘어납니다. 원점에서 어느 방향으로 나가도 대칭입니다.

**둘째, 안장 $$z = x^2 - y^2$$.** $$x^2 - y^2 = k$$ 는 [24번](/articles/math-basics-coordinate-plane-and-lines)에서 다룬 좌표평면 위의 **쌍곡선**입니다 — $$k > 0$$ 이면 좌우로 열리고, $$k < 0$$ 이면 위아래로 열립니다. **$$x$$ 방향으로는 올라가고 $$y$$ 방향으로는 내려가는 이 모양이 안장이고**, 원점을 지나는 두 대각선 $$y = \pm x$$ 는 $$z = 0$$ 인 자리입니다.

**셋째, 골짜기 $$z = x^2 + 10y^2$$.** 등고선이 원이 아니라 가로로 긴 **타원**입니다. $$z = 1$$ 이 되려면 $$x = 1$$ 이면 $$y = 0$$ 이어야 하지만 $$y = 1/\sqrt{10} \approx 0.316$$ 이면 $$x = 0$$ 으로 충분합니다 — **$$y$$ 는 조금만 움직여도 같은 높이가 됩니다.** 이 늘어진 정도가 계수 비 $$1 : 10$$ 에서 옵니다.

**넷째, 봉우리 $$z = \exp\!\left(-\dfrac{x^2 + y^2}{2}\right)$$.** 이번에는 원점이 가장 높은 자리($$z = 1$$)이고 밖으로 갈수록 낮아집니다. $$z = c$$ 를 풀면 $$x^2 + y^2 = -2 \ln c$$ 이므로 등고선은 원인데, **$$c$$ 가 작을수록 원이 큽니다** — 낮은 높이는 원점에서 멀리 그려집니다.

## 편미분 — 단면에서 하는 보통의 미분

두 변수 함수의 변화율은 어떻게 잴까요. **한 방향씩 나눠서** 잽니다. **다른 변수를 상수로 고정한 뒤 하나에 대해서만 미분하는 것**을 편미분이라 하고 $$\partial$$ 을 붙여 적습니다. $$x$$ 에 대한 편미분은 $$\dfrac{\partial f}{\partial x}$$ 입니다.

![y=0 단면을 잘라내 그 위에서 x로 미분하는 것이 ∂f/∂x](/assets/posts/math-basics-surfaces-and-contours-surface-section.svg)

**계산 자체는 새로울 것이 없습니다.** [32번 · 도함수 계산 규칙](/articles/math-basics-derivative-rules)을 그대로 씁니다 — 다른 변수를 상수 문자로 취급하면 됩니다.

$$f(x, y) = x^2 + y^2$$ 의 두 편도함수는

$$\frac{\partial f}{\partial x} = 2x, \qquad \frac{\partial f}{\partial y} = 2y$$

$$x$$ 로 미분할 때는 $$y^2$$ 이 상수라 사라지고, $$y$$ 로 미분할 때는 $$x^2$$ 이 사라집니다.

네 함수의 편도함수를 표로 정리합니다.

| 함수 | $$\partial f / \partial x$$ | $$\partial f / \partial y$$ |
| --- | --- | --- |
| $$x^2 + y^2$$ | $$2x$$ | $$2y$$ |
| $$x^2 - y^2$$ | $$2x$$ | $$-2y$$ |
| $$x^2 + 10y^2$$ | $$2x$$ | $$20y$$ |
| $$\exp(-(x^2+y^2)/2)$$ | $$-x \cdot \exp(-(x^2+y^2)/2)$$ | $$-y \cdot \exp(-(x^2+y^2)/2)$$ |

네 번째는 합성함수라 [32번](/articles/math-basics-derivative-rules)의 연쇄법칙을 써서 안쪽 $$-(x^2+y^2)/2$$ 를 $$x$$ 로 미분한 $$-x$$ 를 지수함수의 도함수 $$\exp(\cdot)$$ 뒤에 곱한 결과입니다.

**두 편도함수를 하나로 묶어 다루는 그래디언트 벡터는 중급 32번의 것**이라 이 글은 두 개를 따로따로 계산하는 데까지만 갑니다.

## 두 변수 함수 아래의 부피 — 이중적분

[33번 · 정적분](/articles/math-basics-integral-as-area)에서 1변수 함수 아래의 **넓이**를 잘게 나눠 더했습니다. 두 변수 함수의 자연스러운 대응물은 **부피**입니다 — $$z = f(x, y)$$ 가 $$xy$$ 평면 위에 얹은 지붕과 그 아래 바닥 사이의 공간이 부피입니다.

**계산은 자로 잰 것이 아니라 방금 다룬 단면을 두 번 쓰는 것**입니다. $$x$$ 를 하나 고정하면 $$z = f(x, y)$$ 는 $$y$$ 만의 1변수 함수가 됩니다. 이 함수를 $$y$$ 로 적분한 값이 그 $$x$$ 에서의 세로 단면 넓이입니다. **이 넓이를 다시 $$x$$ 축을 따라 더하면 전체 부피**가 됩니다.

![세로 단면 넓이를 x축을 따라 다시 더한다](/assets/posts/math-basics-surfaces-and-contours-double-integral.svg)

기호로 적으면 이렇습니다.

$$\iint_R f(x, y)\, dx\, dy = \int_a^b \left[ \int_c^d f(x, y)\, dy \right] dx$$

**안쪽 대괄호가 세로 단면의 넓이, 바깥쪽 적분이 그 넓이들의 합**입니다. **직사각형 구간 위에서는 순서를 바꿔도 같은 값이 나옵니다** — 언제 그래도 되는지의 정확한 조건은 이 트랙 밖의 이야기라 여기서는 결과만 씁니다.

두 예로 확인합니다.

### 예 1 — $$f(x, y) = xy$$, $$R = [0, 1] \times [0, 2]$$

먼저 $$x$$ 를 상수로 두고 $$y$$ 로 적분합니다.

$$\int_0^2 xy\, dy = x \int_0^2 y\, dy = x \cdot \left[\frac{y^2}{2}\right]_0^2 = x \cdot 2 = 2x$$

이제 이것을 $$x$$ 로 다시 적분합니다.

$$\int_0^1 2x\, dx = \left[x^2\right]_0^1 = 1$$

**순서를 바꿔 봅니다** — 먼저 $$y$$ 를 상수로 두고 $$x$$ 로 적분한 뒤 $$y$$ 로.

$$\int_0^1 xy\, dx = y \cdot \left[\frac{x^2}{2}\right]_0^1 = \frac{y}{2}$$

$$\int_0^2 \frac{y}{2}\, dy = \left[\frac{y^2}{4}\right]_0^2 = 1$$

**같은 값 1**이 나왔습니다.

### 예 2 — $$f(x, y) = x + y$$, $$R = [0, 1] \times [0, 1]$$

$$\int_0^1 \left[ \int_0^1 (x + y)\, dy \right] dx = \int_0^1 \left[ xy + \frac{y^2}{2} \right]_0^1 dx = \int_0^1 \left( x + \frac{1}{2} \right) dx = \frac{1}{2} + \frac{1}{2} = 1$$

순서를 바꾸면

$$\int_0^1 \left[ \int_0^1 (x + y)\, dx \right] dy = \int_0^1 \left[ \frac{x^2}{2} + xy \right]_0^1 dy = \int_0^1 \left( \frac{1}{2} + y \right) dy = \frac{1}{2} + \frac{1}{2} = 1$$

**두 번 다 같은 값**입니다.

## 변수가 셋을 넘으면

두 변수까지는 종이 위에 그림이 됩니다. **세 변수부터는 그림이 안 됩니다** — $$w = f(x, y, z)$$ 는 각 3차원 점에 하나의 수를 얹은 것인데, 우리가 볼 수 있는 것은 3차원까지라 그 위에 얹은 수를 그릴 자리가 없습니다.

그래서 앞으로 함수가 여러 변수를 가지면 **"지형"·"등고선"·"단면"** 같은 말이 그림 없이 은유로만 남습니다. 계산 자체는 편미분과 이중적분을 그대로 확장하지만, 그림을 그려 눈으로 확인하는 재미는 두 변수까지가 마지막입니다.

## 연습 문제

### 연습 1 — 값과 등고선

1. $$f(x, y) = x^2 + y^2$$ 에 대해 $$f(1, 2)$$, $$f(-1, 3)$$, $$f(0, 0)$$ 을 각각 구하세요.

   답. $$f(1, 2) = 1 + 4 = 5$$, $$f(-1, 3) = 1 + 9 = 10$$, $$f(0, 0) = 0$$ 입니다.
2. $$f(x, y) = x^2 - y^2$$ 의 등고선 $$f = 0$$ 을 이루는 점들의 방정식을 적고, 좌표평면 위에 어떤 모양인지 한 문장으로 답하세요.

   답. $$x^2 - y^2 = 0$$ 은 $$(x - y)(x + y) = 0$$ 이므로 $$y = x$$ 또는 $$y = -x$$ 입니다. 원점에서 서로 수직으로 교차하는 **두 직선**입니다.
3. $$f(x, y) = x^2 + 10y^2$$ 의 등고선 $$f = 10$$ 을 이루는 점들의 방정식을 적고, 반지름이 아니라 반축 길이를 $$x$$·$$y$$ 방향 각각에 대해 답하세요.

   답. $$x^2 + 10y^2 = 10$$ 이므로 $$\dfrac{x^2}{10} + y^2 = 1$$ 입니다. $$x$$ 방향 반축 길이가 $$\sqrt{10} \approx 3.16$$, $$y$$ 방향 반축 길이가 1인 **가로로 늘어진 타원**입니다.

### 연습 2 — 편도함수 계산

1. $$f(x, y) = 3x^2 y + y^3$$ 의 두 편도함수 $$\partial f/\partial x$$ 와 $$\partial f/\partial y$$ 를 구하세요.

   답. $$x$$ 로 미분할 때 $$y^3$$ 은 상수이므로 사라지고 $$3x^2 y$$ 만 남아 $$\partial f/\partial x = 6xy$$ 입니다. $$y$$ 로 미분할 때 $$3x^2 y$$ 는 $$3x^2$$ 이 상수라 $$3x^2$$ 이 남고, $$y^3$$ 의 도함수는 $$3y^2$$ 이라 $$\partial f/\partial y = 3x^2 + 3y^2$$ 입니다.
2. $$f(x, y) = \sin(xy)$$ 의 두 편도함수를 구하세요.

   답. 연쇄법칙을 씁니다. $$x$$ 로 미분: 안쪽 $$xy$$ 를 $$x$$ 로 미분한 것이 $$y$$ 이므로 $$\partial f/\partial x = y \cos(xy)$$. $$y$$ 로 미분: 안쪽 $$xy$$ 를 $$y$$ 로 미분한 것이 $$x$$ 이므로 $$\partial f/\partial y = x \cos(xy)$$.
3. $$f(x, y) = \exp(-(x^2 + y^2)/2)$$ 의 두 편도함수를 구하고, 두 결과 모두 원래 함수에 무엇을 곱한 꼴인지 한 줄로 적으세요.

   답. 안쪽 $$-(x^2 + y^2)/2$$ 를 $$x$$ 로 미분한 $$-x$$ 를 곱해 $$\partial f/\partial x = -x \cdot \exp(-(x^2+y^2)/2)$$. 같은 방식으로 $$\partial f/\partial y = -y \cdot \exp(-(x^2+y^2)/2)$$. **원래 함수 값에 각각 $$-x$$, $$-y$$ 를 곱한 꼴**입니다 — 원점에서 두 편도함수가 모두 0이 되는 것이 여기서 옵니다.

### 연습 3 — 이중적분과 순서 바꾸기

1. $$R = [0, 1] \times [0, 3]$$ 에서 $$\iint_R x^2 y\, dx\, dy$$ 를 계산하세요.

   답. $$\int_0^3 \int_0^1 x^2 y\, dx\, dy = \int_0^3 y \left[\dfrac{x^3}{3}\right]_0^1 dy = \int_0^3 \dfrac{y}{3}\, dy = \left[\dfrac{y^2}{6}\right]_0^3 = \dfrac{9}{6} = \dfrac{3}{2}$$ 입니다.
2. 같은 문제를 순서를 바꿔 $$\int_0^1 \int_0^3 x^2 y\, dy\, dx$$ 로 계산해 같은 값이 나오는지 확인하세요.

   답. $$\int_0^1 x^2 \left[\dfrac{y^2}{2}\right]_0^3 dx = \int_0^1 x^2 \cdot \dfrac{9}{2}\, dx = \dfrac{9}{2} \cdot \left[\dfrac{x^3}{3}\right]_0^1 = \dfrac{9}{2} \cdot \dfrac{1}{3} = \dfrac{3}{2}$$ 입니다. 같은 값입니다.
3. $$R = [0, 2] \times [0, 1]$$ 에서 $$\iint_R (2x + 3y)\, dx\, dy$$ 를 계산하세요.

   답. $$\int_0^1 \int_0^2 (2x + 3y)\, dx\, dy = \int_0^1 \left[x^2 + 3yx\right]_0^2 dy = \int_0^1 (4 + 6y)\, dy = \left[4y + 3y^2\right]_0^1 = 4 + 3 = 7$$ 입니다.

## 정리

- **두 변수 함수 $$z = f(x, y)$$ 는 평면 위 각 점에 하나의 높이를 얹은 것**이고, 곡면·등고선·단면 세 방법으로 볼 수 있습니다. **등고선이 가장 실용적**입니다.
- 그릇($$x^2 + y^2$$, 동심원), 안장($$x^2 - y^2$$, 쌍곡선), 골짜기($$x^2 + 10y^2$$, 늘어진 타원), 봉우리($$\exp(-(x^2+y^2)/2)$$, 가운데가 가장 높은 원)는 각각 다른 모양의 등고선을 갖습니다.
- **편미분 $$\partial f/\partial x$$ 는 다른 변수를 상수로 두고 $$x$$ 로만 하는 보통의 미분**입니다. 32번의 도함수 계산 규칙을 그대로 씁니다.
- **두 변수 함수 아래의 부피가 이중적분** $$\iint_R f\, dx\, dy$$ 이고, 이것은 **1축 적분을 두 번** 한 것입니다 — 안쪽 적분이 한 축 단면의 넓이, 바깥 적분이 그 넓이의 합.
- **직사각형 구간에서는 적분 순서를 바꿔도 같은 값**이 나옵니다.
- **변수가 셋을 넘으면 그림이 안 됩니다.** 계산은 확장되지만 눈으로 보는 재미는 두 변수까지가 마지막입니다.

여기까지가 초급 트랙의 다변수 얼개입니다. 다음 글은 지금까지 여러 번 나온 "왜"라는 물음을 다루는 언어 자체 — 수학의 증명을 어떻게 읽는가 — 를 세웁니다.
