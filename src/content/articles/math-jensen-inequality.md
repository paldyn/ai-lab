확산 모델이나 VAE의 학습 코드를 열면 손실이 이렇게 생겼습니다.

```python
loss = -(recon_term - kl_term)      # = -ELBO
```

`ELBO`는 evidence lower bound, 우리말로 **증거 하한**입니다. 이름에 「하한」이 박혀 있습니다. 모델이 진짜로 키우고 싶은 것은 데이터의 로그가능도 $$\log p(x)$$ 인데, 그 값은 숨은 변수에 대한 적분이라 계산할 수 없습니다. 그래서 **계산할 수 있는 다른 값**을 대신 최대화합니다.

이상하게 들리는 대목이 여기입니다. 목표를 대신할 값을 아무거나 골라서는 안 될 텐데, 무엇이 이 바꿔치기를 정당하게 만드는가. 답은 부등호 하나이고, 그 부등호의 이름이 **젠센 부등식**입니다. [지난 글](/articles/math-cross-entropy-and-nll)에서 「$$H(p,q) - H(p)$$ 는 음수가 될 수 없다」고 적어 놓고 증명을 미뤘는데, 그것도 같은 부등호에서 나옵니다. 이 글에서 도구 하나를 세우고 빚 둘을 갚습니다.

## 볼록함수 — 현이 그래프 위에 있다

두 점을 이은 선분을 **현**(chord)이라고 합니다. 볼록성의 정의는 그 현의 위치에 대한 이야기입니다.

> **정의.** 함수 $$f$$ 가 **볼록**(convex)하다는 것은 정의역의 임의의 두 점 $$a$$, $$b$$ 와 $$0 \le \lambda \le 1$$ 에 대해
> $$f(\lambda a + (1-\lambda) b) \;\le\; \lambda f(a) + (1-\lambda) f(b)$$
> 가 성립한다는 뜻이다.

왼쪽은 **두 점 사이의 어떤 자리에서 잰 함숫값**이고, 오른쪽은 **같은 자리에서 잰 현의 높이**입니다. 부등호는 「그래프가 현보다 아래에 있다」를 적은 것입니다.

![볼록함수는 현이 언제나 그래프 위에 있다](/assets/posts/math-jensen-inequality-chord.svg)

부등호가 반대이면 **오목**(concave)하다고 합니다. $$f$$ 가 오목한 것과 $$-f$$ 가 볼록한 것은 같은 말이라, 오목함수를 따로 다룰 필요는 없습니다. 부호만 뒤집으면 됩니다.

$$\lambda$$ 를 0과 1로 놓으면 양변이 같아지니 등호는 늘 가능합니다. 눈여겨볼 자리는 **$$0 < \lambda < 1$$ 에서도 등호가 서는가**입니다. 직선은 현이 그래프와 겹치므로 언제나 등호이고, 이것이 뒤에서 등호 조건을 말할 때 다시 나옵니다.

## 이계도함수로 판정하기

정의를 그대로 확인하는 것은 번거롭습니다. 두 번 미분되는 함수라면 훨씬 쉬운 판정법이 있습니다.

> **판정.** $$f$$ 가 두 번 미분 가능하면, $$f$$ 가 볼록한 것과 모든 점에서 $$f''(x) \ge 0$$ 인 것은 같은 말이다.

$$f''$$ 은 기울기의 변화율이니, $$f'' \ge 0$$ 은 **기울기가 줄지 않는다**는 뜻입니다. 왼쪽에서 완만하게 시작해 오른쪽으로 갈수록 가팔라지는 모양이고, 그런 곡선은 현 아래에 놓입니다. AI에서 자주 만나는 함수들을 이 판정으로 갈라 봅니다.

| 함수 | $$f''(x)$$ | 갈래 |
| --- | --- | --- |
| $$x^2$$ | $$2$$ | 볼록 |
| $$e^x$$ | $$e^x > 0$$ | 볼록 |
| $$-\log x$$ | $$1/x^2 > 0$$ | 볼록 |
| $$\log x$$ | $$-1/x^2 < 0$$ | 오목 |
| $$\|x\|$$ | 0에서 미분 불가 | 볼록 (정의로 확인) |

마지막 줄이 판정법의 한계를 보여 줍니다. **볼록성은 미분 가능성을 요구하지 않습니다.** $$|x|$$ 는 0에서 꺾이지만 현은 여전히 그래프 위에 있습니다. 판정법은 미분되는 함수에서 쓰는 지름길일 뿐입니다.

세 번째 줄에 밑줄을 그어 둡니다. **$$-\log$$ 가 볼록이라는 것**, 뒤집어 말해 $$\log$$ 가 오목이라는 것이 이 글에서 실제로 쓰는 사실의 거의 전부입니다.

## 젠센 부등식

정의의 $$\lambda$$ 와 $$1-\lambda$$ 는 더해서 1인 두 수입니다. 확률로 읽으면 「$$a$$ 가 나올 확률 $$\lambda$$, $$b$$ 가 나올 확률 $$1-\lambda$$ 인 확률변수 $$X$$」이고, 그러면 $$\lambda a + (1-\lambda) b$$ 는 $$\mathbb{E}[X]$$ 이고 $$\lambda f(a) + (1-\lambda) f(b)$$ 는 $$\mathbb{E}[f(X)]$$ 입니다. **정의를 확률의 말로 옮겨 적기만 해도 부등식이 됩니다.**

> **젠센 부등식.** $$f$$ 가 볼록하면 임의의 확률변수 $$X$$ 에 대해
> $$f\big(\mathbb{E}[X]\big) \;\le\; \mathbb{E}\big[f(X)\big]$$
> 이다. $$f$$ 가 오목하면 부등호가 뒤집힌다.

값이 두 개일 때는 정의 그 자체였고, 값이 $$n$$ 개일 때도 같은 식이 성립하며, 연속 분포까지 그대로 갑니다. 증명은 **접선 하나**로 끝납니다.

$$\mu = \mathbb{E}[X]$$ 라 두고 $$\mu$$ 에서 그은 접선을 봅니다. 볼록함수는 어느 점에서 그은 접선보다 아래로 내려가지 않습니다.

$$f(x) \;\ge\; f(\mu) + f'(\mu)(x - \mu) \qquad \text{모든 } x \text{ 에 대해}$$

![볼록함수는 접선 위에 있고, 기댓값을 씌우면 젠센 부등식이 나온다](/assets/posts/math-jensen-inequality-supporting-line.svg)

이 자체도 한 줄로 확인됩니다. $$g(x) = f(x) - f(\mu) - f'(\mu)(x-\mu)$$ 로 두면 $$g(\mu) = 0$$ 이고 $$g'(x) = f'(x) - f'(\mu)$$ 인데, $$f'' \ge 0$$ 이라 $$f'$$ 이 증가함수이므로 $$g'$$ 은 $$x < \mu$$ 에서 음수, $$x > \mu$$ 에서 양수입니다. 즉 $$g$$ 는 $$\mu$$ 에서 최솟값 0을 가지므로 $$g \ge 0$$ 입니다.

이제 **양변에 기댓값을 씌웁니다.** 기댓값은 부등호의 방향을 지키고, 오른쪽은 $$x$$ 에 대해 일차식이라 그대로 계산됩니다.

$$\mathbb{E}[f(X)] \;\ge\; f(\mu) + f'(\mu)\big(\mathbb{E}[X] - \mu\big) = f(\mu) + 0 = f\big(\mathbb{E}[X]\big)$$

끝입니다. **오른쪽 항이 0이 되는 것이 증명의 전부**이고, 그것은 접선을 하필 $$\mu$$ 에서 그었기 때문입니다.

**등호 조건도 여기서 읽힙니다.** 등호가 서려면 $$X$$ 가 실제로 값을 갖는 모든 자리에서 $$g(x) = 0$$ 이어야 합니다. 즉 그 구간에서 $$f$$ 가 접선과 겹쳐 **직선이거나**, 아니면 $$X$$ 가 $$\mu$$ 하나만 갖는 **상수**여야 합니다. 굽은 함수에서 등호가 서는 경우는 후자뿐입니다.

## 손으로 확인 — 로그는 오목하다

$$X$$ 가 1과 100을 반반의 확률로 갖는다고 합시다. $$\log$$ 는 오목하니 부등호가 뒤집혀 $$\log \mathbb{E}[X] \ge \mathbb{E}[\log X]$$ 여야 합니다.

$$\mathbb{E}[X] = \frac{1 + 100}{2} = 50.5 \quad \Longrightarrow \quad \log \mathbb{E}[X] = \ln 50.5 = 3.922$$

$$\mathbb{E}[\log X] = \frac{\ln 1 + \ln 100}{2} = \frac{0 + 4.605}{2} = 2.303$$

![로그는 오목해서 현이 그래프 아래에 놓인다](/assets/posts/math-jensen-inequality-log-gap.svg)

$$3.922 \ge 2.303$$ 이고 차이가 1.619나 됩니다. 이 간격은 **$$X$$ 가 퍼져 있을수록 벌어집니다.** $$X$$ 가 50.5 하나로 몰리면 양변이 3.922로 같아지고, 1과 100처럼 멀리 갈리면 크게 벌어집니다.

두 번째 값을 지수로 되돌려 보면 정체가 드러납니다.

$$\exp\big(\mathbb{E}[\log X]\big) = \exp\left(\frac{\ln 1 + \ln 100}{2}\right) = \sqrt{1 \times 100} = 10$$

**기하평균**입니다. 즉 $$\log \mathbb{E}[X] \ge \mathbb{E}[\log X]$$ 는 「산술평균 50.5가 기하평균 10보다 크거나 같다」와 같은 말이고, 중학교에서 배우는 산술-기하평균 부등식이 젠센 부등식의 한 조각이었던 셈입니다.

## 첫 번째 빚 — 교차엔트로피의 초과분

지난 글에서 $$H(p, q) \ge H(p)$$ 를 세 예로 확인만 하고 증명을 미뤘습니다. 이제 갚습니다. 초과분을 한 덩어리로 묶는 것부터 시작합니다.

$$H(p,q) - H(p) = -\sum_i p_i \log q_i + \sum_i p_i \log p_i = \sum_i p_i \log \frac{p_i}{q_i}$$

부호를 밖으로 빼면 기댓값 꼴이 보입니다.

$$H(p,q) - H(p) = -\sum_i p_i \log \frac{q_i}{p_i} = -\,\mathbb{E}_{i \sim p}\!\left[\log \frac{q_i}{p_i}\right]$$

대괄호 안이 $$\log(\text{어떤 확률변수})$$ 이고 $$\log$$ 는 오목하니, 젠센을 그대로 적용합니다.

$$\mathbb{E}_{i \sim p}\!\left[\log \frac{q_i}{p_i}\right] \;\le\; \log\, \mathbb{E}_{i \sim p}\!\left[\frac{q_i}{p_i}\right] = \log \sum_i p_i \frac{q_i}{p_i} = \log \sum_i q_i = \log 1 = 0$$

$$p_i$$ 가 약분되어 **$$q$$ 의 총합만 남고, 그것은 1**입니다. 앞에 마이너스가 붙어 있었으니 부등호가 뒤집혀

$$H(p,q) - H(p) \;\ge\; 0$$

입니다. 등호 조건도 함께 옵니다. $$\log$$ 는 직선이 아니므로 등호는 확률변수 $$q_i/p_i$$ 가 **상수일 때만** 서는데, $$p$$ 와 $$q$$ 가 둘 다 합이 1이라 그 상수는 1일 수밖에 없습니다. 즉 $$q = p$$ 입니다.

「모델 분포를 정답 분포에 맞추는 것이 손실을 줄이는 유일한 길」이라는 주장이 이제 증명된 사실이 되었습니다. 이 초과분에 이름이 있고, 그 이름과 성질은 다음 글이 맡습니다.

## 두 번째 빚 — 하한을 대신 최대화한다

처음의 ELBO로 돌아갑니다. 숨은 변수 $$z$$ 가 있는 모델에서 데이터의 로그가능도는 적분입니다.

$$\log p(x) = \log \int p(x, z)\, dz$$

**로그가 적분 바깥에 있는 것**이 문제입니다. 안쪽 적분을 닫힌 꼴로 못 구하고, 표본으로 어림하자니 로그 안쪽이라 평균으로 대신할 수도 없습니다. 여기서 우리가 고른 아무 분포 $$q(z)$$ 를 곱하고 나누는 수를 씁니다.

$$\log p(x) = \log \int q(z) \frac{p(x,z)}{q(z)}\, dz = \log\, \mathbb{E}_{z \sim q}\!\left[\frac{p(x,z)}{q(z)}\right]$$

이제 «로그가 씌워진 기댓값»이고, 젠센이 이것을 뒤집어 줍니다.

$$\log p(x) \;\ge\; \mathbb{E}_{z \sim q}\!\left[\log \frac{p(x,z)}{q(z)}\right] \;=\; \text{ELBO}$$

**로그가 기댓값 안으로 들어갔습니다.** 안쪽은 이제 표본을 뽑아 평균 내면 되는 값이라 계산이 됩니다.

![하한을 밀어 올리면 그 위의 참값도 따라 올라간다](/assets/posts/math-jensen-inequality-elbo.svg)

바꿔치기가 정당한 이유가 이 부등호입니다. **ELBO는 언제나 $$\log p(x)$$ 아래에 있으므로, ELBO를 올리면 그 위에 있는 참값을 아래에서 떠받쳐 올립니다.** 다만 「올린 만큼 참값이 올라간다」는 보장은 없습니다 — 둘 사이의 간격이 줄어드는 쪽으로 힘이 갈 수도 있기 때문입니다. 그 간격이 정확히 무엇이고 언제 0이 되는지는 중급 60번 · 변분 하한과 ELBO가 다룹니다. 지금 필요한 것은 발상의 뿌리 하나입니다. **구할 수 없는 값은 볼록성으로 밀어 내려 하한을 만들고, 그 하한을 대신 최대화한다.**

## 코드로 확인하기

```python
import numpy as np

# ① 정의를 직접 확인 — f(x) = -log x 는 볼록
f = lambda t: -np.log(t)
a, b, lam = 1.0, 100.0, 0.5
print(round(f(lam * a + (1 - lam) * b), 4),      # -3.922  그래프
      round(lam * f(a) + (1 - lam) * f(b), 4))   # -2.3026 현 — 현이 위에 있다

# ② log 는 오목 — 부등호가 뒤집힌다
x = np.array([1.0, 100.0]); w = np.array([0.5, 0.5])
print(round(np.log(x @ w), 4), round(w @ np.log(x), 4))    # 3.922 2.3026
print(round(np.exp(w @ np.log(x)), 4))                     # 10.0  기하평균

# ③ 등호는 X가 상수일 때만
x2 = np.array([50.5, 50.5])
print(round(np.log(x2 @ w), 4), round(w @ np.log(x2), 4))  # 3.922 3.922

# ④ 젠센이 보장한 H(p,q) - H(p) >= 0
p = np.array([0.5, 0.25, 0.125, 0.125])
for q in [p, np.full(4, 0.25), np.array([0.125, 0.125, 0.25, 0.5])]:
    print(round(float((p * np.log2(p / q)).sum()), 4))     # 0.0  0.25  0.875
```

④가 지난 글의 세 예와 같은 수입니다. 교차엔트로피 1.75·2.0·2.625에서 엔트로피 1.75를 뺀 값이고, **하나도 음수가 아닙니다.**

## 정리

- **볼록함수는 현이 그래프 위에 있는 함수**다. $$f(\lambda a + (1-\lambda)b) \le \lambda f(a) + (1-\lambda) f(b)$$ 가 정의이고, 미분되는 함수라면 $$f'' \ge 0$$ 으로 판정한다.
- 볼록성은 **미분 가능성을 요구하지 않는다.** $$|x|$$ 는 0에서 꺾이지만 볼록하다.
- **젠센 부등식은 $$f(\mathbb{E}[X]) \le \mathbb{E}[f(X)]$$** 이고, 오목함수에서는 뒤집힌다. 정의를 확률의 말로 옮겨 적은 것이다.
- **증명은 $$\mu = \mathbb{E}[X]$$ 에서 그은 접선 하나**로 끝난다. 접선 위에 있다는 부등식의 양변에 기댓값을 씌우면 일차항이 0으로 사라진다.
- **등호는 $$f$$ 가 그 구간에서 직선이거나 $$X$$ 가 상수일 때만** 선다.
- 이 글에서 실제로 쓰는 사실은 하나다 — **$$\log$$ 는 오목하다.** 여기서 산술-기하평균 부등식도 나온다.
- **$$H(p,q) \ge H(p)$$** 의 증명은 $$\log$$ 의 오목성 + 젠센이고, 등호는 $$q = p$$ 일 때만이다.
- **구할 수 없는 값은 하한으로 바꿔 최대화한다.** $$\log \mathbb{E}[\cdot] \ge \mathbb{E}[\log \cdot]$$ 이 로그를 기댓값 안으로 넣어 계산 가능한 식을 만든다.

`loss = -(recon_term - kl_term)`으로 돌아가 봅시다. 저 한 줄이 원래 목표가 아니라 그 하한이라는 사실은 이제 결함이 아니라 **설계**로 읽힙니다. 계산할 수 없는 로그를 기댓값 안으로 밀어 넣은 대가로 부등호가 하나 생겼고, 볼록성이 그 부등호의 방향을 붙들어 주고 있습니다.

그리고 이 글에서 두 번 나온 양이 하나 있습니다. $$H(p,q) - H(p)$$ 라는 초과분과 ELBO가 참값에 못 미치는 간격 — 둘은 같은 모양의 식입니다. 다음 글이 그 양에 이름을 붙이고, 왜 그것을 «거리»라고 부르면 안 되는지를 봅니다.
