[지난 글](/articles/math-basics-what-is-a-derivative)에서 정의식만으로 네 함수의 도함수를 얻었습니다. 정확하지만 느립니다. $$x^2 e^{-x^2}$$ 같은 식을 정의식으로 풀려고 하면 분자를 전개하다 끝나지 않습니다.

이 글은 계산만 다룹니다. 표 하나와 규칙 넷을 세우고, 그다음은 손으로 스무 문제입니다.

## 기본 도함수 표

가장 자주 쓰는 것들입니다. 각각은 정의식으로 유도할 수 있지만, 한 번 유도해 둔 뒤로는 외워 쓰는 것이 보통입니다.

| $$f(x)$$ | $$f'(x)$$ |
| --- | --- |
| $$c$$ (상수) | $$0$$ |
| $$x^n$$ | $$n\,x^{n-1}$$ |
| $$e^x$$ | $$e^x$$ |
| $$a^x$$ | $$a^x \ln a$$ |
| $$\ln x$$ | $$\dfrac1x$$ |
| $$\log_a x$$ | $$\dfrac{1}{x \ln a}$$ |
| $$\sin x$$ | $$\cos x$$ |
| $$\cos x$$ | $$-\sin x$$ |
| $$\tan x$$ | $$\dfrac{1}{\cos^2 x}$$ |

$$x^n$$ 줄이 지난 글의 넷을 한 줄로 삼킵니다 — $$x^2\to2x$$, $$x^3\to3x^2$$, $$\dfrac1x=x^{-1}\to-x^{-2}$$, $$\sqrt{x}=x^{1/2}\to\dfrac12x^{-1/2}$$ 가 전부 이 규칙입니다. $$n$$ 이 음수나 분수여도 그대로 통합니다.

$$\cos x$$ 줄의 마이너스는 자주 빠뜨리는 자리입니다. [25번 글](/articles/math-basics-trigonometry-and-unit-circle)의 그래프를 떠올리면 $$\cos$$ 은 0에서 시작해 내려가므로 그 자리의 기울기가 음수여야 맞습니다.

맨 아래 $$\tan$$ 줄은 이 표에서 유일하게 유도를 미뤄 둔 것입니다. $$\tan x = \dfrac{\sin x}{\cos x}$$ 라 나눗셈이 들어 있어서, 다음 절에서 몫의 규칙을 세운 뒤에 그 자리에서 두 줄로 얻습니다.

### 자연로그의 밑

표에서 $$e^x$$ 만 미분해도 그대로입니다. 왜 그런지 수치로 봅니다. 정의식에서 $$f(x)=a^x$$ 를 넣으면

$$\frac{a^{x+h}-a^x}{h} = a^x \cdot \frac{a^h-1}{h}$$

$$a^{x+h}=a^x a^h$$ 로 갈라 $$a^x$$ 을 밖으로 뺀 것입니다. 남은 $$\dfrac{a^h-1}{h}$$ 에는 $$x$$ 가 없습니다 — 그러니 이 값이 $$h\to0$$ 에서 무엇에 붙는지가 곧 $$a^x$$ 앞에 붙는 계수입니다. 밑을 셋으로 바꿔 가며 표를 채웁니다.

| $$h$$ | $$a=2$$ | $$a=e$$ | $$a=3$$ |
| --- | --- | --- | --- |
| 0.1 | 0.71773 | 1.05171 | 1.16123 |
| 0.01 | 0.69556 | 1.00502 | 1.10467 |
| 0.001 | 0.69339 | 1.00050 | 1.09922 |
| $$-0.01$$ | 0.69075 | 0.99502 | 1.09260 |

$$a=e$$ 일 때만 1에 붙습니다. 그래서 $$(e^x)'=e^x$$ 이고, 다른 밑에서는 계수가 하나 붙습니다 — 2에서는 0.693, 3에서는 1.099로 [22번 글](/articles/math-basics-logarithms)의 $$\ln 2$$ 와 $$\ln 3$$ 그대로입니다.

[21번 글](/articles/math-basics-exponential-function)에서 $$e$$ 를 $$\left(1+\dfrac1n\right)^n$$ 의 표로 정의할 때는 왜 그런 이상한 수를 고르는지가 분명하지 않았습니다. 여기가 그 값을 갚는 자리입니다 — 밑을 $$e$$ 로 잡으면 계수가 1이 되어 계산이 가장 깨끗해집니다.

### a^x 의 계수

위 표는 계수가 $$\ln a$$ 라는 것을 수로 보여 주지만 유도는 아닙니다. 유도는 한 줄로 됩니다. 모든 양수는 $$e$$ 의 거듭제곱으로 적을 수 있습니다 — $$\ln a$$ 가 「$$e$$ 를 몇 제곱해야 $$a$$ 가 되는가」였으니까요.

$$a = e^{\ln a} \quad\Longrightarrow\quad a^x = \left(e^{\ln a}\right)^x = e^{x\ln a}$$

오른쪽 끝을 보면 지수에 $$x$$ 가 상수배로 들어 있습니다. $$e^{\square}$$ 은 미분해도 그대로이고 $$\square = x\ln a$$ 를 미분하면 상수 $$\ln a$$ 이므로, 아래에서 세울 연쇄법칙을 한 번 쓰면

$$(a^x)' = e^{x\ln a}\cdot\ln a = a^x\ln a$$

입니다. 표의 0.693과 1.099가 여기서 나왔습니다. 그리고 $$a=e$$ 이면 $$\ln e = 1$$ 이라 계수가 사라집니다 — 앞 소절의 결론이 여기에 다시 들어 있습니다.

### log_a x 의 계수

$$\log_a x$$ 줄도 따로 유도할 필요가 없습니다. 22번 글의 **밑변환 공식**이 이미 답을 들고 있습니다.

$$\log_a x = \frac{\ln x}{\ln a}$$

$$\ln a$$ 는 $$x$$ 와 무관한 상수입니다. 그러니 이 식은 $$\ln x$$ 에 상수 $$\dfrac{1}{\ln a}$$ 를 곱한 것일 뿐이고, 아래에서 보듯 상수배는 미분을 그대로 통과합니다.

$$(\log_a x)' = \frac{1}{\ln a}\cdot\frac1x = \frac{1}{x\ln a}$$

표의 마지막 두 줄이 이렇게 앞 두 줄에서 따라 나옵니다. 표에서 외울 것은 $$e^x$$ 과 $$\ln x$$ 둘뿐이고 나머지 지수·로그 줄은 거기서 뽑아 쓰면 됩니다.

## 합·상수배·곱·몫

### 상수배·합·차

셋은 유도할 것이 없습니다. 결과만 적습니다.

$$(c\,f)' = c\,f' \qquad (f+g)' = f'+g' \qquad (f-g)' = f'-g'$$

$$f(x)=5x^3-2x^2+7$$ 이면 항마다 따로 미분해서 붙이면 됩니다.

$$f'(x)=5\cdot3x^2-2\cdot2x+0 = 15x^2-4x$$

### 곱의 규칙

여기서부터는 그대로 통하지 않습니다. $$(fg)'$$ 은 $$f'g'$$ 이 아닙니다. 확인하기 쉽습니다 — $$f=g=x$$ 면 $$fg=x^2$$ 이라 $$(fg)'=2x$$ 인데, $$f'g'=1\times1=1$$ 입니다.

맞는 규칙은 넓이로 유도합니다. 가로가 $$f$$, 세로가 $$g$$ 인 직사각형의 넓이가 $$fg$$ 입니다.

![직사각형의 가로와 세로가 늘어날 때 넓이가 세 조각 늘어나는 그림](/assets/posts/math-basics-derivative-rules-product-rule.svg)

$$x$$ 가 $$h$$ 만큼 늘면 가로가 $$\Delta f$$, 세로가 $$\Delta g$$ 만큼 늘어납니다. 늘어난 넓이는 세 조각입니다.

$$f\,\Delta g + g\,\Delta f + \Delta f\,\Delta g$$

이것을 $$h$$ 로 나눕니다.

$$f\cdot\frac{\Delta g}{h} + g\cdot\frac{\Delta f}{h} + \Delta f\cdot\frac{\Delta g}{h}$$

앞의 두 조각은 $$f g'$$ 과 $$g f'$$ 이 됩니다. 셋째 조각만 사라집니다 — 뒤쪽 $$\dfrac{\Delta g}{h}$$ 는 $$g'$$ 으로 가는데 앞에 곱해진 $$\Delta f$$ 가 0으로 줄기 때문입니다. 그림에서 오른쪽 위 작은 네모가 가장 먼저 없어지는 것이 이것입니다.

$$(fg)' = f'g + fg'$$

써 봅니다. $$f(x)=x^2 e^x$$ 이면 $$f'=2x$$, $$g=e^x$$, $$g'=e^x$$ 이므로

$$(x^2e^x)' = 2x\,e^x + x^2e^x = (x^2+2x)e^x$$

곱이 셋이면 항이 셋이 됩니다. 같은 그림을 상자로 한 차원 올려 생각하면 되고, 결과는 한 번에 하나씩 미분한 것을 더하는 모양입니다.

$$(fgh)' = f'gh + fg'h + fgh'$$

규칙이 보입니다 — 자리마다 차례로 프라임을 하나씩 옮겨 붙이고 전부 더합니다. 넷이면 항이 넷입니다. $$f(x)=x\,e^x\sin x$$ 를 예로 들면

$$(x\,e^x\sin x)' = e^x\sin x + x\,e^x\sin x + x\,e^x\cos x$$

입니다. 물론 $$x e^x$$ 을 한 덩어리로 묶고 곱의 규칙을 두 번 써도 같은 답이 나옵니다.

### 몫의 규칙

나눗셈은 이렇습니다.

$$\left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}$$

분자의 순서가 중요합니다. 곱의 규칙과 달리 빼기라서 앞뒤를 바꾸면 부호가 뒤집힙니다. "위 미분 곱하기 아래, 빼기, 위 곱하기 아래 미분, 나누기 아래 제곱"으로 외우면 순서가 안 흔들립니다.

$$f(x)=\dfrac{x}{1+x}$$ 로 써 봅니다. 위는 $$x$$ 이고 미분하면 1, 아래는 $$1+x$$ 이고 미분하면 1입니다.

$$f'(x) = \frac{1\cdot(1+x) - x\cdot 1}{(1+x)^2} = \frac{1}{(1+x)^2}$$

미뤄 둔 $$\tan$$ 을 여기서 갚습니다. $$\tan x = \dfrac{\sin x}{\cos x}$$ 에 그대로 넣으면

$$(\tan x)' = \frac{\cos x\cdot\cos x - \sin x\cdot(-\sin x)}{\cos^2 x} = \frac{\cos^2 x + \sin^2 x}{\cos^2 x} = \frac{1}{\cos^2 x}$$

분자가 $$\cos^2 x + \sin^2 x$$ 로 모이는 순간 25번 글의 피타고라스 항등식이 그것을 1로 만듭니다. 표의 마지막 줄이 이 두 줄입니다.

이 규칙은 셋 중 가장 지저분하므로 쓰기 전에 나눠 적을 수 있는지 먼저 봅니다. 분자를 항마다 나누면 나눗셈이 없어지는 경우가 많습니다.

$$\frac{x^2+1}{x} = x + \frac1x = x + x^{-1} \quad\Longrightarrow\quad \left(\frac{x^2+1}{x}\right)' = 1 - x^{-2} = 1 - \frac{1}{x^2}$$

몫의 규칙으로 풀면 $$\dfrac{2x\cdot x-(x^2+1)}{x^2}=\dfrac{x^2-1}{x^2}$$ 이라 같은 답인데 줄이 하나 더 들고 약분이 남습니다. 분모가 한 항일 때는 나눠 적는 쪽이 늘 빠릅니다.

## 합성함수와 연쇄법칙

### 겉과 속

마지막 규칙은 함수 안에 함수가 든 경우입니다. 그 모양에 먼저 이름을 붙여야 합니다.

함수 $$f$$ 에 넣어 나온 값을 다시 $$g$$ 에 넣는 것을 **합성**이라고 하고 $$g(f(x))$$ 또는 $$g\circ f$$ 로 적습니다. "지 서클 에프"라고 읽고, 오른쪽 것을 먼저 먹입니다.

$$f(x)=x^2$$ 과 $$g(x)=x+1$$ 로 확인합니다.

$$g(f(x)) = g(x^2) = x^2+1 \qquad f(g(x)) = f(x+1) = (x+1)^2$$

![같은 2를 넣어도 합성 순서에 따라 5와 9로 갈리는 그림](/assets/posts/math-basics-derivative-rules-composition-order.svg)

$$x=2$$ 를 넣으면 앞은 $$4+1=5$$, 뒤는 $$3^2=9$$ 입니다. 순서를 바꾸면 다른 함수입니다. 그래서 합성식을 볼 때 어느 쪽이 먼저인지를 반드시 갈라야 합니다.

가르는 이름도 정해 둡니다. 나중에 먹이는 바깥쪽을 **겉**이라 하고, 먼저 먹이는 안쪽을 **속**이라고 합니다.

| 식 | 겉 | 속 |
| --- | --- | --- |
| $$(2x+1)^5$$ | 다섯제곱 | $$2x+1$$ |
| $$\sin(x^2)$$ | $$\sin$$ | $$x^2$$ |
| $$e^{-x^2}$$ | $$e$$ 의 거듭제곱 | $$-x^2$$ |
| $$\ln(1+x^2)$$ | $$\ln$$ | $$1+x^2$$ |

괄호 안에 든 것이 속입니다. 이 한 줄이면 대부분 갈립니다.

### 연쇄법칙

합성함수의 도함수는 이렇습니다.

$$\bigl(g(f(x))\bigr)' = g'(f(x))\cdot f'(x)$$

말로 하면 겉을 미분하고, 속을 미분해서, 곱합니다. 겉을 미분할 때 속은 통째로 하나의 덩어리로 두고, 미분이 끝난 뒤 그 자리에 속을 도로 넣습니다.

![겉과 속을 갈라 각각 미분하고 곱하는 네 단계 그림](/assets/posts/math-basics-derivative-rules-chain-rule.svg)

$$(2x+1)^5$$ 로 단계를 밟습니다.

1. 겉은 다섯제곱, 속은 $$2x+1$$
2. 겉을 미분하면 $$5u^4$$, 속을 도로 넣어 $$5(2x+1)^4$$
3. 속을 미분하면 2
4. 곱하면 $$10(2x+1)^4$$

$$\ln(1+x^2)$$ 도 같습니다. 겉은 $$\ln$$ 이라 미분하면 $$\dfrac1{\square}$$ 이고 속을 넣으면 $$\dfrac{1}{1+x^2}$$, 속을 미분하면 $$2x$$ 이므로

$$\bigl(\ln(1+x^2)\bigr)' = \frac{2x}{1+x^2}$$

이제 앞 절에서 미뤄 둔 몫의 규칙을 갚습니다. 나눗셈을 음의 지수로 고쳐 적으면 곱의 규칙과 연쇄법칙만으로 두 줄입니다.

$$\frac fg = f\cdot g^{-1}$$

곱의 규칙을 쓰면 $$f'g^{-1} + f\cdot(g^{-1})'$$ 이고, $$(g^{-1})'$$ 은 겉이 $$\square^{-1}$$ 이고 속이 $$g$$ 인 합성이라 연쇄법칙으로 $$-g^{-2}g'$$ 입니다.

$$\left(\frac fg\right)' = \frac{f'}{g} - \frac{fg'}{g^2} = \frac{f'g - fg'}{g^2}$$

통분 한 번으로 외워 둔 그 모양이 나옵니다. 몫의 규칙은 새 규칙이 아니라 앞의 둘에서 따라 나오는 것이고, 그래서 셋 중 잊어버려도 되는 유일한 규칙입니다.

### 배율의 곱

연쇄법칙이 왜 더하기가 아니라 곱하기인지를 그림으로 봅니다. 눈금자 셋을 나란히 놓습니다 — 맨 위가 $$x$$, 가운데가 속의 값 $$u$$, 맨 아래가 최종값 $$y$$ 입니다.

$$u = 2x+1$$ 이고 $$y = u^2$$ 인 경우를 $$x=1$$ 근처에서 봅니다. 이때 $$u=3$$ 이고 $$y=9$$ 입니다.

![x·u·y 눈금자 셋에서 배율이 곱해지는 그림](/assets/posts/math-basics-derivative-rules-rulers.svg)

$$x$$ 를 1칸 움직이면 $$u$$ 는 2칸 움직입니다. $$u$$ 를 1칸 움직이면 $$y$$ 는 $$2u = 6$$ 칸 움직입니다. 그러면 $$x$$ 가 1칸 움직일 때 $$y$$ 는 몇 칸 움직일까요. $$u$$ 가 2칸 움직이고 그 1칸마다 $$y$$ 가 6칸이니 $$2\times6=12$$ 칸입니다.

배율이 이어 붙을 때는 더하는 것이 아니라 곱하는 것입니다. 변화량의 비로 적으면 한 줄로 보입니다.

$$\frac{\Delta y}{\Delta x} = \frac{\Delta y}{\Delta u}\cdot\frac{\Delta u}{\Delta x}$$

오른쪽에서 $$\Delta u$$ 가 약분되는 것처럼 보이고, 실제로 이것이 $$h\to0$$ 에서 연쇄법칙이 됩니다. 검산도 됩니다 — $$y=(2x+1)^2$$ 을 펼치면 $$4x^2+4x+1$$ 이고 $$y'=8x+4$$ 이니 $$x=1$$ 에서 12입니다.

라이프니츠 표기로 적으면 약분이 더 그럴듯해 보입니다.

$$\frac{dy}{dx} = \frac{dy}{du}\cdot\frac{du}{dx}$$

그런데 이것은 증명이 아닙니다. $$dy$$ 나 $$du$$ 는 따로 떼어 나눌 수 있는 수가 아니고, $$\dfrac{dy}{du}$$ 전체가 하나의 기호입니다. 게다가 $$\Delta u$$ 가 0이 되는 자리에서는 위의 분수식이 아예 성립하지 않아서 진짜 증명은 그 경우를 따로 다뤄야 합니다. 기억을 돕는 모양이지 근거는 아니라고 갈라 두세요.

### 세 겹의 합성

껍질이 셋이면 안쪽으로 한 겹씩 벗기며 곱을 하나씩 더 붙입니다. $$e^{\sin(x^2)}$$ 을 봅니다 — 겉은 $$e$$ 의 거듭제곱, 그 속은 $$\sin$$, 그 속은 $$x^2$$ 입니다.

$$\bigl(e^{\sin(x^2)}\bigr)' = e^{\sin(x^2)}\cdot\cos(x^2)\cdot 2x$$

벗긴 껍질의 수만큼 곱이 붙습니다. 두 겹이면 둘, 세 겹이면 셋입니다. 눈금자로 읽으면 자가 넷이 되고 배율이 셋 곱해지는 것뿐입니다.

## 고계도함수와 볼록

### 이계도함수

$$f'$$ 도 함수이므로 다시 미분할 수 있습니다. 그렇게 얻은 것을 **이계도함수** 라 하고 $$f''$$ 로 적습니다. "에프 투 프라임"이라고 읽습니다. 더 가면 $$f'''$$, 그 뒤로는 작대기 대신 숫자를 괄호에 넣어 $$f^{(4)}$$ 로 적습니다.

$$f(x)=x^4$$ 로 끝까지 가 봅니다.

| | 식 |
| --- | --- |
| $$f$$ | $$x^4$$ |
| $$f'$$ | $$4x^3$$ |
| $$f''$$ | $$12x^2$$ |
| $$f'''$$ | $$24x$$ |
| $$f^{(4)}$$ | $$24$$ |
| $$f^{(5)}$$ | $$0$$ |

이름 붙이기 좋은 대응이 하나 있습니다. $$f$$ 를 시각에 따른 **위치**로 보면 $$f'$$ 은 위치가 변하는 빠르기, 곧 **속도**입니다. 그리고 $$f''$$ 은 속도가 변하는 빠르기, 곧 **가속도**입니다. 아래 볼록 이야기는 전부 「가속도의 부호」를 다른 말로 한 것입니다.

### 볼록과 변곡점

지난 글에서 $$f'$$ 의 부호가 오르내림을 말했습니다. $$f''$$ 은 $$f'$$ 의 도함수이므로 기울기 자체가 커지는 중인지 작아지는 중인지 를 말합니다.

![아래로 볼록, 위로 볼록, 그리고 변곡점을 그린 그림](/assets/posts/math-basics-derivative-rules-second-derivative.svg)

- $$f''>0$$ 이면 기울기가 커지는 중이라 그릇처럼 위로 열립니다. 이것을 **아래로 볼록** 이라고 합니다.
- $$f''<0$$ 이면 기울기가 작아지는 중이라 덮개처럼 아래로 열립니다. **위로 볼록** 입니다.
- $$f''$$ 의 부호가 바뀌는 점을 **변곡점**이라고 합니다. 휘는 방향이 뒤집히는 자리입니다.

$$f(x)=x^3$$ 에서 확인합니다. $$f'=3x^2$$, $$f''=6x$$ 이므로 $$x<0$$ 에서 음수, $$x>0$$ 에서 양수입니다. $$x=0$$ 이 변곡점입니다. 지난 글에서 이 점이 극값이 아니었던 것과 나란히 놓으면 정리가 됩니다 — $$f'(0)=0$$ 이지만 꺾이지는 않았고, 대신 휘는 방향이 거기서 뒤집혔습니다.

### 부호 네 조합

$$f'$$ 과 $$f''$$ 은 서로 다른 것을 말하므로 부호를 따로 봐야 합니다. 조합이 넷이고 곡선 모양도 넷입니다.

| $$f'$$ | $$f''$$ | 곡선 | 예 |
| --- | --- | --- | --- |
| $$+$$ | $$+$$ | 올라가면서 점점 가파르게 | $$e^x$$ |
| $$+$$ | $$-$$ | 올라가면서 점점 완만하게 | $$\ln x$$ ($$x>0$$) |
| $$-$$ | $$-$$ | 내려가면서 점점 가파르게 | $$-e^x$$ |
| $$-$$ | $$+$$ | 내려가면서 점점 완만하게 | $$e^{-x}$$ |

가장 자주 헷갈리는 자리가 둘째 줄과 셋째 줄입니다. 둘째 줄은 「올라가는데 위로 볼록」이라 올라가는 것을 멈출 기세이고, 셋째 줄은 「내려가는데 위로 볼록」이라 내려가는 속도가 붙는 중입니다. 위로 볼록인지 아래로 볼록인지는 오르내림과 아무 상관이 없습니다 — $$f''$$ 만 보면 됩니다.

### x⁴의 원점

변곡점을 찾을 때 $$f''=0$$ 인 점을 구하는 것까지는 맞습니다. 그런데 거기서 멈추면 틀립니다.

$$f(x)=x^4$$ 을 봅니다. $$f''=12x^2$$ 이므로 $$f''(0)=0$$ 입니다. 그런데 $$x=0$$ 은 변곡점이 아닙니다 — $$12x^2$$ 은 $$x$$ 가 음수든 양수든 양수라 부호가 안 바뀌기 때문입니다. 원점의 좌우 모두 아래로 볼록이고, 실제로 그 점은 이 함수의 극소입니다.

$$x^3$$ 과 나란히 놓으면 차이가 분명합니다.

| | $$f''$$ | $$x<0$$ | $$x>0$$ | $$x=0$$ 은 |
| --- | --- | --- | --- | --- |
| $$x^3$$ | $$6x$$ | 음수 | 양수 | 변곡점 |
| $$x^4$$ | $$12x^2$$ | 양수 | 양수 | 극소 |

$$f''=0$$ 은 변곡점의 필요조건일 뿐입니다. 그 점을 찾은 뒤에 좌우에서 $$f''$$ 의 부호가 실제로 갈리는지 한 번 더 봐야 합니다. 지난 글에서 $$f'=0$$ 이 극값의 필요조건일 뿐이었던 것과 똑같은 모양이고, 그때의 반례도 $$x^3$$ 이었습니다.

## 음함수·로그·역함수 미분

앞의 규칙 넷으로 안 풀리는 모양이 셋 남았습니다. 셋 다 미분을 새로 배우는 것이 아니라 식을 먼저 손보는 요령입니다.

### 음함수 미분

$$y$$ 가 $$x$$ 의 식으로 깔끔하게 풀려 있지 않은 경우가 있습니다. 원의 방정식 $$x^2+y^2=25$$ 가 그렇습니다. 이럴 때는 양변을 그대로 미분하되, $$y$$ 를 미분할 때마다 연쇄법칙에 따라 $$y'$$ 을 곱해 줍니다. $$y$$ 가 속에 든 함수이기 때문입니다.

$$2x + 2y\,y' = 0 \quad\Longrightarrow\quad y' = -\frac{x}{y}$$

점 $$(3,\ 4)$$ 에서 $$-\dfrac34$$ 입니다. 답에 $$y$$ 가 남아 있는 것이 이 방법의 특징입니다 — 곡선 위의 점 하나를 주면 기울기가 정해집니다.

### 로그 미분법

곱과 거듭제곱이 여러 겹 겹친 식은 규칙을 그대로 쓰면 항이 폭발합니다. 그럴 때 양변에 로그를 씌우면 곱이 합으로, 거듭제곱이 상수배로 내려옵니다. 22번 글의 로그 성질이 그대로 쓰이는 자리이고, 이것을 **로그 미분법**이라고 부릅니다.

$$y = x^x$$ 으로 해 봅니다. 밑에도 $$x$$ 가 있고 지수에도 $$x$$ 가 있어 표의 어느 줄도 안 맞습니다. 양변에 자연로그를 씌웁니다.

$$\ln y = x\ln x$$

이제 양변을 $$x$$ 로 미분합니다. 왼쪽은 음함수 미분과 같아서 $$\dfrac{y'}{y}$$ 이고, 오른쪽은 곱의 규칙으로 $$\ln x + 1$$ 입니다.

$$\frac{y'}{y} = \ln x + 1 \quad\Longrightarrow\quad y' = x^x(\ln x + 1)$$

마지막에 $$y$$ 를 원래 식으로 되돌려 놓는 것을 빠뜨리지 마세요. 양변에 $$y$$ 를 곱하는 그 한 줄이 이 방법의 마무리입니다.

밑에 $$x$$ 가 없어도 겹친 곱이면 같은 요령이 통합니다. 로그가 곱을 합으로 바꾸므로, 괄호가 여럿인 식은 항의 수만큼 짧은 분수로 갈라집니다. 곱의 규칙을 세 번 쓰는 것보다 훨씬 짧고, 아래 연습 2번이 그 자리입니다.

### 역함수의 미분

$$y=f(x)$$ 의 **역함수**는 $$x$$ 와 $$y$$ 의 역할을 바꾼 함수이고, 그래프는 원래 그래프를 직선 $$y=x$$ 에 대해 뒤집은 모양입니다. 거울에 비춘 것이므로 한 점에서의 접선도 함께 뒤집힙니다.

접선이 뒤집히면 기울기는 어떻게 될까요. 직선 $$y=x$$ 대칭은 가로와 세로를 맞바꾸는 일이니, 가로로 $$a$$ 세로로 $$b$$ 였던 기울기가 가로로 $$b$$ 세로로 $$a$$ 가 됩니다. 곧 역수입니다.

$$\frac{dy}{dx} = \frac{1}{\;\dfrac{dx}{dy}\;}$$

$$y=\sqrt{x}$$ 로 확인합니다. 양변을 제곱하면 $$x = y^2$$ 이고 $$\dfrac{dx}{dy} = 2y$$ 이므로

$$\frac{dy}{dx} = \frac{1}{2y} = \frac{1}{2\sqrt{x}}$$

표의 $$x^{1/2}$$ 줄과 같습니다. $$\ln x$$ 도 같은 방법으로 되찾을 수 있습니다. $$y=\ln x$$ 이면 $$x = e^y$$ 이고 $$\dfrac{dx}{dy} = e^y = x$$ 이므로 $$\dfrac{dy}{dx} = \dfrac1x$$ 입니다. 표에서 외우기로 한 두 줄 중 하나가 나머지 하나에서 나온 셈입니다.

## 연습 문제

여기가 이 글의 본체입니다. 규칙을 읽는 것과 쓰는 것은 다릅니다.

틀렸을 때는 이 순서로 의심합니다.

1. **부호** — $$\cos$$ 을 미분하면 $$-\sin$$ 입니다. $$e^{-x}$$ 처럼 속에 마이너스가 있으면 그것도 곱해집니다.
2. **속미분 누락** — 괄호가 있었는데 답에 속의 도함수가 안 붙었으면 그것입니다. $$\sin(x^2)$$ 의 답에 $$2x$$ 가 있는지 봅니다.
3. **음의 지수 처리** — $$\dfrac{1}{x^2}=x^{-2}$$ 이고 미분하면 $$-2x^{-3}=-\dfrac{2}{x^3}$$ 입니다. 지수가 작아진다는 것은 음수 쪽으로 더 간다는 뜻입니다.

답을 컴퓨터로 맞춰 보는 방법도 있습니다. 그 절차는 48번 · SymPy 검산의 몫이라 여기서는 그런 것이 있다고만 적어 둡니다.

### 연습 1 — 표·합·곱·몫 열두 문제

1. $$f(x)=x^7$$

   답. $$f'(x)=7x^6$$ 입니다.
2. $$f(x)=4x^3-3x^2+6$$

   답. 항마다 따로 미분해 $$f'(x)=12x^2-6x$$ 입니다. 상수 6은 0이 됩니다.
3. $$f(x)=\sqrt{x}+\dfrac1x$$

   답. $$x^{1/2}+x^{-1}$$ 로 고쳐 적으면 $$f'(x)=\dfrac12x^{-1/2}-x^{-2} = \dfrac{1}{2\sqrt{x}}-\dfrac{1}{x^2}$$ 입니다.
4. $$f(x)=3e^x-2\ln x$$

   답. $$f'(x)=3e^x-\dfrac2x$$ 입니다.
5. $$f(x)=4\sin x+\cos x$$

   답. $$f'(x)=4\cos x-\sin x$$ 입니다. $$\cos$$ 쪽에서 마이너스가 나옵니다.
6. $$f(x)=5\cdot 2^x + \log_2 x$$

   답. 표의 두 줄을 그대로 씁니다. $$f'(x)=5\cdot 2^x\ln 2 + \dfrac{1}{x\ln 2}$$ 입니다.
7. $$f(x)=x^3 e^x$$

   답. $$3x^2e^x + x^3e^x = (x^3+3x^2)e^x$$ 입니다.
8. $$f(x)=x\ln x$$

   답. $$1\cdot\ln x + x\cdot\dfrac1x = \ln x + 1$$ 입니다.
9. $$f(x)=(x+1)\sin x$$

   답. $$1\cdot\sin x + (x+1)\cos x = \sin x + (x+1)\cos x$$ 입니다.
10. $$f(x)=x\,e^x\cos x$$

    답. 곱이 셋이라 항도 셋입니다. $$e^x\cos x + x\,e^x\cos x - x\,e^x\sin x$$ 입니다.
11. $$f(x)=\dfrac{x^2}{1+x}$$

    답. $$\dfrac{2x(1+x)-x^2\cdot1}{(1+x)^2} = \dfrac{x^2+2x}{(1+x)^2}$$ 입니다.
12. $$f(x)=\dfrac{\sin x}{x}$$

    답. $$\dfrac{x\cos x-\sin x}{x^2}$$ 입니다.

10번은 앞의 둘을 한 덩어리로 묶어 곱의 규칙을 두 번 써도 같은 답이 나옵니다. 어느 쪽이 편한지 두 번 다 해 보세요.

### 연습 2 — 연쇄법칙과 섞어 쓰기 여덟 문제

1. $$f(x)=(3x-2)^4$$

   답. 겉을 미분해 $$4(3x-2)^3$$, 속을 미분해 3, 곱하면 $$12(3x-2)^3$$ 입니다.
2. $$f(x)=\ln(1+3x)$$

   답. $$\dfrac{1}{1+3x}\times3 = \dfrac{3}{1+3x}$$ 입니다.
3. $$f(x)=\sin(4x)$$

   답. $$\cos(4x)\times4 = 4\cos(4x)$$ 입니다.
4. $$f(x)=e^{3x}$$

   답. $$e^{3x}\times3 = 3e^{3x}$$ 입니다.
5. $$f(x)=\sqrt{x^2+1}$$

   답. $$(x^2+1)^{1/2}$$ 로 보면 겉이 $$\dfrac12(x^2+1)^{-1/2}$$ 이고 속이 $$2x$$ 이므로 $$\dfrac{x}{\sqrt{x^2+1}}$$ 입니다.
6. $$f(x)=x^2e^{-x^2}$$

   답. 곱의 규칙으로 $$2x\,e^{-x^2} + x^2\cdot e^{-x^2}\cdot(-2x)$$ 이고, 뒤쪽에 연쇄법칙이 한 번 들어갔습니다. 정리하면 $$(2x-2x^3)e^{-x^2}$$ 입니다.
7. $$f(x)=e^{\cos(x^2)}$$

   답. 껍질이 셋이라 곱이 셋입니다. $$e^{\cos(x^2)}\cdot(-\sin(x^2))\cdot2x = -2x\sin(x^2)\,e^{\cos(x^2)}$$ 입니다.
8. $$f(x)=\dfrac{\ln x}{x^2}$$

   답. 몫의 규칙으로 $$\dfrac{\frac1x\cdot x^2-\ln x\cdot 2x}{x^4} = \dfrac{x-2x\ln x}{x^4} = \dfrac{1-2\ln x}{x^3}$$ 입니다.

### 연습 3 — 로그 미분법과 역함수 미분

1. $$y=x^{2x}$$ 를 로그 미분법으로 구하세요.

   답. $$\ln y = 2x\ln x$$ 이므로 $$\dfrac{y'}{y} = 2\ln x + 2$$ 입니다. 양변에 $$y$$ 를 곱하면 $$y' = x^{2x}(2\ln x + 2)$$ 입니다.
2. $$y=(x^2+1)^3(x-1)^4$$ 의 $$\dfrac{y'}{y}$$ 를 구하고, 그것으로 $$y'$$ 을 적으세요.

   답. $$\ln y = 3\ln(x^2+1)+4\ln(x-1)$$ 이므로 $$\dfrac{y'}{y} = \dfrac{6x}{x^2+1}+\dfrac{4}{x-1}$$ 입니다. 양변에 $$y$$ 를 곱해 정리하면 $$y' = 6x(x^2+1)^2(x-1)^4 + 4(x^2+1)^3(x-1)^3$$ 입니다.
3. $$y=\sqrt[3]{x}$$ 를 역함수 미분으로 구하세요.

   답. 세제곱하면 $$x=y^3$$ 이고 $$\dfrac{dx}{dy}=3y^2$$ 입니다. 역수를 취해 $$\dfrac{dy}{dx}=\dfrac{1}{3y^2}=\dfrac{1}{3x^{2/3}}$$ 이고, 표의 $$x^{1/3}$$ 줄과 같습니다.
4. $$y=\log_2 x$$ 를 역함수 미분으로 구하세요.

   답. $$x = 2^y$$ 이고 $$\dfrac{dx}{dy}=2^y\ln 2 = x\ln 2$$ 입니다. 역수를 취하면 $$\dfrac{dy}{dx}=\dfrac{1}{x\ln 2}$$ 로 표의 줄과 같습니다.

### 연습 4 — 검산과 오답 진단

앞의 둘은 계산기로 직접 재는 검산입니다. 한 점에서 $$\dfrac{f(x+h)-f(x-h)}{2h}$$ 를 $$h$$ 를 바꿔 가며 계산하고, 규칙으로 얻은 값과 맞대 보세요.

1. $$f(x)=x^x$$ 의 $$x=2$$ 에서의 값을 규칙으로 구하고, $$h=10^{-3},\ 10^{-6},\ 10^{-10}$$ 에서 잰 값과 맞대세요.

   답. 로그 미분법으로 $$f'(x)=x^x(\ln x+1)$$ 이므로 $$f'(2)=4(\ln 2+1)=6.772589$$ 입니다. 재면 $$h=10^{-3}$$ 에서 $$6.772593$$, $$h=10^{-6}$$ 에서 $$6.772589$$, $$h=10^{-10}$$ 에서 $$6.772591$$ 입니다.
2. $$f(x)=\sqrt{x^2+1}$$ 의 $$x=2$$ 에서도 같은 일을 하세요.

   답. 연쇄법칙으로 $$f'(x)=\dfrac{x}{\sqrt{x^2+1}}$$ 이므로 $$f'(2)=\dfrac{2}{\sqrt5}=0.8944272$$ 입니다. 재면 $$h=10^{-3}$$ 에서 $$0.8944272$$, $$h=10^{-6}$$ 에서 $$0.8944272$$, $$h=10^{-10}$$ 에서 $$0.8944268$$ 입니다.
3. 위 둘에서 $$h$$ 를 가장 작게 잡은 $$10^{-10}$$ 이 오히려 나빴습니다. 왜 그런지 적으세요.

   답. $$h$$ 가 너무 작으면 $$f(x+h)$$ 와 $$f(x-h)$$ 가 거의 같은 수가 되어, 빼고 나면 계산기가 들고 있던 자릿수가 대부분 사라집니다. 남은 몇 자리를 아주 작은 $$2h$$ 로 나누므로 그 오차가 크게 부풀려집니다. $$h$$ 를 줄이면 한동안 좋아지다가 어느 지점부터 다시 나빠집니다.

아래 다섯은 전부 틀린 답입니다. 위의 의심 순서 셋 가운데 무엇을 놓친 것인지 고르고 바른 답을 적으세요.

1. $$\bigl(\cos(3x)\bigr)' = 3\sin(3x)$$

   답. 부호입니다. $$\cos$$ 을 미분하면 $$-\sin$$ 이므로 $$-3\sin(3x)$$ 입니다.
2. $$\bigl(\sin(x^2)\bigr)' = \cos(x^2)$$

   답. 속미분 누락입니다. 속 $$x^2$$ 의 도함수 $$2x$$ 가 빠졌으므로 $$2x\cos(x^2)$$ 입니다.
3. $$\left(\dfrac{1}{x^3}\right)' = -\dfrac{3}{x^2}$$

   답. 음의 지수 처리입니다. $$x^{-3}$$ 을 미분하면 $$-3x^{-4}$$ 이므로 $$-\dfrac{3}{x^4}$$ 입니다. 지수가 $$-3$$ 에서 $$-4$$ 로 작아집니다.
4. $$\bigl(e^{-x}\bigr)' = e^{-x}$$

   답. 부호입니다. 속 $$-x$$ 의 도함수 $$-1$$ 이 곱해져 $$-e^{-x}$$ 입니다.
5. $$\bigl(\ln(3x+1)\bigr)' = \dfrac{1}{3x+1}$$

   답. 속미분 누락입니다. 속 $$3x+1$$ 의 도함수 3이 곱해져 $$\dfrac{3}{3x+1}$$ 입니다.

## 정리

- 기본 도함수 표와 상수배·합·차 규칙이면 다항식과 기본 함수는 바로 미분됩니다. $$x^n\to nx^{n-1}$$ 이 지수가 음수·분수여도 통합니다.
- 밑이 $$e$$ 일 때만 $$\dfrac{a^h-1}{h}$$ 가 1에 붙습니다. $$a=e^{\ln a}$$ 로 고쳐 적으면 $$(a^x)'=a^x\ln a$$ 가 한 줄로 나오고, $$\log_a x$$ 줄은 밑변환에서 따라옵니다.
- $$(fg)'=f'g+fg'$$ 이고, 곱이 셋이면 항이 셋입니다. $$\left(\dfrac fg\right)'=\dfrac{f'g-fg'}{g^2}$$ 은 $$f\cdot g^{-1}$$ 로 보면 앞의 둘에서 두 줄로 따라 나옵니다.
- 합성 $$g(f(x))$$ 는 오른쪽을 먼저 먹입니다. 순서를 바꾸면 다른 함수입니다.
- 연쇄법칙은 겉을 미분하고 속을 미분해 곱합니다. 껍질 수만큼 곱이 붙고, 곱인 이유는 눈금자 셋에서 배율이 이어 붙기 때문입니다. 라이프니츠 표기의 약분은 기억을 돕는 모양이지 증명이 아닙니다.
- $$f''$$ 의 부호가 휘는 방향을 말하고, 부호가 바뀌는 점이 변곡점입니다. $$f''=0$$ 은 필요조건일 뿐이라 $$x^4$$ 의 원점처럼 변곡점이 아닌 자리도 있습니다.
- 규칙으로 안 풀리는 모양 셋은 식을 먼저 손봅니다 — 음함수는 $$y'$$ 을 달고 미분하고, 곱과 거듭제곱이 겹치면 로그 미분법으로 합과 상수배로 내리고, 역함수는 $$\dfrac{dx}{dy}$$ 의 역수를 취합니다.

미분은 이걸로 손에 붙었습니다. 다음 글은 반대쪽으로 갑니다 — 곡선 아래 넓이를 직사각형으로 잘게 덮어 더하는 일입니다.
