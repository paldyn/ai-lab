[지난 글](/articles/math-basics-what-is-a-derivative)에서 정의식만으로 네 함수의 도함수를 얻었습니다. 정확하지만 느립니다. $$x^2 e^{-x^2}$$ 같은 식을 정의식으로 풀려고 하면 분자를 전개하다 끝나지 않습니다.

이 글은 계산만 다룹니다. 표 하나와 규칙 넷을 세우고, 그다음은 손으로 스무 문제입니다.

## 기본 도함수 표

가장 자주 쓰는 것들입니다. 각각은 정의식으로 유도할 수 있지만, 한 번 유도해 둔 뒤로는 외워 쓰는 것이 보통입니다.

| $$f(x)$$ | $$f'(x)$$ |
| --- | --- |
| $$c$$ (상수) | $$0$$ |
| $$x^n$$ | $$n\,x^{n-1}$$ |
| $$e^x$$ | $$e^x$$ |
| $$a^x$$ | $$a^x \ln a$$ |
| $$\ln x$$ | $$\dfrac1x$$ |
| $$\log_a x$$ | $$\dfrac{1}{x \ln a}$$ |
| $$\sin x$$ | $$\cos x$$ |
| $$\cos x$$ | $$-\sin x$$ |

$$x^n$$ 줄이 지난 글의 넷을 한 줄로 삼킵니다 — $$x^2\to2x$$, $$x^3\to3x^2$$, $$\dfrac1x=x^{-1}\to-x^{-2}$$, $$\sqrt{x}=x^{1/2}\to\dfrac12x^{-1/2}$$ 가 전부 이 규칙입니다. **$$n$$ 이 음수나 분수여도 그대로 통합니다.**

$$\cos x$$ 줄의 마이너스는 자주 빠뜨리는 자리입니다. [25번 글](/articles/math-basics-trigonometry-and-unit-circle)의 그래프를 떠올리면 $$\cos$$ 은 0에서 시작해 내려가므로 그 자리의 기울기가 음수여야 맞습니다.

### 왜 하필 밑이 e인가

표에서 $$e^x$$ 만 미분해도 그대로입니다. 왜 그런지 수치로 봅니다. 정의식에서 $$f(x)=a^x$$ 를 넣으면

$$\frac{a^{x+h}-a^x}{h} = a^x \cdot \frac{a^h-1}{h}$$

$$a^{x+h}=a^x a^h$$ 로 갈라 $$a^x$$ 을 밖으로 뺀 것입니다. **남은 $$\dfrac{a^h-1}{h}$$ 에는 $$x$$ 가 없습니다** — 그러니 이 값이 $$h\to0$$ 에서 무엇에 붙는지가 곧 $$a^x$$ 앞에 붙는 계수입니다. 밑을 셋으로 바꿔 가며 표를 채웁니다.

| $$h$$ | $$a=2$$ | $$a=e$$ | $$a=3$$ |
| --- | --- | --- | --- |
| 0.1 | 0.71773 | 1.05171 | 1.16123 |
| 0.01 | 0.69556 | 1.00502 | 1.10467 |
| 0.001 | 0.69339 | 1.00050 | 1.09922 |
| $$-0.01$$ | 0.69075 | 0.99502 | 1.09260 |

**$$a=e$$ 일 때만 1에 붙습니다.** 그래서 $$(e^x)'=e^x$$ 이고, 다른 밑에서는 계수가 하나 붙습니다 — 2에서는 0.693, 3에서는 1.099로 [22번 글](/articles/math-basics-logarithms)의 $$\ln 2$$ 와 $$\ln 3$$ 그대로입니다. 표의 $$(a^x)'=a^x\ln a$$ 가 이것입니다.

[21번 글](/articles/math-basics-exponential-function)에서 $$e$$ 를 $$\left(1+\dfrac1n\right)^n$$ 의 표로 정의할 때는 왜 그런 이상한 수를 고르는지가 분명하지 않았습니다. **여기가 그 값을 갚는 자리입니다** — 밑을 $$e$$ 로 잡으면 계수가 1이 되어 계산이 가장 깨끗해집니다.

## 상수배·합·차는 그대로 통과한다

셋은 유도할 것이 없습니다. 결과만 적습니다.

$$(c\,f)' = c\,f' \qquad (f+g)' = f'+g' \qquad (f-g)' = f'-g'$$

$$f(x)=5x^3-2x^2+7$$ 이면 항마다 따로 미분해서 붙이면 됩니다.

$$f'(x)=5\cdot3x^2-2\cdot2x+0 = 15x^2-4x$$

## 곱의 규칙

여기서부터는 그대로 통하지 않습니다. **$$(fg)'$$ 은 $$f'g'$$ 이 아닙니다.** 확인하기 쉽습니다 — $$f=g=x$$ 면 $$fg=x^2$$ 이라 $$(fg)'=2x$$ 인데, $$f'g'=1\times1=1$$ 입니다.

맞는 규칙은 넓이로 유도합니다. 가로가 $$f$$, 세로가 $$g$$ 인 직사각형의 넓이가 $$fg$$ 입니다.

![직사각형의 가로와 세로가 늘어날 때 넓이가 세 조각 늘어나는 그림](/assets/posts/math-basics-derivative-rules-product-rule.svg)

$$x$$ 가 $$h$$ 만큼 늘면 가로가 $$\Delta f$$, 세로가 $$\Delta g$$ 만큼 늘어납니다. 늘어난 넓이는 세 조각입니다.

$$f\,\Delta g + g\,\Delta f + \Delta f\,\Delta g$$

이것을 $$h$$ 로 나눕니다.

$$f\cdot\frac{\Delta g}{h} + g\cdot\frac{\Delta f}{h} + \Delta f\cdot\frac{\Delta g}{h}$$

앞의 두 조각은 $$f g'$$ 과 $$g f'$$ 이 됩니다. **셋째 조각만 사라집니다** — 뒤쪽 $$\dfrac{\Delta g}{h}$$ 는 $$g'$$ 으로 가는데 앞에 곱해진 $$\Delta f$$ 가 0으로 줄기 때문입니다. 그림에서 오른쪽 위 작은 네모가 가장 먼저 없어지는 것이 이것입니다.

$$(fg)' = f'g + fg'$$

써 봅니다. $$f(x)=x^2 e^x$$ 이면 $$f'=2x$$, $$g=e^x$$, $$g'=e^x$$ 이므로

$$(x^2e^x)' = 2x\,e^x + x^2e^x = (x^2+2x)e^x$$

## 몫의 규칙

곱의 규칙에서 따라 나오는 것이라 결과만 씁니다.

$$\left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}$$

**분자의 순서가 중요합니다.** 곱의 규칙과 달리 빼기라서 앞뒤를 바꾸면 부호가 뒤집힙니다. "위 미분 곱하기 아래, 빼기, 위 곱하기 아래 미분, 나누기 아래 제곱"으로 외우면 순서가 안 흔들립니다.

$$f(x)=\dfrac{x}{1+x}$$ 로 써 봅니다. 위는 $$x$$ 이고 미분하면 1, 아래는 $$1+x$$ 이고 미분하면 1입니다.

$$f'(x) = \frac{1\cdot(1+x) - x\cdot 1}{(1+x)^2} = \frac{1}{(1+x)^2}$$

## 합성함수를 먼저 세운다

마지막 규칙은 함수 안에 함수가 든 경우입니다. 그 모양에 먼저 이름을 붙여야 합니다.

**함수 $$f$$ 에 넣어 나온 값을 다시 $$g$$ 에 넣는 것을 합성이라고 하고 $$g(f(x))$$ 또는 $$g\circ f$$ 로 적습니다.** "지 서클 에프"라고 읽고, **오른쪽 것을 먼저 먹입니다.**

$$f(x)=x^2$$ 과 $$g(x)=x+1$$ 로 확인합니다.

$$g(f(x)) = g(x^2) = x^2+1 \qquad f(g(x)) = f(x+1) = (x+1)^2$$

![같은 2를 넣어도 합성 순서에 따라 5와 9로 갈리는 그림](/assets/posts/math-basics-derivative-rules-composition-order.svg)

$$x=2$$ 를 넣으면 앞은 $$4+1=5$$, 뒤는 $$3^2=9$$ 입니다. **순서를 바꾸면 다른 함수입니다.** 그래서 합성식을 볼 때 어느 쪽이 먼저인지를 반드시 갈라야 합니다.

가르는 이름도 정해 둡니다. **나중에 먹이는 바깥쪽을 겉이라 하고, 먼저 먹이는 안쪽을 속이라고 합니다.**

| 식 | 겉 | 속 |
| --- | --- | --- |
| $$(2x+1)^5$$ | 다섯제곱 | $$2x+1$$ |
| $$\sin(x^2)$$ | $$\sin$$ | $$x^2$$ |
| $$e^{-x^2}$$ | $$e$$ 의 거듭제곱 | $$-x^2$$ |
| $$\ln(1+x^2)$$ | $$\ln$$ | $$1+x^2$$ |

**괄호 안에 든 것이 속입니다.** 이 한 줄이면 대부분 갈립니다.

## 연쇄법칙

합성함수의 도함수는 이렇습니다.

$$\bigl(g(f(x))\bigr)' = g'(f(x))\cdot f'(x)$$

말로 하면 **겉을 미분하고, 속을 미분해서, 곱합니다.** 겉을 미분할 때 속은 통째로 하나의 덩어리로 두고, 미분이 끝난 뒤 그 자리에 속을 도로 넣습니다.

![겉과 속을 갈라 각각 미분하고 곱하는 네 단계 그림](/assets/posts/math-basics-derivative-rules-chain-rule.svg)

$$(2x+1)^5$$ 로 단계를 밟습니다.

1. 겉은 다섯제곱, 속은 $$2x+1$$
2. 겉을 미분하면 $$5u^4$$, 속을 도로 넣어 $$5(2x+1)^4$$
3. 속을 미분하면 2
4. 곱하면 $$10(2x+1)^4$$

$$\ln(1+x^2)$$ 도 같습니다. 겉은 $$\ln$$ 이라 미분하면 $$\dfrac1{\square}$$ 이고 속을 넣으면 $$\dfrac{1}{1+x^2}$$, 속을 미분하면 $$2x$$ 이므로

$$\bigl(\ln(1+x^2)\bigr)' = \frac{2x}{1+x^2}$$

### 세 겹이면 한 번 더 한다

껍질이 셋이면 안쪽으로 한 겹씩 벗기며 곱을 하나씩 더 붙입니다. $$e^{\sin(x^2)}$$ 을 봅니다 — 겉은 $$e$$ 의 거듭제곱, 그 속은 $$\sin$$, 그 속은 $$x^2$$ 입니다.

$$\bigl(e^{\sin(x^2)}\bigr)' = e^{\sin(x^2)}\cdot\cos(x^2)\cdot 2x$$

**벗긴 껍질의 수만큼 곱이 붙습니다.** 두 겹이면 둘, 세 겹이면 셋입니다.

## 고계도함수

$$f'$$ 도 함수이므로 다시 미분할 수 있습니다. 그렇게 얻은 것을 **이계도함수** 라 하고 $$f''$$ 로 적습니다. "에프 투 프라임"이라고 읽습니다. 더 가면 $$f'''$$, 그 뒤로는 작대기 대신 숫자를 괄호에 넣어 $$f^{(4)}$$ 로 적습니다.

$$f(x)=x^4$$ 로 끝까지 가 봅니다.

| | 식 |
| --- | --- |
| $$f$$ | $$x^4$$ |
| $$f'$$ | $$4x^3$$ |
| $$f''$$ | $$12x^2$$ |
| $$f'''$$ | $$24x$$ |
| $$f^{(4)}$$ | $$24$$ |
| $$f^{(5)}$$ | $$0$$ |

### f″의 부호는 휘는 방향을 말한다

지난 글에서 $$f'$$ 의 부호가 오르내림을 말했습니다. $$f''$$ 은 $$f'$$ 의 도함수이므로 **기울기 자체가 커지는 중인지 작아지는 중인지** 를 말합니다.

![아래로 볼록, 위로 볼록, 그리고 변곡점을 그린 그림](/assets/posts/math-basics-derivative-rules-second-derivative.svg)

- $$f''>0$$ 이면 기울기가 커지는 중이라 그릇처럼 위로 열립니다. 이것을 **아래로 볼록** 이라고 합니다.
- $$f''<0$$ 이면 기울기가 작아지는 중이라 덮개처럼 아래로 열립니다. **위로 볼록** 입니다.
- **$$f''$$ 의 부호가 바뀌는 점을 변곡점이라고 합니다.** 휘는 방향이 뒤집히는 자리입니다.

$$f(x)=x^3$$ 에서 확인합니다. $$f'=3x^2$$, $$f''=6x$$ 이므로 $$x<0$$ 에서 음수, $$x>0$$ 에서 양수입니다. **$$x=0$$ 이 변곡점입니다.** 지난 글에서 이 점이 극값이 아니었던 것과 나란히 놓으면 정리가 됩니다 — $$f'(0)=0$$ 이지만 꺾이지는 않았고, 대신 휘는 방향이 거기서 뒤집혔습니다.

## 음함수 미분

$$y$$ 가 $$x$$ 의 식으로 깔끔하게 풀려 있지 않은 경우도 있습니다. 원의 방정식 $$x^2+y^2=25$$ 가 그렇습니다. **이럴 때는 양변을 그대로 미분하되, $$y$$ 를 미분할 때마다 연쇄법칙에 따라 $$y'$$ 을 곱해 줍니다.** $$y$$ 가 속에 든 함수이기 때문입니다.

$$2x + 2y\,y' = 0$$

$$y'$$ 에 대해 풀면

$$y' = -\frac{x}{y}$$

점 $$(3,\ 4)$$ 에서 $$-\dfrac34$$ 입니다. **초급에서 이것을 다시 쓰는 자리는 없으므로 이런 것이 있다는 것만 보고 지나갑니다.**

## 실습 스무 문제

여기가 이 글의 본체입니다. 규칙을 읽는 것과 쓰는 것은 다릅니다.

**틀렸을 때는 이 순서로 의심합니다.**

1. **부호** — $$\cos$$ 을 미분하면 $$-\sin$$ 입니다. $$e^{-x}$$ 처럼 속에 마이너스가 있으면 그것도 곱해집니다.
2. **속미분 누락** — 괄호가 있었는데 답에 속의 도함수가 안 붙었으면 그것입니다. $$\sin(x^2)$$ 의 답에 $$2x$$ 가 있는지 봅니다.
3. **음의 지수 처리** — $$\dfrac{1}{x^2}=x^{-2}$$ 이고 미분하면 $$-2x^{-3}=-\dfrac{2}{x^3}$$ 입니다. 지수가 작아진다는 것은 음수 쪽으로 더 간다는 뜻입니다.

답을 컴퓨터로 맞춰 보는 방법도 있습니다. 그 절차는 48번 · SymPy 검산의 몫이라 여기서는 그런 것이 있다고만 적어 둡니다.

## 연습 문제

### 연습 1 — 표와 합·상수배

1. $$f(x)=x^7$$

   답. $$f'(x)=7x^6$$ 입니다.
2. $$f(x)=4x^3-3x^2+6$$

   답. 항마다 따로 미분해 $$f'(x)=12x^2-6x$$ 입니다. 상수 6은 0이 됩니다.
3. $$f(x)=\sqrt{x}+\dfrac1x$$

   답. $$x^{1/2}+x^{-1}$$ 로 고쳐 적으면 $$f'(x)=\dfrac12x^{-1/2}-x^{-2} = \dfrac{1}{2\sqrt{x}}-\dfrac{1}{x^2}$$ 입니다.
4. $$f(x)=3e^x-2\ln x$$

   답. $$f'(x)=3e^x-\dfrac2x$$ 입니다.
5. $$f(x)=4\sin x+\cos x$$

   답. $$f'(x)=4\cos x-\sin x$$ 입니다. $$\cos$$ 쪽에서 마이너스가 나옵니다.

### 연습 2 — 곱의 규칙

1. $$f(x)=x^3 e^x$$

   답. $$3x^2e^x + x^3e^x = (x^3+3x^2)e^x$$ 입니다.
2. $$f(x)=x\ln x$$

   답. $$1\cdot\ln x + x\cdot\dfrac1x = \ln x + 1$$ 입니다.
3. $$f(x)=(x+1)\sin x$$

   답. $$1\cdot\sin x + (x+1)\cos x = \sin x + (x+1)\cos x$$ 입니다.
4. $$f(x)=e^x\cos x$$

   답. $$e^x\cos x + e^x(-\sin x) = e^x(\cos x-\sin x)$$ 입니다.

### 연습 3 — 몫의 규칙

1. $$f(x)=\dfrac{x^2}{1+x}$$

   답. $$\dfrac{2x(1+x)-x^2\cdot1}{(1+x)^2} = \dfrac{x^2+2x}{(1+x)^2}$$ 입니다.
2. $$f(x)=\dfrac{x^2+1}{x}$$

   답. $$\dfrac{2x\cdot x-(x^2+1)}{x^2} = \dfrac{x^2-1}{x^2} = 1-\dfrac{1}{x^2}$$ 입니다. $$x+\dfrac1x$$ 로 먼저 나눠 적고 미분해도 같습니다.
3. $$f(x)=\dfrac{\sin x}{x}$$

   답. $$\dfrac{x\cos x-\sin x}{x^2}$$ 입니다.

### 연습 4 — 연쇄법칙

1. $$f(x)=(3x-2)^4$$

   답. 겉을 미분해 $$4(3x-2)^3$$, 속을 미분해 3, 곱하면 $$12(3x-2)^3$$ 입니다.
2. $$f(x)=\ln(1+3x)$$

   답. $$\dfrac{1}{1+3x}\times3 = \dfrac{3}{1+3x}$$ 입니다.
3. $$f(x)=\sin(4x)$$

   답. $$\cos(4x)\times4 = 4\cos(4x)$$ 입니다.
4. $$f(x)=e^{3x}$$

   답. $$e^{3x}\times3 = 3e^{3x}$$ 입니다.
5. $$f(x)=\sqrt{x^2+1}$$

   답. $$(x^2+1)^{1/2}$$ 로 보면 겉이 $$\dfrac12(x^2+1)^{-1/2}$$ 이고 속이 $$2x$$ 이므로 $$\dfrac{x}{\sqrt{x^2+1}}$$ 입니다.

### 연습 5 — 규칙을 섞어 쓰기

1. $$f(x)=x^2e^{-x^2}$$

   답. 곱의 규칙으로 $$2x\,e^{-x^2} + x^2\cdot e^{-x^2}\cdot(-2x)$$ 이고, 뒤쪽에 연쇄법칙이 한 번 들어갔습니다. 정리하면 $$(2x-2x^3)e^{-x^2}$$ 입니다.
2. $$f(x)=e^{\cos(x^2)}$$

   답. 껍질이 셋이라 곱이 셋입니다. $$e^{\cos(x^2)}\cdot(-\sin(x^2))\cdot2x = -2x\sin(x^2)\,e^{\cos(x^2)}$$ 입니다.
3. $$f(x)=\dfrac{\ln x}{x^2}$$

   답. 몫의 규칙으로 $$\dfrac{\frac1x\cdot x^2-\ln x\cdot 2x}{x^4} = \dfrac{x-2x\ln x}{x^4} = \dfrac{1-2\ln x}{x^3}$$ 입니다.

## 정리

- 기본 도함수 표와 상수배·합·차 규칙이면 다항식과 기본 함수는 바로 미분됩니다. $$x^n\to nx^{n-1}$$ 이 지수가 음수·분수여도 통합니다.
- 밑이 $$e$$ 일 때만 $$\dfrac{a^h-1}{h}$$ 가 1에 붙습니다. 다른 밑에서는 $$\ln a$$ 가 계수로 붙습니다.
- $$(fg)'=f'g+fg'$$ 이고, $$\left(\dfrac fg\right)'=\dfrac{f'g-fg'}{g^2}$$ 입니다. **곱의 규칙과 달리 몫은 빼기라 순서가 중요합니다.**
- 합성 $$g(f(x))$$ 는 오른쪽을 먼저 먹입니다. 순서를 바꾸면 다른 함수입니다.
- 연쇄법칙은 **겉을 미분하고 속을 미분해 곱합니다.** 껍질 수만큼 곱이 붙습니다.
- $$f''$$ 의 부호가 휘는 방향을 말하고, 부호가 바뀌는 점이 **변곡점** 입니다.

미분은 이걸로 손에 붙었습니다. 다음 글은 반대쪽으로 갑니다 — 곡선 아래 넓이를 직사각형으로 잘게 덮어 더하는 일입니다.
