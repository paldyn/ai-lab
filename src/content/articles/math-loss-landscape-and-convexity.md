학습 곡선이 내려갑니다. 손실이 2.7에서 1.9로, 다시 1.4로 떨어지고 모델은 쓸 만해집니다. 그런데 최적화 교과서를 펴면 수렴을 보장하는 정리들은 거의 전부 **볼록함수**를 전제하고, 신경망의 손실은 볼록이 아닙니다. 보장이 없는 채로 매일 학습이 되고 있는 셈입니다.

[지난 글](/articles/math-positional-encoding-math)까지가 순전파와 역전파의 식이었다면, 이 단원은 그 식을 **어떻게 내려가는가**입니다. 첫 글인 여기서는 내려갈 지형이 어떻게 생겼는지를 봅니다. 볼록이 정확히 무엇을 보장하는지, 신경망이 왜 그 조건에서 벗어나는지, 그리고 벗어났는데도 학습이 되는 이유를 셈으로 확인합니다.

## 볼록집합과 볼록함수

[젠센 부등식 글](/articles/math-jensen-inequality)에서 한 변수 볼록함수를 "현이 그래프 위에 있다"로 정의했습니다. 파라미터가 수억 개인 지형을 다루려면 이것을 벡터로 옮겨야 합니다.

먼저 정의역부터입니다. 집합 $$C \subseteq \mathbb{R}^n$$ 가 **볼록집합**이라는 것은, 그 안의 두 점을 잇는 선분이 통째로 집합 안에 있다는 뜻입니다.

$$x, y \in C, \ \ 0 \le t \le 1 \ \implies \ tx + (1-t)y \in C$$

$$tx + (1-t)y$$ 는 $$t$$ 를 1에서 0으로 줄이며 $$x$$ 에서 $$y$$ 로 곧게 이동하는 점입니다. 이것을 두 점의 **볼록결합**이라고 부릅니다.

![볼록집합과 볼록함수의 정의](/assets/posts/math-loss-landscape-and-convexity-convex-definition.svg)

볼록집합 위에서 정의된 $$f$$ 가 **볼록함수**라는 것은 같은 선분 위에서 함수값이 현을 넘지 않는다는 뜻입니다.

$$f\big(tx + (1-t)y\big) \le t f(x) + (1-t) f(y)$$

왼쪽은 "먼저 섞고 그다음 함수에 넣은 값", 오른쪽은 "먼저 함수에 넣고 그다음 섞은 값"입니다. **섞은 다음이 언제나 더 작거나 같다** — 정의는 이 한 문장이고, 아래에서 신경망을 반박할 때 쓸 것도 정확히 이 부등식입니다.

미분 가능하면 같은 조건을 두 가지로 더 적을 수 있습니다.

> **1차 조건.** $$f(y) \ge f(x) + \nabla f(x)\cdot(y - x)$$ 가 모든 $$x, y$$ 에서 성립한다.
>
> **2차 조건.** 헤세 행렬 $$\nabla^2 f(x)$$ 가 모든 $$x$$ 에서 **양반정치**다.

**헤세 행렬**은 이계편도함수를 모아 놓은 $$n \times n$$ 대칭 행렬 $$[\nabla^2 f]_{ij} = \partial^2 f / \partial x_i \partial x_j$$ 입니다. 다변수 테일러 전개에서 이것이 어디서 나오고 곡률로 어떻게 읽히는지는 다음 글이 맡고, 여기서는 부호 판정에만 씁니다. **양반정치**(positive semidefinite)는 모든 벡터 $$z$$ 에 대해 $$z^{\mathsf T} \nabla^2 f\, z \ge 0$$ 이라는 뜻이고, [대칭 행렬 글](/articles/math-spectral-theorem-and-quadratic-forms)에서 본 대로 이것은 **모든 고윳값이 0 이상**이라는 말과 같습니다.

1차 조건이 말하는 것은 "접평면이 그래프 아래에 깔린다"입니다. 2차 조건은 "어느 방향으로 잘라도 위로 굽는다"입니다.

## 볼록이 주는 선물은 정확히 하나다

볼록성이 왜 그렇게 대접받는지는 1차 조건에서 두 줄로 나옵니다. $$\nabla f(x^\star) = 0$$ 인 점을 잡습니다.

$$f(y) \ \ge\ f(x^\star) + \underbrace{\nabla f(x^\star)}_{=\,0}\cdot(y - x^\star) \ =\ f(x^\star)$$

모든 $$y$$ 에 대해 성립하므로 $$x^\star$$ 는 **전역최소**입니다.

> **볼록함수에서는 그래디언트가 0인 점이 곧 전역최소다.** 국소최소도, 안장점도, 평지도 따로 없다.

![볼록이면 임계점이 하나뿐이고 그것이 전역최소다](/assets/posts/math-loss-landscape-and-convexity-convex-gradient-zero.svg)

이것이 전부이자 전부입니다. 볼록이면 "여기가 바닥인가, 아니면 더 낮은 데가 어딘가 있나"를 고민할 필요가 없습니다. 손에 든 그래디언트가 0이면 끝난 것입니다.

우리가 쓰는 손실 중에도 볼록한 것이 있습니다. 선형회귀의 제곱오차 $$L(w) = \|Xw - y\|^2$$ 는 헤세가 $$2X^{\mathsf T}X$$ 이고

$$z^{\mathsf T}(2X^{\mathsf T}X)z = 2\,\|Xz\|^2 \ \ge\ 0$$

이라 어디서나 양반정치입니다. 로지스틱 회귀의 교차엔트로피도 가중치에 대해 볼록입니다. **선형 모델까지는 볼록의 세계입니다.** 층을 하나 얹는 순간 그 세계가 끝납니다.

## 뉴런을 맞바꾸면 손실이 같다

신경망 손실이 비볼록이라는 것은 실험적 관찰이 아니라 **한 줄로 증명되는 사실**입니다. 필요한 것은 대칭성 하나뿐입니다.

은닉층의 뉴런 두 개를 통째로 맞바꿉니다 — 첫째 뉴런의 입력 가중치와 출력 가중치를 둘째 것과 바꿔 답니다. 그러면 은닉 유닛의 계산 순서만 바뀔 뿐 **망이 계산하는 함수가 글자 그대로 같습니다**. 손실도 당연히 같습니다. 은닉 뉴런이 $$h$$ 개면 이런 재배열이 $$h!$$ 가지 있고, 전역최소 하나가 있으면 그것과 손실이 똑같은 점이 최소 $$h!$$ 개 있다는 뜻입니다. 이것을 **치환 대칭성**이라고 부릅니다.

이제 볼록성의 정의를 그대로 들이댑니다. 가장 작은 망으로 손계산을 해 보겠습니다.

입력이 2차원, 은닉 뉴런이 2개(ReLU), 출력이 스칼라입니다.

$$f(x) = v_1\,\mathrm{relu}(w_1 \cdot x) + v_2\,\mathrm{relu}(w_2 \cdot x)$$

데이터는 한 점입니다. $$x = (1, 0)$$, 정답 $$t = 1$$, 손실은 $$L = (f(x) - t)^2$$.

**파라미터 A**: $$w_1 = (1,0),\ v_1 = 1,\quad w_2 = (0,1),\ v_2 = -1$$

$$f_A(x) = 1\cdot\mathrm{relu}(1) + (-1)\cdot\mathrm{relu}(0) = 1 - 0 = 1 \quad\Rightarrow\quad L(A) = (1-1)^2 = 0$$

**파라미터 B**는 두 뉴런을 맞바꾼 것입니다. $$w_1 = (0,1),\ v_1 = -1,\quad w_2 = (1,0),\ v_2 = 1$$

$$f_B(x) = -1\cdot\mathrm{relu}(0) + 1\cdot\mathrm{relu}(1) = 0 + 1 = 1 \quad\Rightarrow\quad L(B) = 0$$

둘 다 손실 0인 전역최소입니다. 이제 **중점** $$M = \tfrac12 A + \tfrac12 B$$ 를 파라미터마다 평균해서 만듭니다.

$$w_1 = \tfrac{(1,0)+(0,1)}{2} = (0.5,\ 0.5), \quad v_1 = \tfrac{1 + (-1)}{2} = 0$$

$$w_2 = \tfrac{(0,1)+(1,0)}{2} = (0.5,\ 0.5), \quad v_2 = \tfrac{-1 + 1}{2} = 0$$

출력 가중치가 둘 다 0이 되었습니다. 중점의 망은 무엇을 넣든 0을 뱉습니다.

$$f_M(x) = 0 \cdot \mathrm{relu}(0.5) + 0 \cdot \mathrm{relu}(0.5) = 0 \quad\Rightarrow\quad L(M) = (0-1)^2 = 1$$

볼록함수라면 $$L(M) \le \tfrac12 L(A) + \tfrac12 L(B) = 0$$ 이어야 합니다. 실제로는 $$1 > 0$$ 입니다.

> **반례 하나로 끝났습니다.** 신경망의 손실은 볼록이 아니다.

![두 전역최소의 중점에서 손실이 솟는다](/assets/posts/math-loss-landscape-and-convexity-permutation.svg)

무엇이 일어났는지가 중요합니다. 두 뉴런을 평균 내니 **둘이 똑같아졌고**, 서로를 상쇄해 표현력을 잃었습니다. 치환 대칭성이 만든 여러 최소점 사이에는 언제나 이런 봉우리가 낍니다 — 그래서 비볼록성은 신경망의 사고가 아니라 **구조가 보장하는 성질**입니다. 파라미터를 늘리고 층을 쌓으면 대칭은 더 늘어날 뿐입니다.

## 그런데 왜 학습이 되는가

볼록이 아니라는 것은 "그래디언트가 0인 점이 전역최소가 아닐 수 있다"는 뜻입니다. 그래디언트가 0인 점을 **임계점**이라고 부르고, 헤세의 고윳값 부호가 임계점의 종류를 정합니다.

| 헤세 고윳값 | 임계점의 종류 | 경사하강이 만나면 |
| --- | --- | --- |
| 전부 양수 | 국소최소 | 갇힌다 |
| 전부 음수 | 국소최대 | 조금만 밀려도 벗어난다 |
| 양수와 음수가 섞임 | **안장점** | 음수 방향으로 빠져나간다 |
| 상당수가 0 근처 | **평지** | 나가긴 하는데 아주 느리다 |

![임계점 네 갈래와 헤세 고윳값의 부호](/assets/posts/math-loss-landscape-and-convexity-critical-points.svg)

여기서 **차원이 결정적입니다.** 임계점이 국소최소이려면 고윳값 $$n$$ 개가 **하나도 빠짐없이** 양수여야 합니다. 부호가 서로 독립인 동전 던지기라면 그 확률은

$$P(\text{모두 양수}) = 2^{-n}$$

입니다. 파라미터가 100개만 되어도 $$2^{-100} \approx 8 \times 10^{-31}$$ 이고, 요즘 모델의 $$n$$ 은 $$10^9$$ 을 넘습니다. **임의로 고른 임계점이 국소최소일 가능성은 사실상 없고, 거의 전부가 안장점입니다.**

부호가 독립이라는 가정은 정확하지 않습니다. 실제 헤세의 고윳값들은 서로 밀어내며 반원 모양으로 퍼지고, 그 때문에 전부 같은 부호가 되기는 동전 던지기보다 **오히려 더 어렵습니다**. 무작위 대칭행렬로 세어 보면 $$2^{-n}$$ 보다 훨씬 빨리 줄어듭니다.

| $$n$$ | 고윳값이 전부 양수인 비율 (20만 회) | 동전 던지기 $$2^{-n}$$ |
| --- | --- | --- |
| 1 | 0.4999 | 0.5 |
| 2 | 0.1467 | 0.25 |
| 3 | 0.0250 | 0.125 |
| 4 | 0.00257 | 0.0625 |
| 5 | 0.00010 | 0.03125 |
| 6 | 0 (한 번도 없음) | 0.0156 |

파라미터가 여섯 개만 되어도 20만 번을 뽑는 동안 한 번도 안 나왔습니다.

**안장점은 국소최소와 결정적으로 다릅니다.** 안장점에는 음의 고윳값이 있고, 그 고유벡터 방향으로 가면 손실이 **내려갑니다**. 내려가는 길이 열려 있다는 뜻입니다. 경사하강은 그 방향의 그래디언트가 작아 오래 머물지만 결국은 빠져나갑니다. 다음 글부터 다룰 모멘텀과 적응적 학습률이 실제로 하는 일이 이 체류 시간을 줄이는 것입니다.

정리하면 이렇습니다.

- 비볼록이라 **전역최소를 찾는다는 보장은 없다.** 그 보장은 포기한 지 오래다.
- 대신 고차원에서는 **갇히는 함정보다 지나가는 고개가 압도적으로 많다.** 시간이 걸릴 뿐 길은 대개 열려 있다.
- 도달한 국소최소들끼리는 손실 값이 서로 비슷하다는 것이 반복 관찰되어 왔다. 어느 최소에 앉느냐보다 **거기까지 얼마나 빨리 가느냐**가 실무의 문제가 된 이유다.

## 코드로 확인하기

먼저 중점 반례입니다.

```python
import numpy as np

relu = lambda z: np.maximum(z, 0.0)
x, t = np.array([1.0, 0.0]), 1.0

def loss(W, v):
    return (v @ relu(W @ x) - t) ** 2

W_A, v_A = np.array([[1., 0.], [0., 1.]]), np.array([ 1., -1.])
W_B, v_B = np.array([[0., 1.], [1., 0.]]), np.array([-1.,  1.])   # 두 뉴런을 맞바꾼 것
W_M, v_M = (W_A + W_B) / 2, (v_A + v_B) / 2

print("L(A) =", loss(W_A, v_A))
print("L(B) =", loss(W_B, v_B))
print("L(M) =", loss(W_M, v_M), " 볼록이면 <= ", 0.5 * loss(W_A, v_A) + 0.5 * loss(W_B, v_B))
print("중점의 은닉 가중치:", W_M.tolist(), " 출력 가중치:", v_M.tolist())

# L(A) = 0.0
# L(B) = 0.0
# L(M) = 1.0  볼록이면 <=  0.0
# 중점의 은닉 가중치: [[0.5, 0.5], [0.5, 0.5]]  출력 가중치: [0.0, 0.0]
```

두 뉴런이 같아지고 출력 가중치가 상쇄되어 사라진 것이 숫자로 보입니다.

다음은 고윳값 부호입니다.

```python
rng = np.random.default_rng(0)

for n in [1, 2, 3, 4, 5, 6]:
    hit = 0
    for _ in range(200_000):
        A = rng.normal(size=(n, n))
        S = (A + A.T) / np.sqrt(2)              # 무작위 대칭행렬
        if np.linalg.eigvalsh(S)[0] > 0:        # 가장 작은 고윳값이 양수인가
            hit += 1
    print(f"n={n}  전부 양수 {hit/200_000:.5f}   2^-n = {2.0**-n:.5f}")

# n=1  전부 양수 0.49991   2^-n = 0.50000
# n=2  전부 양수 0.14673   2^-n = 0.25000
# n=3  전부 양수 0.02504   2^-n = 0.12500
# n=4  전부 양수 0.00257   2^-n = 0.06250
# n=5  전부 양수 0.00010   2^-n = 0.03125
# n=6  전부 양수 0.00000   2^-n = 0.01562
```

선형회귀 쪽도 확인해 둡니다.

```python
X = np.random.default_rng(1).normal(size=(20, 4))
print(np.round(np.linalg.eigvalsh(2 * X.T @ X), 4))
# [15.1246 24.0044 29.0265 45.8561]      ← 전부 양수, 어디서나 볼록
```

## 정리

- **볼록집합**은 두 점을 잇는 선분을 품는 집합이고, **볼록함수**는 그 선분 위에서 $$f(tx+(1-t)y) \le tf(x)+(1-t)f(y)$$ 를 만족하는 함수다. 미분 가능하면 접평면이 그래프 아래라는 조건, 헤세가 양반정치라는 조건과 같다.
- 볼록이 주는 것은 딱 하나다 — **그래디언트가 0이면 전역최소다.** 선형회귀와 로지스틱 회귀는 여기에 속한다.
- 신경망은 아니다. 은닉 뉴런을 맞바꿔도 손실이 같으므로 손실이 같은 점이 $$h!$$ 개 있고, 그중 둘의 **중점에서는 두 뉴런이 같아져 표현력을 잃는다.** 손계산 하나로 $$L(M) = 1 > 0 = \tfrac12 L(A) + \tfrac12 L(B)$$ 라는 반례가 나온다.
- 그래도 학습이 되는 이유는 차원이다. 임계점이 국소최소이려면 헤세의 고윳값 $$n$$ 개가 전부 양수여야 하는데 그 확률은 $$2^{-n}$$ 보다도 빨리 줄어든다. **고차원의 임계점은 거의 전부 안장점이고, 안장점에는 내려가는 방향이 남아 있다.**
- 그래서 실무의 질문이 "전역최소를 찾을 수 있는가"에서 "**얼마나 빨리 내려가는가**"로 옮겨 간다.

빨리 내려가려면 지금 서 있는 자리가 어떻게 굽어 있는지를 알아야 합니다. 이 글에서 부호 판정에만 쓴 헤세 행렬이 실은 각 방향의 **곡률**을 담고 있습니다. 다음 글에서 다변수 테일러 전개로 헤세가 어디서 나오는지를 유도하고, 고윳값의 비율인 조건수가 등고선을 얼마나 길쭉하게 만드는지를 봅니다.
