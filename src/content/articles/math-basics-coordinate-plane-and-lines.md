임베딩 100만 개에서 비슷한 것을 찾아야 합니다. 전부 비교하면 느리니까 해시로 먼저 후보를 줄입니다. 그 코드가 대개 이렇게 생겼습니다.

```python
import numpy as np

rng = np.random.default_rng(0)
W = rng.normal(size=(128, 768))      # 무작위 초평면 128장
bits = (embeddings @ W.T > 0)        # (N, 128) 불리언
```

한 줄에 전부 들어 있습니다. `embeddings @ W.T > 0`이 하는 일은 **각 벡터가 128개 평면의 어느 쪽에 있는지**를 묻는 것이고, 그 답 128비트가 곧 해시입니다. 그런데 이 줄을 읽으려면 세 가지를 알아야 합니다. `W`의 한 행이 왜 "평면"인지, 왜 하필 부호가 "어느 쪽"을 답하는지, 그리고 그 평면이 벡터에서 얼마나 떨어져 있는지는 어떻게 재는지입니다.

셋 다 좌표평면 위 직선 하나에서 나옵니다. 차원을 768로 올려도 식이 그대로라서, 2차원에서 손으로 한 번 확인하면 그다음은 항을 늘리는 일만 남습니다.

## 이 글이 필요한지 30초 확인

**문제 1.** 직선 $$3x + 4y - 24 = 0$$에 수직인 벡터를 하나 적어 보세요.

**문제 2.** 점 $$P(2, 7)$$에서 그 직선까지의 거리는 얼마인가요?

<br>

1번에 "$$(3, 4)$$"라고 바로 적었고 2번을 $$\lvert 3\cdot2 + 4\cdot7 - 24 \rvert / 5 = 2$$로 계산했다면 **이 글은 건너뛰어도 됩니다.** 본선 5번 · 노름과 거리로 바로 가세요.

1번에서 기울기를 먼저 구했다면 — 답은 맞을 수 있지만 먼 길을 간 것입니다. **계수쌍을 그대로 읽는 법**이 이 글의 절반입니다.

## 점을 숫자 목록으로 적는다

평면 위 점 하나를 순서쌍 $$(x, y)$$로 적습니다. 순서가 있다는 것이 핵심이라서 $$(2, 7)$$과 $$(7, 2)$$는 다른 점입니다.

이 표기가 대단해 보이지 않지만, 여기서 딱 한 걸음만 나가면 **성분 목록으로 대상을 적는다**는 발상이 됩니다. 성분이 셋이면 $$(x, y, z)$$, 768개면 $$(x_1, x_2, \dots, x_{768})$$입니다. 임베딩 한 줄이 정확히 그것이고, 본선 4번 · 벡터: 임베딩 한 줄이 숫자 배열이 아니라 벡터인 이유가 그 목록 위에 덧셈과 스칼라배를 얹어 '벡터'라는 수학 대상을 세웁니다. 이 글은 그 앞 계단인 **좌표와 거리**만 맡습니다.

## 두 점 사이 거리 — 항을 늘리기만 하면 된다

두 점 $$A(x_1, y_1)$$과 $$B(x_2, y_2)$$ 사이 거리를 구합니다. 두 점을 잇는 선분을 빗변으로 하는 직각삼각형을 그리면 밑변이 $$\lvert x_1 - x_2 \rvert$$, 높이가 $$\lvert y_1 - y_2 \rvert$$입니다. 피타고라스 정리를 그대로 적용합니다.

$$d(A, B) = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$$

숫자를 넣어 봅니다. $$A(1, 2)$$, $$B(4, 6)$$이면

$$d = \sqrt{(1-4)^2 + (2-6)^2} = \sqrt{9 + 16} = \sqrt{25} = 5$$

3차원으로 가면 항이 하나 늘어납니다. 밑면에서 먼저 피타고라스를 쓰고 그 결과를 다시 빗변으로 삼아 한 번 더 쓰면 이렇게 됩니다.

$$d = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2 + (z_1-z_2)^2}$$

**그리고 여기서 멈출 이유가 없습니다.** 성분이 $$n$$개면 항도 $$n$$개입니다.

$$d(a, b) = \sqrt{\sum_{i=1}^{n} (a_i - b_i)^2}$$

이 식이 768차원 임베딩 두 개의 거리를 재는 그 식입니다. `np.linalg.norm(a - b)`가 계산하는 값이고, 3차원 이상을 그림으로 볼 수 없어도 **식은 그림을 필요로 하지 않습니다.** 항을 늘려도 계산 절차가 똑같다는 것이 요점입니다.

본선 5번 · 노름과 거리는 이 식을 반대 방향에서 다시 세웁니다. 거기서는 "크기를 잰다"가 만족해야 할 세 조건을 먼저 적고, 그 조건을 만족하는 함수가 여럿이라는 것을 보인 뒤 이 식을 그중 하나(L2)로 자리매김합니다. 이 글은 **그 식이 어디서 왔는지**만 보여 주고 넘깁니다.

## 직선을 적는 세 가지 방법

기울기부터 봅니다. 직선 위에서 $$x$$가 1 늘 때 $$y$$가 얼마나 오르는지가 기울기입니다.

$$m = \frac{\Delta y}{\Delta x} = \frac{y_2 - y_1}{x_2 - x_1}$$

$$A(1, 2)$$와 $$B(4, 6)$$을 지나는 직선이면 $$m = (6-2)/(4-1) = 4/3$$입니다. "오른쪽으로 3칸 가면 위로 4칸 오른다"입니다.

같은 직선을 적는 방법이 셋 있습니다.

| 이름 | 꼴 | 언제 편한가 |
| --- | --- | --- |
| 기울기-절편형 | $$y = mx + b$$ | 그래프를 그릴 때 |
| 점-기울기형 | $$y - y_1 = m(x - x_1)$$ | 지나는 점 하나와 기울기를 알 때 |
| 일반형 | $$ax + by + c = 0$$ | **고차원으로 올릴 때** |

셋 사이를 옮겨 적어 봅니다. $$A(1,2)$$를 지나고 기울기 $$4/3$$인 직선은 점-기울기형으로

$$y - 2 = \tfrac{4}{3}(x - 1)$$

양변에 3을 곱하면 $$3y - 6 = 4x - 4$$이고, 한쪽으로 모으면 일반형이 나옵니다.

$$4x - 3y + 2 = 0$$

**기울기-절편형에는 치명적인 구멍이 하나 있습니다.** 세로선 $$x = 5$$는 기울기가 무한대라 $$y = mx + b$$로 적을 수 없습니다. 일반형은 $$1 \cdot x + 0 \cdot y - 5 = 0$$으로 아무 문제 없이 적습니다. 예외가 없다는 것이 일반형을 고차원으로 가져갈 수 있는 이유입니다.

평행과 수직도 짚어 둡니다. 두 직선이 평행하면 기울기가 같고, 수직이면 기울기의 곱이 $$-1$$입니다.

$$m_1 m_2 = -1$$

기울기 $$4/3$$인 직선에 수직인 직선의 기울기는 $$-3/4$$입니다. 이 조건을 잠시 기억해 두세요. 곧 이것이 다른 언어로 다시 나타납니다.

## 계수쌍 (a, b)가 곧 법선이다

여기서부터가 본론입니다. 일반형 $$ax + by + c = 0$$의 앞 두 계수를 그냥 벡터로 읽습니다.

$$n = (a, b)$$

주장은 이렇습니다. **이 벡터는 그 직선에 수직입니다.** 계산으로 확인합니다.

직선 위의 서로 다른 두 점 $$P(x_1, y_1)$$과 $$Q(x_2, y_2)$$를 잡습니다. 둘 다 직선 위에 있으므로

$$ax_1 + by_1 + c = 0, \qquad ax_2 + by_2 + c = 0$$

두 식을 빼면 $$c$$가 사라집니다.

$$a(x_1 - x_2) + b(y_1 - y_2) = 0$$

여기서 $$(x_1 - x_2,\; y_1 - y_2)$$는 **직선을 따라가는 방향벡터**입니다. 그리고 왼쪽 식은 $$n = (a, b)$$와 그 방향벡터의 성분끼리 곱해 더한 것, 즉 내적입니다.

$$n \cdot d = 0$$

내적이 0이라는 것이 곧 수직입니다. 두 벡터가 이루는 각이 $$90°$$이면 $$\cos 90° = 0$$이라 내적이 0이 되고, 그 역도 성립합니다. 왜 그런지는 본선 6번 · 내적·코사인·L2 거리가 언제 같은 순위를 주고 언제 갈리는가가 $$a \cdot b = \lVert a \rVert \lVert b \rVert \cos\theta$$를 세우며 답합니다. 여기서는 **"내적이 0이면 수직"이라는 사실 하나만** 빌려 씁니다.

앞에서 본 $$m_1 m_2 = -1$$과 같은 말인지 확인해 봅니다. $$ax + by + c = 0$$의 기울기는 $$-a/b$$입니다($$y$$에 대해 풀면 $$y = -\frac{a}{b}x - \frac{c}{b}$$). 법선 $$n = (a, b)$$가 나타내는 방향의 기울기는 $$b/a$$입니다. 둘을 곱하면

$$\left(-\frac{a}{b}\right)\left(\frac{b}{a}\right) = -1$$

같은 사실을 두 언어로 적은 것입니다. 그런데 **한쪽만 고차원으로 갑니다.** "기울기의 곱이 $$-1$$"은 3차원에서 벌써 말이 안 되지만, "내적이 0"은 768차원에서도 그대로입니다.

![계수쌍 (3, 4)는 그 직선의 법선이다](/assets/posts/math-basics-coordinate-plane-and-lines-normal-and-distance.svg)

## 점에서 직선까지의 거리

법선을 손에 넣었으니 거리를 유도할 수 있습니다. 직선 $$ax + by + c = 0$$과 직선 밖의 점 $$P(x_0, y_0)$$이 있습니다.

$$P$$에서 직선에 내린 수선의 발을 $$H$$라 하면, 벡터 $$\overrightarrow{HP}$$는 직선에 수직이므로 **법선 $$n$$과 나란합니다.** 그러니 어떤 실수 $$t$$에 대해

$$P = H + t\,n, \qquad \text{즉} \quad (x_0, y_0) = (x_H + ta,\; y_H + tb)$$

이제 $$P$$의 좌표를 직선의 좌변에 대입해 봅니다.

$$
\begin{aligned}
ax_0 + by_0 + c &= a(x_H + ta) + b(y_H + tb) + c \\
&= \underbrace{(ax_H + by_H + c)}_{= \,0 \;(\text{H는 직선 위})} + t(a^2 + b^2) \\
&= t(a^2 + b^2)
\end{aligned}
$$

한편 우리가 구하려는 거리는 $$\lVert \overrightarrow{HP} \rVert = \lvert t \rvert \cdot \sqrt{a^2 + b^2}$$입니다. 위 식에서 $$t = \dfrac{ax_0 + by_0 + c}{a^2 + b^2}$$이므로

$$d = \frac{\lvert ax_0 + by_0 + c \rvert}{a^2+b^2} \cdot \sqrt{a^2+b^2} = \frac{\lvert ax_0 + by_0 + c \rvert}{\sqrt{a^2 + b^2}}$$

**말로 옮기면 한 문장입니다. "점의 좌표를 좌변에 그냥 대입하고, 법선의 길이로 나눈다."**

앞의 30초 확인 문제로 검산합니다. 직선 $$3x + 4y - 24 = 0$$, 점 $$P(2, 7)$$입니다.

$$3 \cdot 2 + 4 \cdot 7 - 24 = 6 + 28 - 24 = 10, \qquad \sqrt{3^2 + 4^2} = 5$$

$$d = \frac{\lvert 10 \rvert}{5} = 2$$

수선의 발도 구해 봅니다. $$t = 10/25 = 0.4$$이므로 $$H = P - t\,n = (2, 7) - 0.4(3, 4) = (0.8, 5.4)$$입니다. 직선 식에 넣어 확인하면 $$3(0.8) + 4(5.4) - 24 = 2.4 + 21.6 - 24 = 0$$으로 정확히 직선 위입니다.

## 차원을 올리기 — 초평면

이제 항을 늘립니다. $$ax + by + c = 0$$에서 계수를 벡터 $$w = (a, b)$$로, 변수를 $$x = (x, y)$$로, 상수를 $$b$$로 이름만 바꿔 적으면

$$w^\top x + b = 0$$

성분이 $$n$$개여도 식이 그대로입니다. $$w \in \mathbb{R}^n$$, $$x \in \mathbb{R}^n$$이고 $$w^\top x = \sum_i w_i x_i$$입니다. 이 식이 나타내는 것을 **초평면**이라 부릅니다.

| 차원 | 식 | 그 식이 그리는 것 | 남는 자유도 |
| --- | --- | --- | --- |
| 2 | $$w_1x_1 + w_2x_2 + b = 0$$ | 직선 | 1 |
| 3 | $$w_1x_1 + w_2x_2 + w_3x_3 + b = 0$$ | 평면 | 2 |
| $$n$$ | $$w^\top x + b = 0$$ | 초평면 | $$n-1$$ |

**식 하나가 자유도 하나를 잡아먹습니다.** 그래서 초평면은 언제나 전체 공간보다 딱 한 차원 낮고, 공간을 정확히 두 쪽으로 가릅니다.

거리 공식도 문자만 바뀝니다. 유도 과정에서 쓴 것은 "$$H$$가 초평면 위에 있다"와 "$$\overrightarrow{HP}$$가 $$w$$와 나란하다" 둘뿐이고, 둘 다 차원과 무관합니다.

$$d(x_0,\; \text{초평면}) = \frac{\lvert w^\top x_0 + b \rvert}{\lVert w \rVert}$$

## 부호가 답하는 것

절댓값을 벗기면 무엇이 남는지 봅니다. 유도에서 $$w^\top x_0 + b = t \lVert w \rVert^2$$였고, $$P = H + t\,w$$였습니다. 그러니

- $$t > 0$$이면 $$P$$는 $$H$$에서 **$$w$$가 가리키는 방향으로** 떨어져 있습니다
- $$t < 0$$이면 반대 방향입니다
- $$t = 0$$이면 초평면 위입니다

$$\lVert w \rVert^2 > 0$$이므로 $$t$$의 부호와 $$w^\top x_0 + b$$의 부호는 항상 같습니다. 따라서

$$\operatorname{sign}(w^\top x + b) = \begin{cases} +1 & w\text{가 가리키는 쪽} \\ -1 & \text{반대쪽} \end{cases}$$

![b만 바꾸면 직선은 w 방향으로 나란히 밀린다](/assets/posts/math-basics-coordinate-plane-and-lines-hyperplane-sign.svg)

위 그림에서 움직이는 것은 $$b$$ 하나뿐입니다. $$w$$는 그대로이므로 기울기가 바뀌지 않고 직선이 나란히 밀리기만 하며, 직선이 지나간 점부터 차례로 부호가 뒤집힙니다. **뒤집히는 순서는 각 점을 $$w$$ 방향으로 재어 본 값의 순서**입니다.

numpy로 확인해 봅니다.

```python
import numpy as np

w = np.array([3.0, 4.0])
b = -24.0
pts = np.array([[2.0, 7.0], [0.8, 5.4], [0.0, 0.0], [8.0, 8.0]])

vals = pts @ w + b            # [10.  0. -24. 32.]
dist = np.abs(vals) / np.linalg.norm(w)   # [2. 0. 4.8 6.4]
side = np.sign(vals)          # [1. 0. -1. 1.]
```

원점을 넣으면 $$-24$$가 나옵니다. 부호가 음수이니 원점은 $$w$$의 반대쪽에 있고, 거리는 $$24/5 = 4.8$$입니다. 수선의 발 $$(0.8, 5.4)$$는 정확히 0이 나옵니다.

## 아핀과 선형은 다르다

$$b$$가 붙는 순간 하나가 깨집니다. $$b \ne 0$$이면 원점 $$x = 0$$을 대입했을 때 $$b \ne 0$$이라 **초평면이 원점을 지나지 않습니다.**

원점을 지나지 않는 사상은 선형사상이 아닙니다. 선형사상 $$f$$는 $$f(0) = 0$$을 반드시 만족해야 하는데, $$f(x) = Wx + b$$는 $$f(0) = b$$입니다. 이런 것을 **아핀** 사상이라 부르고, 선형사상에 평행이동 하나를 더한 것입니다.

그래서 딥러닝 코드에서 편향 항이 늘 따로 관리됩니다.

```python
layer = nn.Linear(768, 3072, bias=True)
layer.weight   # 선형 부분 W
layer.bias     # 평행이동 부분 b
```

`weight_decay`를 걸 때 `bias`를 제외하는 관례도 여기서 나옵니다. $$W$$를 줄이는 것은 사상이 공간을 늘리는 정도를 줄이는 일이지만, $$b$$를 줄이는 것은 초평면을 원점 쪽으로 끌어당기는 일이라 성격이 다릅니다. 편향을 학습에서 빼면($$b = 0$$) 모든 초평면이 원점을 지나야 하고, 그만큼 표현할 수 있는 것이 줄어듭니다.

선형사상 자체의 정의와 "행렬은 기저의 상을 열에 적어 둔 것"이라는 관점은 본선 9번 · 행렬은 함수다가 맡습니다. 여기서는 **$$b$$가 붙으면 선형이 아니라는 사실**만 못 박습니다.

## 다시 128비트 해시로

처음 코드로 돌아갑니다.

```python
W = rng.normal(size=(128, 768))
bits = (embeddings @ W.T > 0)
```

이제 한 줄씩 읽힙니다.

`W`의 각 행 $$w_k \in \mathbb{R}^{768}$$은 **원점을 지나는 초평면 한 장의 법선**입니다. 편향이 없으니 128장 전부 원점을 지납니다. `embeddings @ W.T`는 각 임베딩에 대해 $$w_k^\top x$$를 128번 계산한 것이고, `> 0`은 그 부호를 읽어 "$$w_k$$가 가리키는 쪽인가"를 답합니다. 그 답 128개를 이어 붙인 것이 해시입니다.

**초평면 한 장은 공간을 두 쪽으로 가르고, 128장은 공간을 조각냅니다.** 가까운 두 벡터는 128장 중 대부분에서 같은 쪽에 있게 되므로 해시가 거의 같고, 먼 두 벡터는 여러 장에서 갈라지므로 해시가 크게 다릅니다. 그래서 해시가 같은 것들만 꺼내 정밀 비교하면 됩니다.

여기까지가 이 글이 세우는 기하입니다. 그다음 질문 — **"두 벡터가 이루는 각이 $$\theta$$일 때, 무작위 초평면 하나가 둘을 갈라놓을 확률이 정확히 얼마인가"** — 는 확률 계산이고, 본선 67번 · 무작위 초평면 해싱: 충돌 확률을 유도하고 recall을 확률로 읽기가 $$\theta/\pi$$라는 답을 유도합니다. 그 유도가 서 있는 바닥이 방금 확인한 "$$w^\top x$$의 부호가 어느 쪽인지를 답한다"입니다.

같은 식이 다른 자리에서도 그대로 나옵니다. [SVM](/articles/ml-svm)의 마진 $$2/\lVert w \rVert$$는 두 초평면 $$w^\top x + b = \pm 1$$ 사이 거리이고, 방금 유도한 거리 공식에 $$\pm 1$$을 넣어 더한 것입니다. 사영의 잔차 길이도 같은 식을 다른 방향에서 읽은 것인데, 사영 공식과 최소제곱의 기하는 본선 7번 · 직교와 사영의 몫입니다.

$$w^\top x + b$$라는 다섯 글자가 이 전부를 지고 있습니다. 그리고 그 다섯 글자는 좌표평면 위 직선 하나에 이름만 바꿔 붙인 것이었습니다.
