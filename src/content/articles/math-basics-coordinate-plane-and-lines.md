> **좌표평면**은 가로축과 세로축을 직각으로 놓고 점을 두 수 $$(x, y)$$ 로 적는 평면입니다.
>
> **기울기**는 가로로 한 칸 갈 때 세로로 얼마나 오르는가입니다.
>
> **법선**은 어떤 직선에 수직인 방향입니다. $$ax + by + c = 0$$ 에서 계수쌍 $$(a, b)$$ 가 그 방향을 가리킵니다.

[19번 글](/articles/math-basics-functions-and-graphs)은 좌표평면을 **함수를 그리는 종이** 로 썼습니다. 점을 찍고 이어 곡선을 만드는 데까지였습니다.

이 글은 좌표평면 자체를 무대로 씁니다. 도형을 올려놓고 **길이를 재고 방향을 재는** 일을 합니다. 도구는 이미 다 있습니다.

## 두 점 사이 거리는 피타고라스 그대로다

$$A(1,2)$$ 와 $$B(5,5)$$ 사이의 거리를 재 봅니다. 자를 대는 대신 직각삼각형을 하나 그립니다.

$$A$$ 에서 오른쪽으로 가고 $$B$$ 에서 아래로 내려오면 $$(5,2)$$ 에서 만납니다. 이 세 점이 직각삼각형을 이루고, **두 변의 길이가 곧 좌표의 차** 입니다.

![두 점을 잇는 선분을 빗변으로 하는 직각삼각형을 좌표평면에 그린 그림](/assets/posts/math-basics-coordinate-plane-and-lines-distance-slope.svg)

가로 변은 $$5-1=4$$, 세로 변은 $$5-2=3$$ 입니다. [7번 글](/articles/math-basics-pythagorean-theorem)의 정리를 그대로 씁니다.

$$\overline{AB} = \sqrt{4^2+3^2} = \sqrt{25} = 5$$

문자로 적으면 이렇습니다.

$$\overline{AB} = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2}$$

**새로 증명할 것이 없습니다.** 피타고라스 정리를 좌표에 얹어 적은 것뿐이고, 제곱하므로 차의 부호가 어느 쪽이든 상관없습니다.

같은 그림에서 중점도 나옵니다. 각 좌표의 평균이 중점입니다.

$$M = \left(\frac{x_1+x_2}{2}, \; \frac{y_1+y_2}{2}\right)$$

$$A(1,2)$$ 와 $$B(5,5)$$ 의 중점은 $$(3, 3.5)$$ 입니다.

## 기울기 — 가로로 한 칸 갈 때 세로로 얼마나 오르는가

같은 직각삼각형을 다르게 읽으면 다른 값이 나옵니다. 두 변을 **더하는** 대신 **나눕니다.**

$$m = \frac{\Delta y}{\Delta x} = \frac{y_2-y_1}{x_2-x_1}$$

$$A(1,2)$$ 와 $$B(5,5)$$ 에서는 $$m = \dfrac{3}{4}$$ 입니다. 가로로 4 가는 동안 세로로 3 오릅니다. 가로로 1만 가면 $$\dfrac34$$ 만큼 오릅니다.

**기울기는 이 트랙에서 여기가 처음** 입니다. 뜻은 한 줄이지만 뒤로 오래 갑니다 — 30번 · 평균변화율과 할선이 이 정의를 그대로 곡선으로 가져갑니다.

부호가 방향을 말합니다. 양수면 오른쪽으로 오르고, 음수면 내리고, 0이면 가로선입니다.

기울기가 있으면 세 점이 한 줄 위에 있는지 한눈에 판정됩니다. $$(0,0)$$, $$(2,1)$$, $$(6,3)$$ 은 앞의 둘로 잰 기울기가 $$\dfrac12$$ 이고 뒤의 둘로 잰 기울기도 $$\dfrac{2}{4}=\dfrac12$$ 이라 한 직선 위에 있습니다.

## 직선을 적는 세 가지 방법

같은 직선을 세 가지 꼴로 적습니다. 상황에 따라 편한 것이 다릅니다.

| 꼴 | 적는 법 | 편한 때 |
| --- | --- | --- |
| 기울기와 절편 | $$y = mx + b$$ | 그래프를 그릴 때 |
| 점과 기울기 | $$y - y_1 = m(x - x_1)$$ | 지나는 점 하나를 알 때 |
| 일반형 | $$ax + by + c = 0$$ | 모든 직선을 한 꼴로 다룰 때 |

기울기 2이고 $$(1,3)$$ 을 지나는 직선은 둘째 꼴로 $$y-3 = 2(x-1)$$ 이고, 정리하면 $$y = 2x+1$$ 이고, 옮겨 적으면 $$2x - y + 1 = 0$$ 입니다. **셋은 같은 직선입니다.**

셋째 꼴이 따로 필요한 이유가 있습니다. **세로선에는 기울기가 없습니다.** $$x=3$$ 은 $$\Delta x = 0$$ 이라 나눌 수가 없어 첫째·둘째 꼴로 적히지 않습니다. 일반형에서는 $$b=0$$ 인 경우일 뿐이라 예외가 사라집니다.

## 평행과 수직

**평행은 쉽습니다.** 기울기가 같으면 평행입니다. 오르는 정도가 같으니 영원히 만나지 않습니다.

**수직 조건은 유도합니다.** 원점을 지나는 두 직선 $$y=m_1x$$ 와 $$y=m_2x$$ 가 서로 수직이라고 해 봅시다. $$x=1$$ 인 자리에서 각각 점 $$A(1, m_1)$$ 과 $$B(1, m_2)$$ 를 잡으면 삼각형 $$OAB$$ 가 원점에서 직각입니다.

거리 공식으로 세 변의 제곱을 적습니다.

$$\overline{OA}^2 = 1 + m_1^2, \quad \overline{OB}^2 = 1 + m_2^2, \quad \overline{AB}^2 = (m_1-m_2)^2$$

피타고라스 정리를 씁니다.

$$(1+m_1^2) + (1+m_2^2) = m_1^2 - 2m_1m_2 + m_2^2$$

양쪽에서 $$m_1^2$$ 과 $$m_2^2$$ 이 지워지고 $$2 = -2m_1m_2$$ 만 남습니다.

$$m_1 m_2 = -1$$

**수직인 두 직선의 기울기는 곱이 $$-1$$** 입니다. 기울기 2인 직선에 수직인 직선의 기울기는 $$-\dfrac12$$ 입니다.

## 점과 직선 사이 거리, 그리고 법선

점 $$P(x_0, y_0)$$ 에서 직선 $$ax+by+c=0$$ 까지의 거리를 구합니다. 수선의 발을 $$H$$ 라 하면 그 방향이 무엇인지부터 알아야 합니다.

직선 위의 두 점 $$(x_1,y_1)$$, $$(x_2,y_2)$$ 는 각각 방정식을 만족하므로 빼면 $$a(x_1-x_2) + b(y_1-y_2) = 0$$ 입니다. 여기서 직선의 기울기가 $$-\dfrac{a}{b}$$ 임이 나오고, 방향 $$(a,b)$$ 가 갖는 기울기는 $$\dfrac{b}{a}$$ 입니다. **두 기울기의 곱이 $$-1$$** 이므로 방금 세운 조건에 따라 $$(a,b)$$ 는 직선에 수직입니다.

이 방향을 **법선** 이라 합니다. 계수쌍이 곧 직선의 수직 방향을 가리키고 있었습니다.

![직선 3x+4y−12=0 과 두 점, 법선 방향을 함께 그린 그림](/assets/posts/math-basics-coordinate-plane-and-lines-normal.svg)

이제 거리를 구합니다. $$P$$ 는 $$H$$ 에서 법선 방향으로 얼마쯤 간 자리이므로 $$P = H + t(a,b)$$ 로 적을 수 있고, 거리는 $$|t|\sqrt{a^2+b^2}$$ 입니다. $$P$$ 의 좌표를 직선의 좌변에 넣어 봅니다.

$$ax_0+by_0+c = a(x_H + ta) + b(y_H + tb) + c = (ax_H+by_H+c) + t(a^2+b^2)$$

$$H$$ 는 직선 위의 점이라 첫 괄호가 0입니다. 따라서 $$t = \dfrac{ax_0+by_0+c}{a^2+b^2}$$ 이고, 거리는 이렇게 됩니다.

$$d = \frac{|ax_0+by_0+c|}{\sqrt{a^2+b^2}}$$

$$3x+4y-12=0$$ 과 점 $$P(4,4)$$ 로 확인합니다. $$\dfrac{|12+16-12|}{\sqrt{9+16}} = \dfrac{16}{5} = 3.2$$ 입니다.

**절댓값을 벗기면 부호가 남고, 그 부호가 어느 쪽에 있는지를 답합니다.** 같은 직선에 대해 $$R(1,1)$$ 을 넣으면 $$3+4-12 = -5$$ 로 음수입니다. $$P$$ 와 $$R$$ 은 직선을 사이에 두고 반대쪽에 있습니다.

## 원의 방정식은 거리 공식의 다른 이름이다

원은 **한 점에서 같은 거리에 있는 점들의 모임** 입니다. 정의를 거리 공식으로 그대로 옮겨 적습니다.

중심 $$(p,q)$$, 반지름 $$r$$ 인 원 위의 점 $$(x,y)$$ 는 중심까지의 거리가 $$r$$ 이므로 이렇습니다.

$$\sqrt{(x-p)^2+(y-q)^2} = r \quad \to \quad (x-p)^2 + (y-q)^2 = r^2$$

$$(x-1)^2 + (y+2)^2 = 9$$ 는 중심이 $$(1,-2)$$ 이고 반지름이 3입니다. 괄호 안의 부호가 반대로 읽히는 것은 20번 글의 평행이동과 같은 이유입니다.

풀어헤친 꼴로 주어지면 [18번 글](/articles/math-basics-algebra-manipulation)의 완전제곱으로 되돌립니다.

$$x^2+y^2+2x-8y+8=0$$

$$x$$ 끼리, $$y$$ 끼리 모아 각각 완전제곱을 만듭니다.

$$(x^2+2x+1) + (y^2-8y+16) = -8 + 1 + 16$$

$$(x+1)^2 + (y-4)^2 = 9$$

중심 $$(-1, 4)$$, 반지름 3입니다. **오른쪽이 음수로 나오면 그런 원은 없습니다.** 거리의 제곱이 음수일 수 없기 때문입니다.

## 연습 문제

### 연습 1 — 거리와 중점 세 문제

1. $$A(-1, 2)$$ 와 $$B(3, -1)$$ 사이의 거리

   답. $$\Delta x = 4$$, $$\Delta y = -3$$ 이므로 $$\sqrt{16+9}=5$$.
2. $$C(0,0)$$ 과 $$D(5, 12)$$ 사이의 거리

   답. $$\sqrt{25+144} = \sqrt{169} = 13$$.
3. $$A(-1,2)$$ 와 $$B(3,-1)$$ 의 중점

   답. 각 좌표의 평균이므로 $$\left(\dfrac{-1+3}{2}, \dfrac{2-1}{2}\right) = \left(1, \dfrac12\right)$$.

### 연습 2 — 기울기 세 문제

1. $$(1,3)$$ 과 $$(4,9)$$ 를 지나는 직선의 기울기

   답. $$\dfrac{9-3}{4-1} = \dfrac63 = 2$$.
2. $$(-2,5)$$ 와 $$(2,-3)$$ 을 지나는 직선의 기울기

   답. $$\dfrac{-3-5}{2-(-2)} = \dfrac{-8}{4} = -2$$. 음수라 오른쪽으로 내려갑니다.
3. $$(0,1)$$, $$(2,5)$$, $$(5,11)$$ 은 한 직선 위에 있습니까?

   답. 앞의 둘로 잰 기울기가 $$\dfrac{4}{2}=2$$ 이고 뒤의 둘로 잰 기울기도 $$\dfrac{6}{3}=2$$ 라 같습니다. 한 직선 위에 있습니다.

### 연습 3 — 직선의 식 네 문제

1. 기울기가 3이고 $$(2,1)$$ 을 지나는 직선

   답. $$y-1 = 3(x-2)$$ 이므로 $$y = 3x-5$$.
2. $$(1,2)$$ 와 $$(3,8)$$ 을 지나는 직선

   답. 기울기가 $$\dfrac{6}{2}=3$$ 이므로 $$y-2 = 3(x-1)$$ 이고 정리하면 $$y = 3x-1$$.
3. $$2x+3y-6=0$$ 을 $$y=mx+b$$ 꼴로

   답. $$3y = -2x+6$$ 이므로 $$y = -\dfrac23 x + 2$$. 기울기 $$-\dfrac23$$, $$y$$ 절편 2입니다.
4. $$(4,-1)$$ 을 지나고 $$y=2x+1$$ 에 수직인 직선

   답. 기울기의 곱이 $$-1$$ 이어야 하므로 $$m = -\dfrac12$$ 입니다. $$y+1 = -\dfrac12(x-4)$$ 이고 정리하면 $$y = -\dfrac{x}{2}+1$$.

### 연습 4 — 점과 직선 사이 거리 두 문제

1. 점 $$(2,3)$$ 과 직선 $$3x+4y-5=0$$ 사이의 거리

   답. $$\dfrac{|6+12-5|}{\sqrt{9+16}} = \dfrac{13}{5} = 2.6$$.
2. 점 $$(3,1)$$ 과 직선 $$x-y+2=0$$ 사이의 거리를 구하고, 이 점이 원점과 같은 쪽에 있는지 판정하세요.

   답. 좌변에 넣으면 $$3-1+2 = 4$$ 이므로 거리는 $$\dfrac{4}{\sqrt2} = 2\sqrt2$$ 입니다. 원점을 넣으면 $$0-0+2 = 2$$ 로 역시 양수라 같은 쪽입니다.

### 연습 5 — 원 세 문제

1. 중심이 $$(2,-3)$$ 이고 반지름이 4인 원의 방정식

   답. $$(x-2)^2+(y+3)^2 = 16$$.
2. $$x^2+y^2-6x+4y-3=0$$ 의 중심과 반지름

   답. $$(x^2-6x+9)+(y^2+4y+4) = 3+9+4$$ 이므로 $$(x-3)^2+(y+2)^2 = 16$$ 입니다. 중심 $$(3,-2)$$, 반지름 4.
3. 중심이 $$(1,2)$$ 이고 점 $$(4,6)$$ 을 지나는 원의 방정식

   답. 반지름은 중심에서 그 점까지의 거리이므로 $$\sqrt{9+16}=5$$ 입니다. $$(x-1)^2+(y-2)^2=25$$.

## 정리

- 두 점 사이 거리 $$\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}$$ 는 피타고라스 정리를 좌표에 얹은 것입니다. 중점은 각 좌표의 평균입니다.
- 기울기 $$\dfrac{\Delta y}{\Delta x}$$ 는 **가로로 한 칸 갈 때 세로로 얼마나 오르는가** 입니다. 두 점으로 잰 기울기가 같으면 한 직선 위에 있습니다.
- 직선은 $$y=mx+b$$, $$y-y_1=m(x-x_1)$$, $$ax+by+c=0$$ 셋으로 적습니다. **세로선은 기울기가 없어 일반형으로만 적힙니다.**
- 평행이면 기울기가 같고, 수직이면 기울기의 곱이 $$-1$$ 입니다.
- 점과 직선 사이 거리는 $$\dfrac{|ax_0+by_0+c|}{\sqrt{a^2+b^2}}$$ 이고, **절댓값 안의 부호가 직선의 어느 쪽인지 답합니다.**
- 계수쌍 $$(a,b)$$ 는 직선에 수직인 방향, 곧 법선입니다.
- 원의 방정식 $$(x-p)^2+(y-q)^2=r^2$$ 은 거리 공식을 옮겨 적은 것입니다. 풀어헤친 꼴은 완전제곱으로 되돌려 중심과 반지름을 읽습니다.
