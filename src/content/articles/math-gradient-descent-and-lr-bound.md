학습률을 $$3\times10^{-4}$$ 에서 $$3\times10^{-3}$$ 으로 올렸더니 몇 스텝 만에 손실이 `nan`이 되었습니다. 흔한 일이고, 대개 "학습률이 너무 컸다"로 정리하고 넘어갑니다. 그런데 **너무 크다는 것은 무엇보다 큰 것일까요.** 이 글의 답은 정확한 수 하나입니다.

[지난 글](/articles/math-taylor-hessian-and-curvature)에서 지형을 2차까지 근사하는 법과 헤세의 고윳값이 곡률이라는 것을 세웠습니다. 그 도구로 경사하강 갱신식을 유도하고, **손실이 반드시 줄어드는 학습률의 구간이 $$0 < \eta < 2/L$$ 임을 증명**한 뒤, 그 경계를 이차함수에서 숫자로 재현합니다.

## 왜 하필 그래디언트의 반대 방향인가

지금 위치 $$x$$ 에서 한 걸음 $$\Delta$$ 를 옮깁니다. 걸음의 크기는 $$\|\Delta\| = r$$ 로 고정하고, **방향만** 고르는 문제로 놓습니다. 1차 근사를 씁니다.

$$f(x + \Delta) \approx f(x) + \nabla f(x)\cdot\Delta$$

$$f(x)$$ 는 고정이므로 줄이려면 $$\nabla f(x)\cdot\Delta$$ 를 가장 작게 만들어야 합니다. [코시–슈바르츠 부등식](/articles/math-dot-product-and-cosine)이 이 값의 하한을 줍니다.

$$\nabla f(x)\cdot\Delta \ \ge\ -\|\nabla f(x)\|\,\|\Delta\| = -r\,\|\nabla f(x)\|$$

등호는 두 벡터가 **정확히 반대 방향일 때**만 성립합니다.

$$\Delta^\star = -\,r\,\frac{\nabla f(x)}{\|\nabla f(x)\|}$$

> **경사하강법.** 크기를 정해 놓고 1차 근사를 가장 많이 줄이는 방향은 그래디언트의 반대쪽뿐이다.

$$r$$ 을 $$\eta\|\nabla f(x)\|$$ 로 잡으면 노름이 약분되어 익숙한 식이 됩니다.

$$x_{t+1} = x_t - \eta\,\nabla f(x_t)$$

![크기를 고정하면 가장 많이 내려가는 방향은 −∇f 하나뿐이다](/assets/posts/math-gradient-descent-and-lr-bound-steepest.svg)

여기서 이미 한계가 보입니다. **이 유도가 옳은 것은 1차 근사가 맞는 동안뿐입니다.** $$r$$ 을 키우면 근사가 어긋나고, 어긋나면 "가장 많이 줄이는 방향"이라는 근거가 사라집니다. 그래서 얼마나 커도 되는지를 재려면 근사의 오차를 위에서 눌러 줄 무언가가 필요합니다.

## L-매끄러움: 그래디언트가 얼마나 급히 변하는가

그 무언가가 이것입니다. 함수 $$f$$ 가 **L-매끄럽다**는 것은 그래디언트가 립시츠 연속이라는 뜻입니다.

$$\|\nabla f(x) - \nabla f(y)\| \ \le\ L\,\|x - y\|$$

[립시츠 상수](/articles/math-matrix-norms)는 "입력이 1만큼 움직일 때 출력이 최대 얼마나 움직이는가"의 상한입니다. 여기서는 입력이 위치, 출력이 **그래디언트**입니다. 즉 $$L$$ 은 **기울기가 변하는 속도의 상한**이고, 기울기가 변하는 속도는 곧 곡률입니다.

두 번 미분 가능하면 관계가 정확히 드러납니다. L-매끄러움은 모든 점에서

$$\lambda_{\max}\big(\nabla^2 f(x)\big) \ \le\ L$$

과 같습니다. **$$L$$ 은 지형 전체에서 가장 가파르게 굽은 곳의 곡률입니다.** 지난 글의 $$\lambda_{\max}$$ 를 전 구간에 걸쳐 최대로 잡은 값입니다.

이제 1차 근사의 오차를 $$L$$ 로 누릅니다. $$d = y - x$$ 라 두고 $$g(t) = f(x + td)$$ 를 미적분의 기본정리로 적습니다.

$$f(y) - f(x) = \int_0^1 \nabla f(x + td)\cdot d\ dt$$

양변에서 1차 항 $$\nabla f(x)\cdot d$$ 를 빼면

$$f(y) - f(x) - \nabla f(x)\cdot d = \int_0^1 \big(\nabla f(x+td) - \nabla f(x)\big)\cdot d\ dt$$

적분 안의 내적을 코시–슈바르츠와 L-매끄러움으로 차례로 누릅니다. $$\|x + td - x\| = t\|d\|$$ 이므로

$$\big(\nabla f(x+td) - \nabla f(x)\big)\cdot d \ \le\ L\,t\,\|d\|\cdot\|d\| = L\,t\,\|d\|^2$$

이고, $$\int_0^1 L t \|d\|^2 dt = \tfrac{L}{2}\|d\|^2$$ 입니다.

> **하강 보조정리.** $$f(y) \ \le\ f(x) + \nabla f(x)\cdot(y-x) + \dfrac{L}{2}\|y - x\|^2$$

근사가 아니라 **부등식**입니다. 어디서나 성립하는 상계이고, 오른쪽은 $$y$$ 에 대한 이차함수 — 위로 열린 포물면입니다. 곡률이 $$L$$ 인 그릇을 접점에 얹으면 함수가 그 아래에 완전히 들어간다는 그림입니다.

![하강 보조정리: 곡률 L의 포물면이 함수를 위에서 덮는다](/assets/posts/math-gradient-descent-and-lr-bound-descent-lemma.svg)

## 학습률의 상한 2/L

이제 상계에 경사하강 갱신을 그대로 넣습니다. $$y = x - \eta\nabla f(x)$$ 이므로 $$y - x = -\eta\nabla f(x)$$ 이고 $$\|y-x\|^2 = \eta^2\|\nabla f(x)\|^2$$ 입니다.

$$f(x_{t+1}) \ \le\ f(x_t) - \eta\|\nabla f\|^2 + \frac{L}{2}\eta^2\|\nabla f\|^2$$

$$\|\nabla f\|^2$$ 로 묶습니다.

$$f(x_{t+1}) \ \le\ f(x_t) - \eta\left(1 - \frac{L\eta}{2}\right)\|\nabla f(x_t)\|^2$$

$$\|\nabla f\|^2 \ge 0$$ 이므로 **손실이 반드시 줄어들려면 앞의 계수가 양수여야 합니다**.

$$\eta\left(1 - \frac{L\eta}{2}\right) > 0 \ \iff\ \eta > 0 \ \text{이고}\ \frac{L\eta}{2} < 1$$

> **학습률 상한.** $$0 < \eta < \dfrac{2}{L}$$ 이면 매 스텝 손실이 줄어든다.

한 걸음 더 갑니다. 감소량 $$\eta - \tfrac{L}{2}\eta^2$$ 를 $$\eta$$ 에 대해 최대로 만드는 지점은 미분해서 $$1 - L\eta = 0$$, 즉

$$\eta^\star = \frac{1}{L}, \qquad \text{그때 감소량} \ \ge\ \frac{1}{2L}\|\nabla f(x_t)\|^2$$

입니다. **가장 좋은 학습률은 상한의 절반**이고, 상한에서 절반만큼 떨어져 있는 것이 아니라 정확히 그 절반입니다.

$$\eta$$ 를 $$0$$ 에서 $$2/L$$ 로 키우면 감소량은 $$\eta = 1/L$$ 까지 늘다가 다시 줄어 $$2/L$$ 에서 $$0$$ 이 됩니다. 그 너머는 보장이 사라집니다.

## 경계를 이차함수에서 재현하기

가장 단순한 예로 경계가 정확한지 확인합니다. $$f(x) = \tfrac12\lambda x^2$$ 이면 $$\nabla f = \lambda x$$ 이고 $$f'' = \lambda$$ 이므로 $$L = \lambda$$ 입니다. 갱신식은

$$x_{t+1} = x_t - \eta\lambda x_t = (1 - \eta\lambda)\,x_t$$

한 스텝이 곱셈 하나입니다. $$t$$ 스텝 뒤에는 $$x_t = (1-\eta\lambda)^t x_0$$ 이므로 [거듭제곱의 크기](/articles/math-matrix-powers-and-power-iteration)가 전부를 정합니다.

$$|1 - \eta\lambda| < 1 \ \iff\ -1 < 1 - \eta\lambda < 1 \ \iff\ 0 < \eta < \frac{2}{\lambda} = \frac{2}{L}$$

**상계에서 얻은 조건과 정확히 같습니다.** 이 경우에는 부등식이 아니라 등호로 딱 맞는 경계입니다. $$\lambda = 1$$, $$x_0 = 1$$ 로 여섯 가지 학습률을 돌려 봅니다.

| $$\eta$$ | $$\|1-\eta\lambda\|$$ | $$x_0 \to x_6$$ | 무슨 일이 |
| --- | --- | --- | --- |
| 0.5 | 0.50 | 1, 0.5, 0.25, 0.125, 0.0625, 0.0312, 0.0156 | 부호를 지키며 수렴 |
| 1.0 | 0.00 | 1, 0, 0, 0, 0, 0, 0 | 한 걸음에 도착 |
| 1.5 | 0.50 | 1, −0.5, 0.25, −0.125, 0.0625, −0.0312, 0.0156 | 부호가 바뀌며 수렴 |
| 1.9 | 0.90 | 1, −0.9, 0.81, −0.729, 0.6561, −0.5905, 0.5314 | 크게 튀며 아주 느리게 수렴 |
| 2.0 | 1.00 | 1, −1, 1, −1, 1, −1, 1 | 영원히 진동 — 경계 |
| 2.1 | 1.10 | 1, −1.1, 1.21, −1.331, 1.4641, −1.6105, 1.7716 | 발산 |

![학습률에 따라 수렴·진동·발산으로 갈린다](/assets/posts/math-gradient-descent-and-lr-bound-eta-sweep.svg)

$$\eta = 1/L = 1$$ 에서 한 걸음에 끝나는 것도 위의 $$\eta^\star = 1/L$$ 그대로입니다. 그리고 **$$\eta = 2/L$$ 은 발산이 아니라 진동의 경계**입니다 — 줄어들지도 커지지도 않습니다. 실제 학습에서 손실이 `nan`으로 가는 것은 이 선을 넘은 다음이고, 넘는 순간 $$|1-\eta\lambda|^t$$ 가 지수적으로 커집니다.

## 조건수가 나쁘면 몇 배 느려지는가

방향이 여럿이면 이야기가 달라집니다. $$f(x) = \tfrac12 x^{\mathsf T}Hx$$ 에서 $$H$$ 를 고유벡터 좌표계로 옮기면 $$H = \mathrm{diag}(\lambda_1,\dots,\lambda_n)$$ 이 되고, 좌표마다 **서로 독립인** 1차원 문제가 됩니다.

$$y_i^{(t)} = (1 - \eta\lambda_i)^t\,y_i^{(0)}$$

전부 수렴하려면 모든 $$i$$ 에서 $$|1-\eta\lambda_i| < 1$$ 이어야 하므로 **가장 큰 고윳값이 상한을 정합니다**.

$$0 < \eta < \frac{2}{\lambda_{\max}}$$

그런데 **수렴 속도는 가장 작은 고윳값이 정합니다.** 전체가 줄어드는 속도는 가장 느린 좌표의 속도이므로

$$\rho(\eta) = \max_i\,|1 - \eta\lambda_i| = \max\big(|1-\eta\lambda_{\min}|,\ |1-\eta\lambda_{\max}|\big)$$

한쪽을 줄이면 다른 쪽이 커지므로, 최적은 둘이 같아지는 자리입니다. $$1 - \eta\lambda_{\min} = -(1 - \eta\lambda_{\max})$$ 를 풀면

$$\eta^\star = \frac{2}{\lambda_{\max} + \lambda_{\min}}, \qquad \rho^\star = \frac{\lambda_{\max}-\lambda_{\min}}{\lambda_{\max}+\lambda_{\min}} = \frac{\kappa - 1}{\kappa + 1}$$

$$\kappa$$ 는 지난 글의 조건수입니다. 오차를 $$\varepsilon$$ 배로 줄이는 데 필요한 반복 수는 $$\rho^t = \varepsilon$$ 에서 $$t = \log\varepsilon / \log\rho$$ 이고, $$\kappa$$ 가 크면 $$\log(1/\rho) \approx 2/\kappa$$ 이므로

$$t \ \approx\ \frac{\kappa}{2}\,\log\frac{1}{\varepsilon}$$

**반복 수가 조건수에 비례합니다.** 손실을 1000분의 1로 줄이는 데 걸리는 스텝을 세어 보면 그대로 나타납니다.

| $$\kappa$$ | $$\eta^\star$$ ($$\lambda_{\min}=1$$) | $$\rho^\star$$ | 오차 $$10^{-3}$$ 까지 |
| --- | --- | --- | --- |
| 1 | 1 | 0 | 1회 |
| 4 | 0.4 | 0.6 | 14회 |
| 10 | 0.1818 | 0.8182 | 35회 |
| 100 | 0.0198 | 0.9802 | 346회 |
| 1000 | 0.0020 | 0.9980 | 3454회 |

**조건수가 10배가 되면 반복도 10배입니다.** 이것이 길쭉한 골짜기에서 경사하강이 지그재그로 오래 헤매는 이유이고, 원인이 학습률을 잘못 골라서가 아니라는 점이 중요합니다. $$\eta^\star$$ 는 이미 최선으로 골랐고, 그래도 $$\kappa$$ 에 비례해 느립니다.

![조건수가 커질수록 최적 학습률에서도 수렴이 느려진다](/assets/posts/math-gradient-descent-and-lr-bound-condition.svg)

## 코드로 확인하기

먼저 1차원 경계입니다.

```python
import numpy as np

lam, x0 = 1.0, 1.0
for eta in [0.5, 1.0, 1.5, 1.9, 2.0, 2.1]:
    x, traj = x0, [x0]
    for _ in range(6):
        x = x - eta * (lam * x)
        traj.append(x)
    print(f"η={eta:4.1f}  |1−ηλ|={abs(1-eta*lam):.2f}  " + " ".join(f"{v: .4f}" for v in traj))

# η= 0.5  |1−ηλ|=0.50   1.0000  0.5000  0.2500  0.1250  0.0625  0.0312  0.0156
# η= 1.0  |1−ηλ|=0.00   1.0000  0.0000  0.0000  0.0000  0.0000  0.0000  0.0000
# η= 1.5  |1−ηλ|=0.50   1.0000 -0.5000  0.2500 -0.1250  0.0625 -0.0312  0.0156
# η= 1.9  |1−ηλ|=0.90   1.0000 -0.9000  0.8100 -0.7290  0.6561 -0.5905  0.5314
# η= 2.0  |1−ηλ|=1.00   1.0000 -1.0000  1.0000 -1.0000  1.0000 -1.0000  1.0000
# η= 2.1  |1−ηλ|=1.10   1.0000 -1.1000  1.2100 -1.3310  1.4641 -1.6105  1.7716
```

정확히 $$\eta = 2$$ 에서 진동이 멈추지도 커지지도 않습니다. 다음은 조건수 10짜리 2차원입니다. $$L = \lambda_{\max} = 10$$ 이므로 상한이 $$2/10 = 0.2$$ 입니다.

```python
H = np.diag([10.0, 1.0])

for eta in [0.05, 0.1818, 0.19, 0.20, 0.21]:
    x = np.array([1.0, 1.0])
    for _ in range(60):
        x = x - eta * (H @ x)
    rho = max(abs(1 - eta * 10), abs(1 - eta * 1))
    print(f"η={eta:.4f}  ρ={rho:.4f}   60스텝 후 ‖x‖={np.linalg.norm(x):.3e}")

# η=0.0500  ρ=0.9500   60스텝 후 ‖x‖=4.607e-02
# η=0.1818  ρ=0.8182   60스텝 후 ‖x‖=8.297e-06      ← 최적 2/(10+1)
# η=0.1900  ρ=0.9000   60스텝 후 ‖x‖=1.797e-03
# η=0.2000  ρ=1.0000   60스텝 후 ‖x‖=1.000e+00      ← 경계, 줄지 않는다
# η=0.2100  ρ=1.1000   60스텝 후 ‖x‖=3.045e+02      ← 발산
```

$$\eta^\star = 2/(10+1) = 0.1818$$ 이 실제로 가장 빠르고, $$0.2$$ 에서 노름이 딱 1로 멈춰 있고, $$0.21$$ 에서 300배로 커졌습니다. 세 줄 모두 유도한 그대로입니다.

```python
import math
for k in [1, 4, 10, 100, 1000]:
    rho = (k - 1) / (k + 1)
    it = 1 if rho == 0 else math.log(1e-3) / math.log(rho)
    print(f"κ={k:5d}  η*={2/(k+1):.4f}  ρ={rho:.4f}  10⁻³까지 {it:.1f}회")

# κ=    1  η*=1.0000  ρ=0.0000  10⁻³까지 1.0회
# κ=    4  η*=0.4000  ρ=0.6000  10⁻³까지 13.5회
# κ=   10  η*=0.1818  ρ=0.8182  10⁻³까지 34.4회
# κ=  100  η*=0.0198  ρ=0.9802  10⁻³까지 345.4회
# κ= 1000  η*=0.0020  ρ=0.9980  10⁻³까지 3453.9회
```

## 정리

- 걸음의 크기를 정해 놓고 1차 근사를 가장 많이 줄이는 방향은 코시–슈바르츠의 등호 조건에서 **$$-\nabla f$$ 하나뿐**이다. 여기서 $$x_{t+1} = x_t - \eta\nabla f(x_t)$$ 가 나온다.
- **L-매끄러움**은 그래디언트의 립시츠 상수가 $$L$$ 이라는 뜻이고, 두 번 미분 가능하면 $$L$$ 은 지형 전체의 최대 곡률 $$\lambda_{\max}$$ 다.
- 그 상수로 1차 근사의 오차를 누르면 **하강 보조정리** $$f(y) \le f(x) + \nabla f\cdot(y-x) + \tfrac{L}{2}\|y-x\|^2$$ 를 얻는다. 근사가 아니라 부등식이다.
- 여기에 갱신식을 넣으면 $$f(x_{t+1}) \le f(x_t) - \eta(1 - L\eta/2)\|\nabla f\|^2$$ 이고, 계수가 양수일 조건이 **$$0 < \eta < 2/L$$** 이다. 감소가 가장 큰 자리는 정확히 그 절반인 $$\eta = 1/L$$ 이다.
- 이차함수에서는 이 경계가 정확하다. $$x_{t+1} = (1-\eta\lambda)x_t$$ 이므로 $$\eta < 1/\lambda$$ 는 단조 수렴, $$1/\lambda < \eta < 2/\lambda$$ 는 진동하며 수렴, $$\eta = 2/\lambda$$ 는 영원한 진동, 그 위는 발산이다.
- 여러 방향에서는 **상한을 $$\lambda_{\max}$$ 가 정하고 속도를 $$\lambda_{\min}$$ 이 정한다.** 최적 $$\eta^\star = 2/(\lambda_{\max}+\lambda_{\min})$$ 에서도 수렴률이 $$(\kappa-1)/(\kappa+1)$$ 이라 **반복 수가 조건수에 비례**한다.

마지막 줄이 다음 글의 출발점입니다. 학습률을 아무리 잘 골라도 조건수에 비례하는 반복은 남습니다. 그 비례를 $$\kappa$$ 에서 $$\sqrt{\kappa}$$ 로 낮추는 것이 모멘텀이고, 다음 글에서 모멘텀과 네스테로프와 EMA가 사실은 같은 점화식이라는 것을 확인한 뒤 좁은 골짜기에서의 이득을 조건수의 함수로 계산합니다.
